# bridges-humanizer SKILL

- 标识：`bridges-humanizer`
- 版本：1.0.0（固定版本，只读内置，不依赖用户上传或 `.env`）
- 来源：原创净室实现，参见同目录 `CLEAN_ROOM.md`（来源清洁记录）
- 许可证：原创内容，无第三方代码或文本复用（零复用声明）

## 用途

在保持科学判断、证据强度、限定条件和引用关系的前提下，把科学内容表达得
更自然、更贴合真实任务、目标受众与中文表达习惯。同时支持两条端到端路径：

1. **改写路径**：对用户粘贴文本或当前账户文件进行人味化改写。先提取任务
   契约与事实锁，再返回人性化结果。
2. **生成路径**：按主题、受众、体裁、渠道与硬约束生成新文章。收集并确认
   输入后生成，再按体裁规则复核。

## 边界（不可逾越）

- 不规避 AI 检测、不冒充真人、不伪造个人经历、不做欺骗性代写。
- 不虚构事实、论文或引用来增强表达；可引用来源一律通过本地/联网证据
  合同呈现，缺来源的引用必须标注需人工核实。
- 不以牺牲科学事实换取口语化：数值、单位、对象关系、限定条件、公式、
  引用与结论强度受事实锁保护，冲突时停止或明确标注人工确认。
- 不复制无许可证参考项目的文本、提示、目录结构或示例（净室约束）。

## 证据边界

- 数值/单位：原文中出现即视为锁定；改写后必须保持（等价换算除外，且须
  在修改明细中说明）。
- 限定条件：约/可能/在……条件下/仅/部分等限定词及其作用对象必须保持，
  删除或弱化视为需人工确认。
- 结论强度：表明/证明/推测/可能等强度词必须与原文一致；升级强度视为
  阻断冲突。
- 公式：公式及其变量含义必须原样保持，改写公式视为阻断冲突。
- 引用：正文引用（作者年份/编号/网址）必须保持；删改引用视为需人工
  确认；新增引用必须来自本地/联网证据合同，否则标记为虚构风险。
- 对象关系：A 影响/导致/与 B 相关的方向与范围必须保持；反向或扩大范围
  视为阻断冲突。

## 输出合同

每次成功结果固定包含以下五项，缺一不标记完成：

1. 最终文本（`final_text`）
2. 逐项修改细节（`edits`，每项必附原文片段、新文片段与理由）
3. 每项理由（含触发的体裁规则标识）
4. 事实核查结果（`fact_check`，逐项给出已核实/需人工确认/虚构风险）
5. 尚未解决的问题（`open_questions`）

## 体裁合同

本 SKILL 不为所有场景提供单一泛化模板；四类体裁分别使用可测试的表达
规则（见 `genres/`）：

- `popular_science.md` — 科普文案
- `lecture_script.md` — 课程讲稿
- `research_report.md` — 科研汇报
- `paper_assist.md` — 论文写作

## 编排

智能体编排与 SKILL 规则共同工作，不允许退化成一条"写得自然一点"的提示词：

1. 解析任务契约（路径/体裁/受众/渠道/长度/硬约束）。
2. 改写路径先从源文本确定性提取事实锁；生成路径把硬约束编译为事实锁。
3. 按体裁合同与事实锁组装结构化指令。
4. 生成结果后执行确定性复核：事实锁前后比较、体裁规则检查、输出合同
   完整性检查、引用保持检查。
5. 阻断冲突 → 停止并给出可操作说明；需人工事项 → 明确标注，结果终态为
   needs_human；全部通过 → done。

## 失败恢复

过程卡提供中文 loading、empty、error、permission、recovery 五种状态。
失败后可从原任务重试，用户输入与任务契约在重试中保持不变。
