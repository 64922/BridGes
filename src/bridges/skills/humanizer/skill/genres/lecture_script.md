# 体裁合同：课程讲稿（lecture_script）

面向课堂教学场景的逐句讲稿，目标是帮助学习者达成可观察的学习目标。

## 必含（缺失即复核不通过）

- 可观察的学习目标（可检测：出现「学完本节，你将能/本讲目标/你能做到」
  类目标句，且目标含可验证动词如「复述/计算/区分」）。
- 先备知识提醒（可检测：出现「你需要先知道/前提是/如果你还不熟悉」类
  句子，点名 1-3 个先备概念）。
- 讲解主线：核心概念不超过 3 个，按「引入—解释—举例—小结」推进
  （可检测：出现示例标记「比如/举个例子」，以及小结标记「小结一下/
  回顾一下」）。
- 至少一处理解检查（可检测：出现「检查一下/想想看/你能说出」类提问句，
  并附预期答案要点）。
- 至少一处练习停顿建议（可检测：出现「停一下/花 1 分钟/尝试做」类
  教学停顿句）。

## 允许省略

- 完整文献引用列表（口头提及来源即可）；过长的历史背景。

## 禁止

- 无目标地罗列知识点（无学习目标句即不通过）。
- 一次性引入超过 3 个新概念且无检查点。
- 删除数值/单位/公式（事实锁，阻断）。
- 把「检查点问题」写成自问自答的装饰句（可检测：提问句后紧跟 15 字内
  直接给出答案且无停顿设计）。

## 保留（事实锁）

数值、单位、公式、对象关系、限定条件、引用、结论强度全部保持。

## 表达规则（可测试断言）

- 讲稿以口语授课语气写成，可用「你/你们」，不用书面论文腔。
- 每个核心概念引入后 3 句内给出通俗解释或例子。
- 每 5-8 分钟讲稿设置一个理解检查或练习停顿。
- 时间标记（如「（5 分钟）」）不得改变事实内容。

## 人工责任

- 学习目标与检查点须与真实教学计划一致；高风险主题（实验操作、医疗）
  的步骤描述须教师确认。
