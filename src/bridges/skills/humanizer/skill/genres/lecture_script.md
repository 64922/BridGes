# 体裁合同：课程讲稿（lecture_script）

在课堂场景下讲清知识，让听众能跟上并自己完成一次检查或练习。人味化改造
Issue 04 起，本体裁不再声明任何必含元素：学习目标、例子、理解检查、练习
停顿等表达手段一律按需使用，原文不需要时不得强行加入。

## 任务目标

在课堂场景下讲清知识，让听众能跟上并自己完成一次检查或练习。

## 风险（作者须规避）

- 把理解检查写成自问自答装饰句。
- 练习与学习目标不一致。

## 可选表达方式（按需使用）

- 开场给出学习目标或预告。
- 提醒先备知识。
- 举例讲解。
- 在关键处设置理解检查或练习停顿。

## 禁止

- 理解检查写成自问自答装饰句（可检测：「提问：……。答案：」）。

## 保留（事实锁）

数值、单位、对象关系、限定条件、公式、引用、结论强度全部保持。

## 人工责任

学习目标与检查点须与真实教学计划一致；高风险主题（实验操作、医疗）步骤
须教师确认。
