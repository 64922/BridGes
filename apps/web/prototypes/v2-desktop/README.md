# BridGes V2 桌面交互原型

**一次性评审原型，不是生产页面。** 所有消息、附件、学习问题、路线与模型验证均只在浏览器内存中演示；不调用后端、地图、Qwen、Tavily 或知识库，不保存任何密钥。刷新即重置。

## 启动

在仓库根目录执行一条命令：

```powershell
conda run -n agent python -m http.server 4173 --directory apps/web/prototypes/v2-desktop
```

随后在电脑浏览器打开 `http://localhost:4173/`。目标窗口为 1280×720、1440×900 或 1920×1080；不设计移动端。

## 建议体验路径

1. 新聊天保持「日常陪伴」，点击输入框左侧 `+`，选「论文搜索」并输入「找 Transformer 入门论文」，发送；再从 `+` 选「贴吧信息搜集」，在同一个会话发送第二条消息。
2. 点击「新聊天」，右上角切「学习模式」；添加两张书页照片并用上移／下移排序，发送后查看预习问题和辅导态。点击「开始复盘」，试答一题，看即时正确答案与下一题；暂停后可继续。
3. 从左下角账户菜单打开「用户画像」，修改或删除演示条目；打开「密钥与模型管理」，试填模型 ID。验证结果是界面模拟，不能证明线上模型可用。
