# V2 可行性与上线门

> 结论按“能否以可信结果交付”判断。能写出模拟回答不算可行；必须实测输入解析、工具可达、证据质量、失败降级与桌面呈现。

| 能力 | 判断 | 关键不确定性与验证门 | 失败时的产品行为 |
| --- | --- | --- | --- |
| 论文搜索 | 可实施 | [arXiv API](https://github.com/arXiv/arxiv-docs/blob/develop/source/help/api/user-manual.md) 可作主来源；以跨学科歧义词、专业术语和稀疏领域构造输入集，检查原词保留、结果匹配与 3–5 篇质量。 | 问清歧义；结果少就展示实际数量和其他学术来源，不凑数。 |
| 校园通勤 | **有条件** | [高德路线规划 2.0](https://lbs.amap.com/api/webservice/guide/api/newroute) 提供步行、骑行、电动车能力，但校内小路、楼门和 POI 质量必须用华东交通大学南昌校区代表起终点实测；动态地图还需 [JavaScript API 的安全配置](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)。 | 地点不明就追问；路径不可核验时说明最近可定位点和局限，不画猜测路线。 |
| 学习资料推荐 | 可实施，元数据质量有条件 | 图书需可核验书目信息；哔哩哔哩公开页面经 Tavily 发现后检查标题、作者、时间和链接可得性，不假定视频正文可读。 | 只推荐已验证条目；数量不足如实说明，不编造书或视频。 |
| 华东交通大学吧 | **有条件** | 公开帖子搜索较易；逐楼回复的公开可得性、分页和访问限制需要样本实测。检查帖子确属目标贴吧。涉及校规再访问学校官方页。 | 不能取得回复时只给帖子链接，明确未读取回复；不总结搜索摘要里没有的楼层内容。 |
| 职业规划 | **有条件** | BOSS 公开职位和企业校招页随时变化。需测试岗位精确匹配、发布时间、薪资原文、城市与样本去重；公开来源不保证足以代表整体市场。 | 只呈现可核验样本及样本范围；样本少时不推断全国薪资。 |
| GitHub 项目推荐 | 可实施 | [GitHub REST API](https://docs.github.com/en/rest/repos/contents) 可核对仓库元数据、README 与必要文件；受[限流](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)和文档缺失影响。用完整产品 idea 与组件 idea 分别测试检索匹配。 | 若只有组件相似项目，清楚写覆盖范围；拿不到代码证据就不声称实现细节。 |
| 书页学习闭环 | 可实施，识别与题目质量需实测 | 图片理解需要通过[百炼精确模型信息](https://help.aliyun.com/zh/model-studio/list-models)与真实调用验证。用跨学科多页、模糊公式、图表和高密度章节测试 OCR、页码定位、预习覆盖、复盘判定。 | 关键处模糊先补拍／补录；不能据缺失书页生成复盘题。 |
| 跨模块上下文与原子画像 | 可实施 | [LangGraph 检查点与存储](https://docs.langchain.com/oss/python/langgraph/persistence)可提供会话状态层；实际历史召回、模型上下文预算、编辑权威和删除墓碑需本项目自己实现与验证。 | 找不到前文时承认不确定；画像提取失败不阻断回复。 |

## 何时调整范围

校园路线实测若无法准确覆盖常用校内通行点，第一版不得把示意线作为真实路线交付；可保留地点澄清与文字路线，并将地图能力留在未通过门的状态。贴吧回复若多数样本受访问限制，该模块仍可提供帖子发现和直达链接，但不能以“回复总结”为默认承诺。职业岗位来源若无法稳定按角色与城市取到足够公开样本，就只做来源清单与岗位技能解读，薪资分析必须给出样本不足。以上收缩都须在对应 ticket 和产品文档中记录，再请用户审查。
