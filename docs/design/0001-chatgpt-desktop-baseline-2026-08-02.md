# ChatGPT 电脑端交互基线参考矩阵（采集日期：2026-08-02）

> 用途：作为 BridGes 桌面模板（Issue 04）的信息架构与交互对照基线。本矩阵只记录**可借鉴的布局与交互行为**；ChatGPT / OpenAI 的商标、Logo、品牌图形、插画、专有文案与像素级视觉细节**禁止复制**（见文末「借鉴与禁区」）。
>
> 后续参考网页会变化，复核时请新建带日期的版本，不要原地修改本文件。

## 采集方法与可达性说明

- 采集日期：2026-08-02（ Asia/Shanghai 本地时间）。
- **匿名页面一手核验成功**：同日读取 `https://chatgpt.com/` 的公开、未登录页面，直接观察到 New chat、Search chats、Images、Chat history、Plugins、Deep research、Settings、Help、登录、注册、Voice 与输入区。这些区域记为「匿名页一手核验」。
- **登录后页面仍有限制**：当前浏览器未开放远程调试连接，无法使用用户登录态核验历史条目溢出菜单、消息操作行和账户弹出菜单的即时 DOM 与像素细节。相关条目只记录长期稳定的交互模式，并明确标成「登录后待人工复核」，不声称本次已经直接观察。
- **官方资料交叉核验**：OpenAI 2026-07-14 官方更新记录说明，Web 端侧栏搜索已统一覆盖聊天、项目、图片和文档，可按内容类型筛选并精确打开结果；该记录用于修正旧版“只搜索聊天历史”的描述。
- **地区与版本差异声明**：OpenAI 按地区、工作区和账户等级灰度功能，模型名、入口名称（如 Plugins、Deep research、Projects）会变化；矩阵中标注「随版本变化」或「登录后待人工复核」的条目不作为像素级硬基线。
- 人工验收要求：具备登录态的验收人应按本矩阵复核登录后行为，并在差异处批注日期；禁止为了填满矩阵而把推测写成观察事实。

## 借鉴与禁区

**借鉴（布局 / 交互层面，允许）**

- 左可折叠侧栏 + 居中限宽消息列 + 底部输入区的三要素骨架；
- 侧栏「新聊天 + 搜索 + 历史列表 + 底部账户」的组织顺序；
- 输入区键位约定（Enter 发送、Shift+Enter 换行、Esc 停止 / 关闭）；
- 助手消息操作行（复制 / 重试 / 反馈 / 朗读）的位置与出现时机；
- 思考摘要「生成时展开、完成折叠为用时摘要」的渐进披露方式；
- 菜单与对话框的键盘约定（方向键遍历、Esc 关闭、焦点归还）。

**禁区（资产与表达层面，禁止复制）**

- ChatGPT、OpenAI 的商标、名称、Logo（含黑色花瓣图形）与任何品牌图形；
- 其页面插画、空态插图、加载动画造型与专有音效；
- 其界面专有文案（问候语、占位提示、按钮措辞、模式名称），模板一律使用 BridGes 自撰中文文案；
- 像素级视觉细节：相同配色值、圆角 / 阴影参数组合、图标路径与组件外观；
- 同上约束适用于 Claude / Anthropic：BridGes 仅借鉴其「温暖、克制、高可读性」的美术方向，不复制其配色值、Logo 与品牌图形。
