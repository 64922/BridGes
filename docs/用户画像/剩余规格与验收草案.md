## 2. 最小逻辑合同方案（待整体确认）

字段是职责合同，不预先规定数据库表或 API 命名；不建设知识图谱、人格或全局能力标签。

| 对象 | 最小内容及规则 |
| --- | --- |
| 事实条目 | 账户、稳定条目 ID、版本、完整正文；主体、关系、对象、适用范围；极性与限定条件不可丢失。事实/偏好/目标/约束为内部用途，不变成页面固定分组 |
| 身份 | 同一账户内以主体/关系/对象/范围判定同一事实；单值属性变化另保留属性槽及替代关系。年级和专业不同槽；考研和六级不同目标；“喜欢 Python”和“正在学 Python”不同关系。语义相似度只提供候选，不能单独裁决覆盖或恢复 |
| 证据 | 来源会话/消息 ID、消息版本、精确区间与原话、消息时间与时区；每个候选均能核对主体、关系、否定、条件及时间。多个片段共同支撑时保留全部引用；助手或材料不能独立证明用户事实 |
| 时间与范围 | 来源明示的起止时间、原时间表达及锚点、跨任务/领域/任务范围；未明示期限标为未知，不能编造日期；当前任务要求留在任务域 |
| 权威与可靠度 | 用户主动编辑/明确控制的权威与自动提取证据可靠度分开。普通自动提取无论时间先后都不能覆盖手动编辑；明确纠正走独立权威操作，版本检查另用于阻止迟到任务覆盖较新操作。低可靠度或证据不足不进入有效切片；模型置信度不是正确概率 |
| 生命周期 | 最小基础状态为活动、被替代、过期、删除；目标再携带暂停/完成标记。暂停/完成停止作为当前目标使用，恢复与续期规则见决策表；被替代记录定位新版本，删除保留必要抑制凭据 |
| 冲突 | 单独记录冲突组、相互矛盾的版本及各自证据；冲突处理待确认，不假定“最新自动记录胜出” |
| 撤回与恢复 | 撤回对象、关系、范围、版本和适用证据；恢复必须有新的明确授权来源，只解除已定位范围，其他撤回继续有效。精确恢复范围待确认 |
| 切片 | 条目 ID/版本、完整事实与条件、适用用途、排除原因、控制/撤回版本、预算及模型/合同版本。整条选择，禁止机械截断；每次实际调用前检查是否因删除、纠正或关闭使用失效 |

“我刚开始学概率”是用户自述基础，不证明具体知识掌握程度；作答题目、评分依据、知识点、时间和误差另留在可追溯知识状态域。两者冲突时不能改写成“数学能力差”，也不能把一道题答对变成全局能力标签。

## 4. 控制操作的不同效果

| 操作 | 记录与取用 | 历史与边界 |
| --- | --- | --- |
| 删除/忘掉某画像 | 指定事实停止取用，旧证据及普通同义新自述不自动恢复；不等于停止全部记录 | 原历史可读/导出；是否抑制回补/摘要待 R07 确认，不能宣称彻底遗忘 |
| 关闭长期画像使用 | 保留记录，阻止后续长期画像取用；自动记录开关独立 | 当前用户原文仍用于理解任务；此开关是否限制历史间接个性化须与 R07 在整体确认时明确 |
| 本轮不使用画像 | 本轮切片为空，后续轮次恢复原使用设置；不删数据、不停止记录 | 当前明示条件仍有效，不是忽略用户本轮自述 |
| 停止自动记录 | 不自动新增/更新；主动记住、编辑、忘掉、删除仍可执行 | 已有画像取用受独立开关控制；异步提交前重新检查停止记录及撤回 |
| 删除聊天原文 | 按现有历史删除合同处理来源及派生物失效，不自动等同于删除全部画像 | 来源无法再展示时如实说明；唯一证据失效的自动事实不继续作为有证据事实使用，用户编辑来源独立。正式接缝需与现有删除/导出合同核对 |

指令对象实质含混时先澄清，不模糊批量删。操作成功或失败如实反馈；生成前成功的管理操作有独立收据，不依赖回答是否成功。

## 5. 时序与恢复方案

用户消息保存 → 本地控制操作提交 → 定位当前任务 → 读取当时已提交的相关有效切片 → 原文与任务材料共同编译 → 调用前校验控制版本与预算 → 回答终态 → 按 R03 决定普通提取资格。

普通提取在事务外调用模型，检查原文支持及身份，再以短事务核对账户、来源版本、记录开关、编辑版本和撤回状态后提交。后台未完成或失败不阻塞回答；同轮不偷偷加入迟到的新事实。同消息重试不能重复增加证据次数。

建议队列以账户、来源消息版本与提取合同版本定位任务，成功收据去重；入队与终态的可恢复接缝避免漏单。恢复沿用原预算消耗与版本锁；版本不兼容不盲目重放。数值预算由评测定，不额外添加画像应用规划模型调用。

正式实施的生命周期检查包括：新增字段版本化、迁移前备份与对账、旧条目无法证明完整身份时不得猜测合并、导出覆盖控制/证据/撤回状态、删除与账户清理覆盖队列/缓存、恢复旧备份不绕过较新撤回。各实际写状态的票交付相应机制，本票只冻结责任与合同，不留给 43 补做。

## 6. 场景演练与验收方案（不是已通过测试）

| 场景步骤 | 预期行为及待确认点 |
| --- | --- |
| 首轮：“我刚开始学概率，希望先举例再讲公式” | 本轮原文即时适配，不等画像；合规自述和偏好分别提取，不推断已掌握知识 |
| 后台尚未完成，新会话问贝叶斯 | 不等待、不虚构新画像已生效；同会话必要原文可用，跨会话暂时缺少该背景 |
| 后台已提交，新会话问贝叶斯 | 相关基础与默认顺序进入切片，先可计算例子再公式；无关跑步爱好不进入 |
| “这次直接给详细推导” | 当前要求覆盖默认顺序和篇幅，不改长期偏好，不删数学条件 |
| 无日期备考目标用于制定计划 | R01：在依赖该目标制定具体计划前确认当前有效性，不编造期限 |
| 暂停 → 继续；到期 → 继续 | R02：前者恢复，后者不凭继续延长；新明确日期产生期限更新及来源 |
| 记住跑步 → 停止自动记录 → 忘掉跑步 | 忘掉仍在生成前执行；后台迟到不得复活；停止记录不挡主动管理 |
| 删除后新普通说“我爱慢跑” | 确定同义不恢复长期记录；不确定候选待 R06；本轮自述的当前适配与长期恢复分开 |
| “重新记住我喜欢跑步” | 新明确来源授权恢复指定事实/范围，不能重放全部旧证据；具体范围待 R06 |
| 回到含跑步原话的旧会话或旧摘要 | 历史可读不等于允许个性化；是否阻断该路径待 R07 |
| 失败/停止，随后成功重试 | 自动提取资格待 R03；已成功明确忘掉持续有效；同消息只计一次证据 |
| 两条矛盾专业自述，无明确纠正 | 未解决属性取用策略待 R05；不得自动覆盖用户编辑或影响其他无冲突事实 |

行为量表建议为每个适用维度 0/1/2：0 错误或造成负作用，1 部分满足，2 满足具体检查点；不适用不计分。检查解释起点、篇幅/顺序、必要限定、计划时间与资源可行性、当前要求优先、澄清必要性。另设账户隔离、删除不复活、禁止无依据/敏感写入、来源准确、预算硬门的通过/失败检查，不能用平均收益抵消失败。

同任务配对比较无画像、正确画像、错误/过期画像，固定模型/提示/合同版本、任务输入和输入预算上界、输出额度；无画像条件从共同上下文移除画像来源，避免旧摘要泄漏污染对照。过期/删除事实测试真实过滤路径；错误但仍活动的事实检验当前纠正和必要澄清，而非声称能自动识别所有错误。盲评实际答案，套话、条数、召回次数不算改善。

成本基线报告前台输入/输出 token、首字等待与总耗时，后台调用/token/耗时、队列延迟、失败/重试、跳过比例、切片实际采用行为。具体样本量、重复次数、阈值、邻近原文量和调用限额先实测再冻结；本票不报告真实模型收益。41 负责画像质量和实际改善，40 负责同预算连续性/成本，39 负责表达盲评。
