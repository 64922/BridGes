# ADR-0035：冻结真实表达材料后独立评分，机器词表仅作诊断

日期：2026-10-06。状态：评测接缝已实现；工单 39 总体验收未通过。

## 背景

工单 39 要求真实模型多轮盲评、三项消融、独立事实/状态/边界硬门。
旧入口在读取人员评分之前重新调用模型，又没有校验集合身份，可能把针对
旧回答的评分用于新回答。只按词表检查不能证明任务完整性或用户边界。

## 决策

- 真实运行和人员评分分为两个步骤。`--review-report` 只读取已冻结报告，
  不创建模型网关；`--submissions` 必须绑定该报告，不能与真实运行混用。
- 匿名模板绑定集合 ID、匿名项及回答摘要，重复评审者、重复投票和未知项
  均拒绝。人数按实际对照及维度统计，原始测量不会被评分覆盖。
- 五维偏好之外，每项每侧六类硬门至少有一次人工核查；候选失败或不确定
  与缺项均阻止放行。机器词表仅作诊断，不能替代语义验收。
- 缺少真实消融、正式路径执行或部署限额证据时继续不放行。冻结报告来源
  的实现版本与当前评分器版本分别保留，不把旧回答声明为修复后新运行。

## 影响与限制

评测套件升级为 1.1.0，机器门 v2，统计放行 v2；量表五维锚点仍为 v2，
新增冻结提交协议 `human-expression-frozen-review-v1`。旧原始报告不改写，
需要用新入口生成模板；不新增数据库状态、不改变产品提示，也不回滚 05/06。

Wilson 区间按票计算，未校正同场景和同人员的相关性；至少一人、十张
决定性票只是当前机制门槛，不能证明总体自然度收益。真实消融、正式路径
执行、部署限额和真人评分仍未完成，必须补齐后再次独立验收。
