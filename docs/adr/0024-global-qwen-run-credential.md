# 正式运行使用唯一的全局百炼运行凭据

BridGes 正式运行的唯一 Qwen 认证来源是全局百炼运行凭据：维护者在启动前通过 `BRIDGES_QWEN_API_KEY` 环境变量或 `BRIDGES_QWEN_API_KEY_FILE` 文件引用配置，两种方式解析为同一 Secret 配置，文件引用优先用于容器或长期部署。`development` 与 `production` 的规范运行入口（`BridGes start`）以及独立启动的 API、后台执行器在缺少、为空或无法读取全局凭据时必须失败关闭，不再启动一个只能登录、不能使用核心能力的降级实例；`test` 环境继续注册确定性适配器，自动测试不依赖真实 Key 或真实网络。启动检查只验证必需值可读取，不发起图片、视频等可能计费的全量真实探测；全局 Key 轮换后必须重启相关服务，首轮整改不引入运行期热更新。

本 ADR 取代 ADR-0005《使用账户级百炼密钥与真实能力探测》：账户级密钥保存、能力探测与重试入口保留为迁移期兼容层，随后续切片（GQ-06/GQ-07）逐步移除，但新实现必须从全局凭据构造供应商客户端。全局凭据改变的是供应商认证来源，不改变账户数据所有权、运行上下文信封、云端最小披露或审计归属：多账户仍分别记录对话、消息、运行锁与云端披露，共享供应商凭据不得造成跨账户上下文或结果召回。
