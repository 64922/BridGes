# 日常陪伴与学习模式按对话持久化

> 历史状态：首条消息后仍可切换模式的条款已由 [ADR-0026](0026-frozen-product-contracts-and-migration-gates.md) 取代；双模式共享聊天系统的原则保留。

BridGes 的日常陪伴和学习能力共用同一聊天系统，每个对话持久化一个当前模式。普通新对话默认日常陪伴，从学习项目中新建的对话默认学习；用户可以在输入区随时切换，消息流记录明确的模式切换事件，且切换只影响后续消息，不重写、重算或重新解释历史回答。日常模式强调自然交流、任务协助和按需检索；学习模式启用学习目标、知识状态、循序教学、理解检查、教学证据充足性门和必要时自动联网。学习项目只组织对话与文件，不引入另一套固定课程工作台；需要上下文隔离时由用户主动新建对话。
