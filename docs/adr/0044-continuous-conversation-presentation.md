# ADR-0044：以连续正文和按需详情替代功能卡片式对话

- 日期：2026-10-17（Asia/Shanghai）
- 状态：accepted（设计与原型已批准），生产页面尚未实施
- 用户依据：逐项确认呈现方向，授权制作原型，最终明确回复「验收通过，你做得很好」
- 详细原则：[对话页面设计](../design/0005-continuous-conversation-and-on-demand-details.md)
- 原型：[独立交互页面](../../.scratch/chat-prototype/dist/index.html)

## 问题

当前消息流在助手正文周围分别渲染上下文说明、检索、教学、模块结果和本轮交付等组件。即使助手正文没有外层气泡，一轮回答仍可能被多个功能卡片切断。用户要求借鉴本地 DeepTutor 项目的对话呈现，并先以原型验收，再记录原则。

## 决策

1. 用户保留气泡，助手以连续正文回答。按问题而不是按调用模块组织内容，必要的地图、表格和媒体随正文出现，保留有实际用途的附件与媒体容器。
2. 正文直接交付完整的核心回答。复杂资料通过引用或文件入口在默认关闭的右侧面板查看，用户主动打开，查看期间可以继续对话。
3. 公开执行过程集中在回答上方的一行进度，生成中也默认折叠；用户主动展开后可查看真实步骤与依据，不展示内部推理。
4. 部分失败、证据不足、等待补充和恢复操作就近呈现，保留已生成内容与已交付结果，不能通过去掉卡片隐藏状态差异。
5. 侧栏、顶部栏、阅读列和输入框共同采用浅色、弱分隔和留白。新对话采用静态欢迎布局，模式入口放在输入区，首条发送后的固定模式合同不变。

## 与现有合同的关系

本决策及设计文档取代旧对话基线中与上述呈现冲突的条款，包括 `docs/design/0001` 的功能建议卡、`0004` 的轮换名言、ADR-0030 的右上角模式入口，以及思考摘要生成时自动展开的规则。旧文档保留为历史记录；详细映射见设计文档。

保留 ADR-0034 的可信状态、渐进交付和真实恢复语义；取消结果卡片这一固定容器，不取消结果投影和证据边界。账户隔离、附件与知识库分域、画像授权、模块调用、固定对话模式以及现行学习合同不因本次视觉改版而变更。

参考项目仅提供呈现机制。本次不引入其其他业务能力，不移植其内部推理展示，也不把原型中的示例数据、模拟成功或内存笔记当作生产能力。

## 验证与实施状态

用户已验收独立交互原型。浏览器检查覆盖过程折叠、并排追问、部分失败重试、停止继续、学习多轮、搜索、附件与多尺寸显示，记录见[原型检查结果](../../.scratch/chat-prototype/verification.json)。这些是静态示例链路的验证，不是生产服务验收。

本次只固化目标设计和原型，不修改业务实现、不迁移数据。后续接入需要保留历史消息与真实状态，完成项目检查、前端构建和真实链路验收；不能仅因本 ADR 已接受就宣称改版上线。呈现回退不应改写历史消息、引用或领域状态。
