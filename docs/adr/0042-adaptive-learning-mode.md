# ADR-0042：以自适应导师替换书页阶段学习模式

- 日期：2026-10-13（Asia/Shanghai）
- 状态：已接受，尚未实现
- 用户依据：本轮 grilling 十五项选择及最终回复「定稿」
- 详细合同：[学习模式重设计定稿](../../.scratch/learning-mode-redesign/PRD.md)

## 决策与原因

学习模式改为面向学习者本人的自适应启发式导师。问题、题目、目标和资料均可启动，资料可选；导师主动带学，验证嵌入教学，允许直接讲解、跳过验证和随时暂停。系统性目标的路线和进展跨会话保存，同一对话保持一个当前目标，临时岔题不自动改目标。

以「突破理解难点」作为首要验收旅程。参考 Socratic-Education-System 的导师、学情诊断与教学建议职责，补齐其诊断没有接入后续导师的反馈路径，并适配本项目的个人学习场景。严格不提供答案、教师管理端、每轮串行完整诊断和常驻课堂面板均未采用。

用户补充约束 C01：只参考教学逻辑，不直接复制、搬运或改名移植参考项目代码。提示词、数据合同与实现按本项目合同重新设计，优先复用 BridGes 已有能力，不迁入参考项目的配置或学生档案。

实时导师负责本轮引导与解释；有价值的作答证据触发后台独立诊断，核验结果提交后进入账户级学习档案并影响后续教学；规划在新建目标或需要调整路线时执行。复用现有流式/结构化模型能力、上下文编译、共享执行内核和持久队列，不引入独立模型平台或另一套执行规则。

学习档案由学习领域拥有，附实际作答、提示程度与不确定性，用户可查看、纠正、删除；原子画像保持自身记录与授权边界。用户跳过、阅读或声称懂了不构成掌握证据，单次答对不推断长期掌握。回复提交与必要诊断任务登记原子一致，迟到结果不得覆盖纠正、删除或新版本进展。

基础概念、常规方法和推导可直接使用模型知识教学；论文、时效信息、精确外部数据、争议结论及明确核实要求按需查证。来源限制、真实引用、条件保留和失败不伪造继续适用。界面以聊天为主，目标和知识点简洁可见，路线、进展与诊断依据按需展开，完成小目标自然小结。

## 合同替代边界

| 既有合同 | 本决策实施后的替代 |
| --- | --- |
| ADR-0030、V2 产品/工作流/交互中的照片首轮、同书同节与固定五阶段 | 自由入口、目标驱动教学与按需材料；取消统一书页门禁和固定阶段条。 |
| ADR-0033 学习条款中的固定书页范围、主动进入集中复盘和单次整节总结 | 嵌入式验证、允许跳过、持续目标与自然小结；评价依据前置、实际作答和版本证据原则保留。 |
| ADR-0020 及 ADR-0026 中普遍适用的教学证据门与材料不足即强制联网 | 基础教学允许模型知识；需要核实的结论按需取证，失败保留缺口，不冒充来源。 |
| ADR-0026 及旧术语中的学习使命、学习路径和创建计划即交付第一课时 | 统一使用学习目标、学习路线和实际学习证据，不按回复数或强制课时计算新进展。 |
| ADR-0038 书页批量识别预算 | 不再作为所有学习入口的前置条件；实际需要照片识别时保留有效的数量、预算和关键疑点规则。 |
| 学习诊断作为泛化个人画像的可能解释 | 学习档案独立管理；不产生人格、心理、注意力或整体能力标签，不扩大原子画像授权。 |

本决策不更改日常陪伴三个模块、首条消息后的模式锁定、账户隔离、附件与知识库分域、用户来源限制、密钥管理及桌面运行边界。学习目标跨会话不将现有会话归属的跨轮任务迁移成全局任务。

## 旧模式退出与历史

实施切换后删除旧学习写入和执行路径，所有新入口只使用新流程。旧消息、材料、作答、判定和总结保留只读与导出，不重新评分，也不自动转换为长期掌握。

用户主动续学时创建新模式对话，可选择沿用本人仍可访问的旧材料；生成新会话有权访问的来源引用，不绕过附件边界。旧未完成运行、检查点和重试不能重新启动旧图或套用新节点。历史合同所需只读类型与渲染保留，不成为旧业务兼容层。

上线须验证备份、迁移、导出、账户删除和回滚。回滚不能将新学习对象按旧阶段解释或静默删除。
