# ADR-0039：研究问题驱动的多来源论文发现

日期：2026-10-11。状态：已实施。

## 背景

日常陪伴中的旧论文流程以 arXiv 和固定术语转换为主，难以同时保留研究方法、应用问题和明确条件；预设补搜也不能依据本轮候选的真实缺口调整。旧结果只突出少量推荐，全文链接与本轮实际阅读范围也需要分开表达。

## 决策

- 将完整用户请求、当前有效任务条件和必要的消歧上下文交给登记的研究意图分析器。模型产出研究对象、问题、方法、应用、阅读目的和来源可追溯的检索概念；固定词表不再作为主题理解、翻译或消歧主路径。首次分析失败时停止外部检索，保留请求并提供重试。
- 由已登记的 arXiv、OpenAlex、Crossref 适配器组成首轮来源范围，按领域建议与用户明确指定/排除条件选择最多三个来源。在共享运行预算内并行执行首轮查询；每个来源独立记录实际查询、取得数量和失败状态。外发只含必要的公开研究概念与过滤条件。
- 论文身份只按 DOI、arXiv ID、OpenAlex ID 或来源原生 ID 关联，保留多来源身份与发现路径；不因近似题名而合并。年份、来源、指定论文、类型排除和篇数上限由代码作为硬条件执行。
- 由登记模型依据来源能力提出查询，代码逐概念校验表达归属和来源范围；筛选发现未覆盖概念、证据或候选数量缺口时，依据真实查询、候选、过滤结果与语义证据提出一次补搜，预算允许且查询实质变化才执行。保留之前的有效候选，不静默放宽明确条件。OpenAlex 引用扩展只使用少量相关种子，引用边须能在来源返回的真实引用列表中定位；扩展候选重新经过筛选。
- 普通请求默认重点推荐 5—8 篇，完整候选目标为 20—30 篇；用户明确指定篇数优先，候选不足时如实说明。推荐按直接相关、覆盖部分问题或探索线索呈现，并附需求证据、来源和发现路径。引用量只作发现辅助信号。
- 全文链接与本轮实际读取范围是两个独立字段。存在 PDF 或开放全文链接不表示本轮已读取；方法、实验、局限和复现断言须有实际取得的正文证据。未登记全文读取器时仅交付摘要级结果。
- 保持日常陪伴聊天入口、共享执行内核、任务版本、账户隔离、查询记录、SSE、停止与终态提交合同；不引入独立运行系统或新持久化写路径。
- 同一筛选节点按实际身份、标题和摘要复用语义裁决，只评估新增或改变的材料；失败裁决不无限重试。未经语义与逐字证据核验的候选不充作推荐，无可交付项时明确失败并允许重试。
- 上轮论文序号从当前账户/会话的已核验产物解析；无效引用明确失败，有真实身份才执行后续引用扩展。引用关系图按需展开，保留完整文字列表；无真实边不绘图。
- 配方升级为 `paper-search-recipe-v3`，解析、规划、检索和筛选能力升级为 v2，旧词表产物不能在新运行或恢复中冒充新合同结果。历史消息的读取与导出不受影响。

## 后果

- `docs/workflow/daily-workflows.md` 第 3 节与 `docs/v2/workflows.md` 采用本 ADR 的来源、筛选、反馈、引用和双层结果合同，替代旧的 arXiv 精确词主路径及默认 3—5 篇推荐。
- 论文投影增加候选来源/引用路径和可核对的开放全文链接字段；`openapi.json` 与前端生成类型须从当前 FastAPI 合同重新生成。没有数据库 schema 变化，不需要迁移；历史投影继续按既有合同读取与导出。
- 2—3 个来源提高覆盖机会，也会增加外部调用和部分成功情况；共享预算、来源并行上限、每来源返回上限和一次缺口补搜共同限制调用。60—90 秒仍是待实测校准的设计目标，不是性能承诺。
- 首版优先覆盖国际学术来源，支持中文理解和中文解释；不承诺中文期刊与学位论文完整覆盖。

## 验证

- 行为回归覆盖 CNN、轴承故障诊断、Transformer 交通流预测、小样本图像分类、硬条件、首次意图失败、来源/引用失败、共享预算、真实引用边和并行首轮。
- 前端回归确认全文链接存在时仍如实显示本轮读取范围。
- 独立验收、修复、main 基线失败归因、完整检查、前端构建和真实来源结果以 `.scratch/paper-search-redesign/ACCEPTANCE.md` 为准；实施阶段记录保留于 `HANDOFF.md`。
