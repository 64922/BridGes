# 固定 BridGes 模型与供应商矩阵

BridGes 将核心对话、推理、视觉理解与工具调用固定为 `qwen3.7-plus-2026-05-26`，知识库向量化固定为 `text-embedding-v4`（1024 维），语音转写固定为 `qwen3-asr-flash-2025-09-08`，单条回答朗读固定为 `qwen3-tts-flash-2025-11-27`，图片生成与编辑固定为 `qwen-image-2.0-pro-2026-06-22`，文生视频固定为 `wan2.7-t2v-2026-06-12`，联网搜索固定使用无需密钥的 DuckDuckGo。首版不另设 OCR 或重排模型：文档优先直接提取文本，图片与图表交由核心多模态模型理解，检索采用关键词与向量结果融合。除 DuckDuckGo 外，全部云端智能能力共用当前账户的百炼密钥，并分别执行真实能力探测；用户不能更换模型，失败只重试同一绑定，模型不可用时明确停用对应能力，不得静默降级。
