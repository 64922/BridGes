# ADR-0036：集成放行证据与未知旧运行安全结束

日期：2026-10-06。状态：已实施；发布范围按独立验收报告裁决。

## 背景

工单 43 负责四个改进方向的组合验证。人工表达门未通过时，仅在文档中
声明“不放行”不能阻止生产使用候选规则；只检查报告关键词和测试文件存在
也不能证明行为通过。历史运行没有图版本记录，不足以证明其没有执行过。

## 决策

- 生产 `GlobalWritingPolicyCompiler` 默认关闭候选全局/形态规则，使用
  `global-chat-release-baseline-v1`。明确本轮交流边界、用途画像切片与撤回、
  合同、输出额度和确定性保护继续生效，不能随提示策略回滚撤销。
- 候选评测显式开启；旧完整快照仍按历史/重试合同原样复用，不改写已冻结
  模型回答或伪装成新策略证据。重新放行候选须完成人工硬门与有效样本门，
  重新独立验收并修改生产默认；本票不增加自动开关或新配置面板。
- 日常运行只接受当前图版本；未知 NULL 或不兼容版本稳定安全失败，保留
  运行与事件，明确重试创建当前版本新运行，不直接套用新图恢复旧谱系。
- 覆盖账本仅用于来源/落点对账；机制证据与真实效果证据分开登记。
  放行台账核查冻结评分、配对调用锁、行为断言、预算、真实语义和最终
  外部探针。缺失、损坏或失败时对应范围不放行，不能继承预设开放结论。
- 回滚保留当前 Schema 与新旧数据。先停止全部写入者，备份后回退允许的
  策略/应用路径。单连接只读演练不能代表生产停机；真实备份恢复与历史
  内容核对在隔离目录完成，不能通过清库或恢复退役入口回滚。

## 影响与限制

本票无新数据库状态、无降级迁移、无稳定 API 字段变化。39 候选继续不放行；
40、41、42 仅按各自报告范围开放。小样本方向性、外部不可达/不可判定、
既有全仓失败和生产部署未演练均须披露，不能据合并/推送推断对外上线。
恢复新写或放行候选的前提和命令见
[集成运行说明](../runbooks/integrated-release-and-rollback.md)。
