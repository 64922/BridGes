# 学习模式以证据充足性门触发强制联网

BridGes 按当前对话附件、所属学习项目文件、用户已授权的个人知识库和外部公开来源组织分层检索，本地采用关键词与 `text-embedding-v4` 向量结果融合，并为不同来源保留独立候选配额。学习模式生成正式教学回答前必须检查本地材料能否覆盖教学目标；材料不存在、过时、证据不足或无法完成任务时，即使用户没有明确要求，也必须自动通过 DuckDuckGo、arXiv 或其他已登记公开来源补充知识。联网过程和引用对用户可见，仍不足时明确说明缺口，模型记忆不得冒充来源。该强制自动联网规则不扩展到普通日常陪伴；日常模式只在用户要求、信息具有时效性或事实核查必要时联网。旧证据工作台退出普通用户导航，其有效能力转为消息引用和可展开证据详情。
