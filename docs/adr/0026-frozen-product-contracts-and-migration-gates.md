# 冻结新版产品契约并建立迁移门

> 状态：accepted（2026-08-09）
>
> 本 ADR 是本轮最终产品合同、领域词汇和迁移顺序的权威来源。历史 ADR 不删除；与本 ADR 冲突的条款仅作为历史决策保留，不得继续指导新实现。

## 决策

BridGes 收敛为一个聊天优先产品：登录后的唯一默认入口是 BridGes 主对话，用户只通过自然语言表达意图，系统按当前对话模式和最小必要上下文自动路由能力。产品只有日常陪伴和学习模式。新聊天可以在首条消息提交前选择模式；第一条用户消息提交后，服务端原子锁定模式，任何客户端、重试、恢复、并发请求或直接 API 调用都不能修改它。需要另一种模式时必须新建会话。

本合同同时冻结以下行为：

- 画像默认自动提取。首次启用时只展示一次非交互、不阻断聊天的隐私说明；它不是授权弹窗，也不要求逐条写入通知。只提取学业情况、感兴趣的知识、兴趣爱好和阶段目标，禁止敏感身份、健康、情绪、人格和心理推断。每轮只注入与当前问题、模式和课时相关的最小切片；用户可修改和撤回，撤回后立即停止使用并阻止同一旧证据自动写回。
- 用户扩展和 MCP 管理退出产品。随应用发布的只读内置 SKILL 与内部论文搜索适配器保留，由产品注册和审计，不转化为用户可安装、选择或管理的扩展。
- 全局知识库是唯一文件和图片上传、本地解析、索引与检索来源。聊天附件、学习项目文件和局部知识库退出；历史对象只保留可审计、可导出、可解析的兼容读取，不作为新上传或新检索入口。检索按意图触发，实际使用材料时只展示紧凑引用。
- 人味化分为随主模型调用注入的全局轻量策略，以及用户明确提出文章润色或改写时执行的完整流程。错误、权限、安全拒答、引用、代码、公式、工具状态和精确数据不做二次风格改写，确定性文本不改写。
- 学习证据不足时自动联网搜索。搜索失败、超时或证据仍不足时必须明确返回可重试状态，不得伪造资料、引用或推进教学计划与课时。

## 领域词汇

以下词汇是新实现和文档的统一称谓：

| 术语 | 权威定义 |
| --- | --- |
| 日常陪伴 | 以理解、陪伴和自然交流为主的聊天模式；可按意图调用能力，但不自动变成教学计划。 |
| 学习模式 | 以学习目标、知识状态、教学计划、课时、测验和证据门为约束的教师式聊天模式。 |
| 对话固定模式 | 首条用户消息提交前选择、提交时由服务端锁定的日常陪伴或学习模式；锁定后不可切换。 |
| 全局知识库 | 当前账户唯一的上传、图片解析、索引和本地检索来源；产品界面简称“知识库”。 |
| 四维画像 | 仅包含学业情况、感兴趣的知识、兴趣爱好和阶段目标的自动画像。 |
| 能力路由 | 把用户自然语言意图映射到受控能力注册表的确定性入口；低置信时只追问一个必要澄清问题，计费能力不得因随口提及误触发。 |
| 教学计划 | 由学习目标、画像切片、知识库证据和必要联网证据驱动的持久教学路线；创建计划的同一回复交付第一课时。 |
| 课时 | 一次有效教学回复的可审计进度单位；每次最多推进一个课时，澄清、失败和重试不推进。 |
| 内置 SKILL | 随 BridGes 发布、只读、由维护者登记和审计的能力说明、参考资料与模板；用户不能上传、安装、选择或修改。 |
| 紧凑引用 | 实际采用知识库或公开来源时展示的最小可定位来源信息；不展示独立检索过程卡。 |

以下称谓明确退役：局部知识库、学习项目、任务安排、复习提醒、用户插件/MCP、聊天附件、会话内模式切换和旧九维画像。退役不等于删除账户、会话、历史消息、有效证据、导出能力或迁移审计记录。

## Expand–migrate–contract 迁移合同

迁移按账户隔离、幂等、可重复、可观测和可回滚执行，不把旧数据直接覆盖为新事实。

### 1. Expand：扩展新合同和读能力

- 先发布新 Schema、投影、能力路由和新读适配器；旧对象在兼容期仍可读取和导出。
- 为每个账户创建迁移报告，记录源对象、目标对象、内容哈希、转换结果、跳过原因和审计 ID；报告不得包含密钥或私人正文。
- 新合同的读能力必须先能处理旧项目引用、历史附件引用、旧画像记录、提醒投递历史和旧扩展清单，再切换写路径。
- 此阶段不物理删除旧表、约束、页面或接口；任何新写入仍须明确归属账户和会话。

### 2. Migrate：切换写路径和用户旅程

- 学习项目文件按账户迁入全局知识库，按内容哈希去重；项目对话保留全部消息并解除项目归属，历史项目名称和关联只进迁移审计。
- 旧九维画像只把高置信学业信息、知识兴趣、兴趣爱好和阶段目标迁入四维画像；无法安全映射的记录只读封存并停止注入，敏感推断不得晋升。
- 未来提醒、待发邮件和旧复习任务幂等取消，不转换为教学计划；历史投递按账户保留导出。QQ SMTP 授权码及可用派生凭据幂等清除。
- 用户 SKILL/MCP 立即停用、终止运行、清除会话选择；扩展包正文先隔离为不可执行，清单和审计封存，兼容窗口结束且导出验证后才清理。
- 新客户端只创建固定模式、全局知识库、四维画像、能力路由和聊天教学对象；旧写 API 在兼容窗口内返回稳定的 `410 Gone`、替代路径和中文错误说明。

### 3. Contract：兼容窗口后收缩

只有同时满足以下门禁，才能删除旧接口、表约束、页面和运行时适配器，并让旧路由从 `410 Gone` 收缩为 `404 Not Found`：

1. 新读写合同已部署并至少跨过一个可观测迁移版本。
2. 所有账户的迁移报告、账户隔离、幂等重复运行、部分失败恢复、导出和备份恢复验证通过。
3. 每个退役页面和旧 API 都有稳定路由标识、真实流量计数和探针结果；完整观察窗口内真实调用为零，探针不计入清零。
4. 扩展包隔离、提醒取消、凭据清除和九维画像封存均有可校验的审计证据。
5. 发布负责人确认回滚快照可恢复新合同数据，且没有必要恢复旧用户扩展执行、提醒发送或模式切换写能力。

## 回滚边界

- Expand 阶段失败：停止迁移，保留旧数据和新 staged 结果，修复后从迁移报告继续；旧读路径继续可用。
- Migrate 阶段失败：只回滚未发布的目标投影或写路径，使用账户级备份和审计报告恢复；已确认取消的提醒、已清除的 SMTP 授权码和已停用的扩展不得因回滚重新启用。
- Contract 阶段完成后：不恢复旧页面、旧 API、旧表写约束或用户扩展执行。恢复只能从已验证备份重建新合同数据，历史对象通过只读导出和审计记录追溯。
- 任一阶段都不得删除账户、会话、历史消息、有效证据、数据导出或迁移审计；这些对象是长期有效的审计边界。
