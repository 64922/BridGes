# ADR-0043：以开放事实与反馈闭环替换四分类画像链路

- 日期：2026-10-14（Asia/Shanghai）
- 状态：已接受，尚未实现
- 用户依据：本轮 grilling 逐项确认，补充持续交流闭环要求，并最终确认「我同意你的方案，定稿吧」
- 详细合同：[用户画像与个人记忆重设计定稿](../../.scratch/profile-memory-redesign/PRD.md)

## 决策与原因

用户画像升级为持续了解用户的个人记忆系统，覆盖稳定事实、偏好、经历、重要关系、目标变化和未完成事项，形成记录、调用、回答、反馈、修正的闭环。取消学业、知识兴趣、爱好、阶段目标四分类在提取、存储、更新与召回中的硬限制；内容主题开放、多选且可扩展，不成为保存事实的门槛。

带来源和版本的原子记忆是事实权威；整体画像和近期摘要是可重建视图，进行中事项复用已有领域状态，回答关联实际采用条目及版本。用户编辑和撤回使相关派生视图立即失效，摘要和助手回答不能自证用户事实。

参考 Giftia 的工作记忆和混合检索，参考 PowerContext 的有界证据、已有条目参与提取、增量窗口、版本化快照与并发提交守卫。按本项目边界实现，复用现有模型网关、持久队列、账户、存储、审计和学习领域；不迁入参考项目的情绪档案、故障放行策略或整段覆盖作为权威事实。

长期事实须由用户明确表达支持，允许口语、省略与跨轮理解；行为不自动晋升为长期事实。选择性保留有后续价值的信息，明确记住可保存普通琐事。敏感自述默认不自动长期保存，用户明确要求后按用途保存，不延伸推断；凭据永不进入记忆。指定材料须由用户明确要求用于画像更新，上传或阅读不等于授权。

普通整理在正常回答后异步进行，显式记住、忘掉和纠正当轮处理；跨会话生效以提交成功为准。新旧信息区分纠错、状态变化与并存，无法确定的冲突不用于确定判断，相关时澄清。反馈明确时直接修正受影响回答，仅在有明确长期依据时修改记忆；本次表达要求不改变长期偏好。

页面提供整体概览、进行中事项和可编辑条目，依据按需展开。历史画像回到原始证据核验，补提取允许处理的历史，尊重用户修改、时间锚及删除/禁止记录边界。新链路成为唯一内部写入路径，四维与原子镜像双写退出。

## 合同替代与保留

| 既有合同或实现 | 本决策实施后的解释 |
| --- | --- |
| ADR-0026 的固定四维及当前提取枚举、规则分流和双写 | 全面替换为开放事实；旧四维只作迁移来源，不保留内部兼容写入层。ADR-0032 已批准开放范围，本次落实完整替代链路。 |
| ADR-0030、ADR-0032 的简洁条目列表及禁止类别分组表述 | 扩展为概览＋事项＋条目；允许开放主题筛选，不恢复固定档案槽位或四维门禁。 |
| 将证据等同于规范事实必须逐字存在于当前消息的实现 | 允许跨轮和经明确指定的材料依据；引用精确位置仍须核验，语义支持另行判断。 |
| 敏感内容全部排除的旧实现 | 区分普通学科兴趣、短期情境与敏感自述；明确要求记住才按用途保存敏感自述，继续禁止敏感推断和凭据保存。 |
| ADR-0033 的附件不进入画像限制 | 草稿与默认上传/读取仍不进入画像；明确指定且有访问权、完成解析的材料可按限定目的提取，不改变附件和知识库分域。 |
| ADR-0032 的用户权威、删除抑制、使用控制、最小切片 | 完整保留，并覆盖新概览、事项投影、索引和历史重整；旧来源不能恢复撤回事实。 |
| ADR-0042 的学习档案与学习目标 | 由学习领域独立拥有；画像按用途引用，不以自述或行为替代作答证据，不创建第二套掌握或目标状态。 |

账户隔离、固定聊天模式、日常陪伴保留模块、密钥管理、历史可读和导出等其他合同不变。用户所说的「记录」不代表把全部聊天或完整私人材料作为长期事实上传。

## 迁移与验证

迁移前核对权威库、备份和恢复、只读预览；分批记录进度和跳过原因，校验来源、用户编辑、撤回和并发版本。旧运行与重试不得重启旧写入。回滚保留新对象和撤回记录，不能强塞回四维或静默丢弃。外部 API 的兼容义务与内部旧路径删除分别处理。

用户没有提供现成失败片段。定稿以实际代码检查、已执行的合成内存探针与 PRD 的 T01–T20 合成旅程建立基线。未来须分别完成确定性测试、真实模型提取/修订评测及回答效果对比；当前没有真实模型效果结论。硬边界失败不能用平均收益抵消，数值门槛实测后在正式评测前冻结。
