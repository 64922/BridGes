# 用户扩展采用声明式 SKILL 与显式授权 MCP

BridGes 将随应用发布且只读的内置 SKILL 视为受信任扩展，但仍要求账户授权、最小数据输入、版本记录和运行审计。用户上传的 SKILL 在首版仅允许 `SKILL.md`、静态参考资料、模板和资源文件，安装检查拒绝脚本、可执行文件、符号链接及越界路径。MCP 服务默认关闭，按账户和固定版本安装，在独立受限进程中运行；安装前必须声明网络域名、文件读写目录、外部命令和敏感操作，未声明权限一律拒绝，首次敏感操作再次确认。任何扩展都不得直接读取百炼密钥、QQ SMTP 授权码或完整个人保险库，只能接收当前任务明确授权的最小数据切片，并必须支持权限预览、启用、停用、卸载与审计记录。
