# 完整画像事实、独立控制与历史个性化抑制

> 状态：accepted（规格与交互合同，2026-09-30）；后续业务实现由各画像票验收。
>
> 用户保留 D01–D09，逐项回答 R01–R08，最后回复“整体确认，定稿规格并完成 02（推荐）”。原回答见 [讨论记录](../用户画像/讨论记录.md)，完整合同为 [profile-contract-v1](../用户画像/画像规格与验收合同.md)。

## 决策

画像记录用户明确表达且可复用的事实、回答偏好、目标与约束；每条保留完整含义、主体/关系/对象/范围身份、精确原话依据、期限与生命周期。行为只作待验证观察，不进入确定事实；自述基础与有答题证据的知识状态分开，禁止人格、心理或全局能力标签。用户编辑权威独立于自动证据可靠度，普通自动提取不能覆盖手动编辑。

可并行目标默认并存，明确暂停、完成、替代或恢复才改变对应状态；期限以来源消息为锚。无期限目标/约束相关时参考，依赖它制定具体计划前确认当前有效性，不设统一 TTL。“继续”不延长明确旧期限，续期需要新日期。争议事实保留各自证据，不用作确定事实，仅影响当前任务时澄清。

明确记住、忘掉与纠正在生成前受控提交，停止自动记录不阻止主动管理。普通自然表达由语义模型提出候选，经精确证据和边界检查后异步提交；只在回答正常完成后入队，失败/停止不提取，成功重试幂等处理。提取只补必要邻近原文消歧，纯无自述消息可跳过，混合内容逐片段检查。后台未完成不阻塞回答，新自述从本轮原文适配，跨会话可能延迟。

删除抑制确定同义新提及和旧证据；恢复仅限明确指定事实与范围，用新的明确原话授权，不重放其他历史；不确定近义候选暂缓写入/长期使用，仅必要时澄清。忘掉同时抑制旧原文、摘要、缓存与任务派生信息中对应事实的个性化使用；原历史可读/导出，明确查看历史可按该用途展示，但不恢复长期记录。已发给模型的内容无法收回，不能宣称彻底遗忘。

自动记录、长期使用和本轮不用分开控制。关闭长期使用或本轮不用期间也停用历史个人信息的间接个性化；任务续接必要前文、来源、明示条件和本轮新自述仍适用。重新开启可使用未删除且有效的信息，不解除撤回。

页面继续无固定类别逐条显示，修改/删除始终可见，按需展开原话依据、范围和有效期；不增加逐条写入确认。画像按目的选择完整切片，当前要求优先，事实结论与必要限定保持准确。无画像/正确画像/错误或过期画像配对检查实际回答行为，可靠性硬门不能被平均收益抵消；数值预算和质量阈值先实测。

## 对既有合同的替代

- 替代 ADR-0026 的固定四维提取范围及旧画像展示限制，保留禁止敏感推断、账户隔离、最小披露与迁移门。四维记录只作旧数据迁移来源。
- 扩展 [ADR-0030](0030-v2-campus-assistant-and-approved-desktop-interaction.md) 的“每行仅修改与删除”为简洁列表加按需依据，明确“下一轮生效”须以后台已提交为前提。
- 补齐旧证据防复活为指定事实/范围的语义撤回及历史取用抑制；补齐使用控制为跨来源间接个性化限制，不把历史可读等同于仍可用于个性化。
- [上下文改进方案](../上下文工程/改进方案.md)此前没有决定的新删除语义由本次 R07/R08 明确；原历史、任务续接、账户隔离、固定模式和附件/知识库分域合同保留。其他工作流、能力和退役行为不受本 ADR 改动。

## 实施与验收责任

02 只定稿规格，没有新增存储状态或运行接口。07 负责控制，16 负责身份/状态，17 负责证据/异步，18 负责期限/撤回和恢复，19 负责用途切片，20 负责依据展示；22、29、41 消费对应合同。11/13 的原文回补和摘要接缝由 18 的撤回治理配合接入，不能只实现画像表删除。

各实际新增持久状态的票必须同时完成版本化迁移、备份/导出、删除、审计与失败恢复；不得留给 43 补做。数值参数、模型/提示/Schema 实际版本与真实模型质量分别按实施及 39–41 评测票交付。02 的确认仅解除它自身的规格依赖，其他前置须实际验收后才能实施。
