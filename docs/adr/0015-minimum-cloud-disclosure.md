# 云端能力只接收最小任务上下文

> 历史状态：本 ADR 的最小上下文、脱敏查询和披露审计仍有效；发送前由用户逐次关闭画像或知识库的交互开关已由 [ADR-0026](0026-frozen-product-contracts-and-migration-gates.md) 取代。

BridGes 调用 Qwen 时只发送当前问题、必要的可见会话片段、用户已授权的最小画像或记忆切片、相关知识库段落和必要工具结果，不上传完整画像、完整聊天历史、整个项目目录或个人保险库。界面显示本次使用的材料与画像类别，并允许用户在发送前关闭画像或知识库使用。DuckDuckGo 只接收在本地提炼并去除身份与私人内容的搜索关键词，搜索结果返回本地后才与私人上下文组合。密码、百炼密钥、QQ SMTP 授权码和内部加密密钥永不进入模型或搜索请求；本地云端披露审计默认只保存能力、时间、数据类别、来源对象 ID、授权快照和响应状态，不额外复制完整敏感请求正文。
