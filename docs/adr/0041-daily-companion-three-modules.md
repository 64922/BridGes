# ADR-0041：日常陪伴收敛为三个任务模块

- 日期：2026-10-13
- 状态：已接受
- 来源：用户要求取消学习资料推荐、职业规划、GitHub 项目推荐模块。

## 决策

日常陪伴保留普通聊天，以及论文搜索（`paper`）、校园通勤（`commute`）、贴吧信息搜集（`tieba`）三个任务模块。学习模式不受此次范围调整影响。

学习资料推荐（`resources`）、职业规划（`career`）、GitHub 项目推荐（`github`）退出当前产品的菜单、自然语言模块路由、建议生成、生产服务装配和父图派发。包含这些模块的跨模块组合也退出生产登记；当前三个模块没有登记组合，多个明确请求先澄清执行顺序。

新消息、首轮和建议启动请求只接受三个保留模块。内部执行白名单同样收紧，避免直接服务调用或旧运行快照绕过请求校验。日常父图版本升级为 `daily-parent-v3`，旧版本运行按已有版本守卫安全结束；普通聊天及保留模块可在新版本重试。

## 历史与存储

不删除既有消息、结果投影和数据库字段。历史模块标识继续用于读取已有消息，不代表模块可启动。退役模块的历史建议不再展示启动按钮，澄清不恢复输入区选择，历史轮次不允许重试为新运行。无需修改数据库 schema 或执行数据搬迁。

保留历史契约与读取所需领域类型，禁止借这些类型重新装配或派发退役模块。若未来决定永久清除历史数据，需要另行约定导出与删除范围。

## 文档效力

本决策覆盖 ADR-0030、ADR-0033 和 V2 设计基线中关于六个日常模块及其组合的范围约定；这些文档的其他有效约束继续适用。当前使用说明以根目录 README 与本决策为准。
