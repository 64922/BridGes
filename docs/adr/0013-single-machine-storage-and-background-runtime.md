# 首版采用单机权威存储与本地后台运行时

> 历史状态：本 ADR 的单机 SQLite、对象库和受监督后台原则保留；学习项目、提醒和扩展管理的现行数据域已由 [ADR-0026](0026-frozen-product-contracts-and-migration-gates.md) 取代。

BridGes 以 SQLite 作为账户、对话、四维画像、全局知识库、教学计划、迁移审计和运行记录的权威数据库，以账户隔离的加密本地对象库保存上传材料与生成媒体，并以 SQLite FTS 和版本化向量索引共同支持知识库检索。耗时生成、索引、迁移和清理任务由同一安装内的独立受监督后台执行器处理；提醒调度、用户扩展执行和聊天附件写入均属退役兼容面，不得产生新业务数据。统一 CLI 和容器入口负责迁移、启动、健康检查与停止。源码 Conda/`.venv` 部署和 Docker/Podman 部署必须共享同一数据合同；首版不引入 PostgreSQL、Redis、Temporal、S3 或 Kubernetes，也不承诺多机高可用和水平扩容。
