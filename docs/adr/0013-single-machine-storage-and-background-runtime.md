# 首版采用单机权威存储与本地后台运行时

BridGes 首版以 SQLite 作为账户、对话、画像、学习项目、提醒、权限和运行记录的权威数据库，以账户隔离的加密本地对象库保存上传材料与生成媒体，并以 SQLite FTS 和版本化向量索引共同支持本地知识库检索。耗时生成、索引、QQ 邮件提醒和清理任务由同一安装内的独立受监督后台执行器与调度器处理，统一 CLI 和容器入口负责迁移、启动、健康检查与停止。源码 Conda/`.venv` 部署和 Docker/Podman 部署必须共享同一数据合同；首版不引入 PostgreSQL、Redis、Temporal、S3 或 Kubernetes，也不承诺多机高可用和水平扩容。
