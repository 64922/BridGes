# 使用账户级百炼密钥与真实能力探测

> **状态：已废弃（superseded）** — 被 [ADR-0024](./0024-global-qwen-run-credential.md) 取代。
> 全局百炼运行凭据是正式运行的唯一 Qwen 认证来源。账户级密钥保存、能力
> 探测与重试入口已随 GQ-06（用户面与公开合同删除）与 GQ-07（服务、探测
> 状态与历史秘密整体清退）移除；既有安装的旧秘密由启动时的一次性、幂等
> 清退收敛，历史审计记录中的 `key_save`/`key_delete`/`key_probe` 事件保留
> 作旧合同遗留证据。
> 本 ADR 保留作历史决策记录，新实现不再采用账户级密钥。

BridGes 的百炼 API Key 只能由登录用户在界面中为当前账户配置：原生运行使用操作系统凭据库，Docker 使用由应用自动生成主密钥保护的加密凭据卷，均不要求 `.env`。缺少或验证失败的密钥只阻断 AI 能力，不阻断登录、密钥设置、资料管理和数据导出；保存密钥后以非用户数据探测每项固定模型能力并显示真实状态，生产环境不得注册会伪装成功的 Stub。
