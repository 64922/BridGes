# 在当前仓库中纵向替换旧产品实现

BridGes 不从空仓库重写，也不继续扩展 Science Companion 的工作台产品模型。项目保留现有 Next.js、React、TypeScript 工程配置、设计令牌、无障碍组件、Playwright 框架、API 类型和经修复的 HttpOnly Cookie 登录骨架；重建聊天、持久化、模型调用、知识库、画像、提醒、媒体与扩展领域，并移除生产 Stub、进程内持久化、硬编码状态和占位页面。首个纵向切片必须端到端完成注册或登录、新建对话、流式回答、保存消息和恢复对话（初版切片曾包含账户级百炼密钥配置步骤，已随全局百炼运行凭据整改 GQ-06/GQ-07 移除）；其后按可验收切片接入其他能力。旧路由在对应替代能力通过功能、安全、账户隔离和回归测试后退出，避免无保护的一次性重写，也避免旧信息架构长期并存。
