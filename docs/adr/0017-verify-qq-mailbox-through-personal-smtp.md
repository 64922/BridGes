# QQ 邮箱通过个人 SMTP 自发自收验证

> 历史状态：提醒能力的 SMTP 验证条款已由 [ADR-0026](0026-frozen-product-contracts-and-migration-gates.md) 取代；本文件仅保留历史决策记录。

BridGes 注册时只校验 QQ 邮箱符合 `纯数字@qq.com` 且全局唯一，不发送邮箱验证码，也不配置应用级公共 SMTP 凭据。用户登录后为自己的账户配置 QQ SMTP 授权码，并由系统向同一 QQ 邮箱发送测试邮件；测试成功后才标记邮箱控制权已验证并允许启用邮件提醒。未验证邮箱不影响本地登录、聊天、资料管理和导出，SMTP 授权码不得作为登录凭据或密码恢复凭据。
