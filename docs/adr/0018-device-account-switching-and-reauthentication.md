# 同设备账户使用独立会话并支持有效期内切换

> 适用边界：账户会话切换和敏感操作再认证原则保留；提醒与 QQ SMTP 凭据条款已由 [ADR-0026](0026-frozen-product-contracts-and-migration-gates.md) 取代。

BridGes 在同一设备维护由用户逐个登录建立的独立账户会话集，账户切换器显示用户名和脱敏 QQ 邮箱；目标会话有效时允许一键切换，过期、退出或撤销后必须重新输入该账户密码。切换只改变活动账户，不得合并或共享对话、画像、全局知识库、教学计划和运行记录；百炼调用凭据为全局运行凭据（ADR-0024），不随账户切换而改变。“退出当前账户”只移除当前会话，同时提供退出此设备全部账户。导出或删除数据等敏感操作必须通过当前账户的近期密码再认证（账户级百炼密钥已随 GQ-06/GQ-07 移除，不再存在对应再认证场景）。
