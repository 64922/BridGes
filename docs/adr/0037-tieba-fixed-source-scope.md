# ADR-0037：贴吧检索使用固定来源范围

状态：accepted（2026-10-07）。

用户报告“我想了解国庆节假期的讨论”被拆成“假期、解国庆节、讨论”，搜索返回视频、百科等站外结果，官方摘录混入导航，页面又重复展示完整证据与审计信息。

固定来源为[华东交通大学吧](https://tieba.baidu.com/f?kw=%E5%8D%8E%E4%B8%9C%E4%BA%A4%E9%80%9A%E5%A4%A7%E5%AD%A6)和 `ecjtu.edu.cn`（包含学校子域）。主查询与备用查询都保留站点限制；备用查询只减少泛化条件，保留事件、地点等主题。通用搜索客户端把 `site:` 操作符落实为 Tavily 的 `include_domains` 限制（[官方请求合同](https://docs.tavily.com/documentation/api-reference/endpoint/search)），并在 Extract 前再次核对结果主机与路径，避免提供方越界结果触发站外读取。贴吧适配器也核对返回 URL，并使用新的查询缓存身份；节点能力版本随解析、计划与取证规则升级，防止恢复时复用旧语义产物。

吧名继续由真实读取的帖子页面确认，固定域名不代表确认吧名；已读标题或楼层还须与本轮主题相关，目标贴吧里的择校帖不能成为国庆讨论证据。未读页面、访问受限和空结果仍按原证据合同呈现，不以搜索摘要编造讨论。官方摘录优先读取 `vsb_content`、`v_news_content` 等通知正文容器，保留“安排如下”之后最多十二段、1200 字的安排。问题未指定年份时不补造年份；已有目标年份的假期通知时不混入其他已注明年份的通知，历史通知不标为当前适用。

真实取证确认：公开 HTTP 入口返回 403 安全验证，真实 Tavily 国庆／十一查询未召回相关讨论。用户日常浏览器可以浏览，但 Codex 扩展在 Edge、Chrome、重启后均连接失败。用户明确授权改用 Playwright 专用 Chrome，会话目录按认证 BridGes 账户的 SHA-256 隔离；不用个人 Chrome 配置，不导出 Cookie，不自动处理安全验证。人工通过滑块后，未登录也可浏览部分帖子；登录后吧内搜索和更多回复可用。

生产取证优先进入固定吧的原生搜索 `/f/search/res?kw=华东交通大学&qw=主题词`，官方检索仍走独立官方域名路径。浏览器失败时记录稳定错误，再尝试限站公开索引；取消和预算耗尽不追加调用。搜索结果先作为候选，实际渲染帖子正文后才能确认归属与主题；新版滚动回复只记录实际加载部分，不捏造楼层和总页数。2026-10-07 的真实原句验收取得五个候选，实际确认三个相关帖子，见 `browser-live.json`。

浏览器在独立子进程中运行，复用数据目录建议锁避免 API 与聊天执行进程同时打开同一账户目录。最多四个活动进程；读取有截止时间，取消或关闭时清理本运行时创建的进程树。人工窗口十分钟到期或点击完成后关闭并保存会话。认证 API 只提供打开和完成，不接受账户、地址、脚本或凭据参数；目录路径、上游异常和会话 URL 不进入公开响应。依赖 Playwright 与本地 Chrome，缺失时给出可恢复错误；不会静默下载浏览器。未来贴吧结构改变或登录失效时需重新验证 DOM 与会话，不能保证永远免验证。

官方通知与贴吧讨论独立交付：有适用的已核实官方通知但无帖子时，回合结果为部分交付，明确缺少讨论。图书馆通知仅证明图书馆开放安排，不能写成学校整体放假安排。未召回不代表吧内没有讨论。

结果卡片是聊天页面的唯一贴吧证据展示。每帖先显示最多三条、每条160字的原文摘录，完整已采集原文和审计默认折叠；部分回复范围提示始终显示。帖子与官方摘录分开呈现；持久化正文保留用于复制、导出和朗读。旧消息继续按原投影解释，旧运行恢复遵守现有能力版本与输入键，不改写历史证据。

验证记录见 [.scratch/tieba-search-scope/issues/01-fix-search-scope.md](../../.scratch/tieba-search-scope/issues/01-fix-search-scope.md)。该改动无需数据库迁移；回滚时一并回滚查询缓存身份与节点能力版本。
