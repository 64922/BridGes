# Issue 07：重建普通聊天轻量策略

Status: resolved

Type: task

Priority: P0

Parent: [BridGes 有人味表达改进方案](../README.md)

User stories: US-01、US-06、US-07

## What to build

在不增加模型调用的前提下，重建普通聊天的全局轻量有人味策略。策略编译器根据当前轮意图、固定对话模式、回答形态和允许的最小画像切片，只选择少量正向行为规则；不再把文章清洗规则、全量方法 ID 或通用黑名单注入每次回答。

新的默认声音是自然、直接、克制：先完成用户此刻的请求；简单问题简单回答；共情必须带来具体判断或帮助；没有真实下一步时直接停下。日常陪伴和学习模式保持不同任务边界，但学习模式也不强制每轮变成有标题、目标、例子、理解检查和继续邀请的完整课时。

## 已验证现状与根因摘要

- 当前全局策略把共享 `CHAT_METHOD_RULES` 与模式/画像信息一起注入；规则量大且抽象，本轮最重要的表达取舍不突出。
- companion 与 study 提示都以“自然、温暖、完整”等通用形容词约束，无法区分空洞赞同和有信息的共情。
- 学习模式合同倾向完整解释和继续邀请，可能与“简单问题简单回答、无必要尾句”冲突。
- 现有聊天测试验证策略快照、注入和保护区恢复，没有真实聊天自然度评测。
- 文章规则中的“去掉助手协作痕迹”不能全局套到聊天；聊天需要保留有信息的承接、必要礼貌和真实追问。

## 非目标

- 不给普通聊天增加第二次生成或生成后模型改写。
- 不取消安全拒答、工具状态、错误、引用、代码、公式、JSON 和精确数据的确定性合同。
- 不新增情绪、人格、心理或亲密度画像。
- 不禁止一切标题、列表、提问、礼貌或共情。
- 不让画像改变事实判断、证据标准或安全边界。

## Acceptance criteria

- [ ] 聊天策略只消费 Issue 03 的版本化表达任务契约、固定 conversation mode 和允许的最小画像切片；旧任务重试继续复用原策略快照。
- [ ] 建立原创回答形态路由，至少覆盖短答、解释、建议、纠错/不同意、情绪承接、澄清、工具结果说明、错误/拒答和学习课时；低置信时使用紧凑默认，不扩成长文。
- [ ] 每轮只编译当前形态的少量高优先级正向规则，建议上限 6—10 条；渲染结果不包含文章体裁规则、内部方法 ID 或全量禁词表。
- [ ] 默认规则明确：答案先行；简单问题允许一两句；只有结构确实帮助扫描时才使用标题或列表；没有真实下一步时不追加礼貌性尾句。
- [ ] 情绪承接只能引用当前对话已出现的信息，且必须带来帮助、判断或下一步；不得推测情绪、人格、经历、亲密关系，不复述用户原句来表演理解。
- [ ] 只有需要用户选择、补充关键材料或确认高影响操作时才提出一个具体问题；不得固定追加“如果你愿意我还可以”。
- [ ] 不同意、纠错、不确定性、失败和拒答直接说明依据与边界，不使用居高临下、客服安抚或励志包装。
- [ ] 学习模式保留教学计划、课时和证据门等领域合同；但普通短问不因模式自动加入目标、先修、检查题、练习和继续邀请。只有真实课时任务才加载教学结构。
- [ ] 画像只可调整用户明确表达的称呼、篇幅、专业程度和表达偏好；画像缺失、撤回或不可用时使用克制默认，不推断补齐。
- [ ] 代码、公式、JSON、URL、引用、工具原始结果、确定性错误、权限/安全拒答和精确数据继续由现有保护边界恢复；新增策略不得改写协议字段。
- [ ] 普通聊天模型调用次数保持一次；策略编译、保护恢复或审计异常不得触发隐式第二次生成。
- [ ] 新策略绑定版本、形态、模式、条目数量和降级原因；审计不保存系统提示、画像正文或私人聊天正文。

## Test plan

1. 为每种回答形态做编译快照，验证规则数量、优先级和不包含文章方法块。
2. 建立真实生成 development cases：一句事实问答、概念解释、需要不同意的错误判断、情绪低落但未求建议、需要澄清、工具失败、安全拒答和正式学习课时。
3. 对每案检查标题/列表必要性、客服尾句、假共情、无关比喻、过度教学和真实下一问；保留原始输出供 Issue 09/10 盲评。
4. 用当前对话明确表达的称呼/篇幅/专业程度验证有限个性化；用撤回、空画像和无关历史验证不泄漏、不主动翻旧账。
5. 用代码、公式、URL、引用、JSON、工具结果和确定性错误验证保护区逐字保持。
6. 用调用计数适配器断言所有普通聊天路径只有一次模型生成，重试沿用快照。
7. 运行日常陪伴、学习计划、证据门、工具和流式聊天回归，确保表达策略不改变业务终态。

## Observability & rollback

- 指标包含策略版本、回答形态、模式、规则数、降级率、回答长度分布、标题/列表率、澄清率和下一问率；不记录正文。
- 真实质量由 Issue 09—11 的聊天盲评判断，自动短语命中只作诊断。
- 用全局策略版本开关灰度。回滚恢复上一版本与旧快照；业务合同、保护恢复和单次调用边界保持不变。
