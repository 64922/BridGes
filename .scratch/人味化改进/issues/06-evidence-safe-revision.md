# Issue 06：实现证据安全修订模式

Status: ready-for-agent

Type: task

Priority: P0

Parent: [BridGes 有人味表达改进方案](../README.md)

User stories: US-02、US-04、US-05

## What to build

为科研、技术和其他高事实密度文章增加显式“证据安全修订”模式。默认普通人味化只改善表达并提示证据风险，不静默把“证明”改成“支持”、把因果改成相关或补入原文没有的限制。只有用户明确选择该模式时，系统才可根据来源账本降低结论强度，并为每项实质变化保存可定位的前后差异、证据依据和原因。

该模式是文章 profile 上的证据安全叠加层，不是另一套通用 humanizer。它复用表达任务契约、来源账本、文章首稿和表达审稿，不复制 `scientific-humanization` 的文本、结构或示例。

## 已验证现状与根因摘要

- 现有事实锁已尝试保护限定词和结论强度，但普通生成提示与体裁规则仍可能鼓励加入“结果显示、局限、下一步”等原文没有的信息。
- 科研参考项目最有价值的是区分做了什么、看到什么、能说明什么和还不能说明什么；但主动降低结论强度已经改变语义，不能伪装成纯风格改写。
- 用户已确认：默认不静默改结论，证据风险单独提示；只有证据安全修订才允许改变，并展示前后差异。
- 本地 `scientific-humanization` 快照没有许可证，任何实现和夹具必须原创。

## 非目标

- 不替代同行评审、统计复核或法律/医学专业判断。
- 不在没有来源或方法信息时推断研究一定“显著”或“不显著”。
- 不自动新增样本量、统计方法、实验条件、局限、未来工作或引用。
- 不改写精确引语中的原作者结论。
- 不把证据风险提示隐藏在普通风格修改清单中。

## Acceptance criteria

- [ ] 表达任务契约明确区分默认 `preserve_claim` 与用户授权的 `evidence_safe_revision`；UI/API/自然语言路由不得因体裁是科研就自动打开后者。
- [ ] 建立原创 claim-strength 分类，至少覆盖观察、相关、预测、比较、机制、因果、显著性、泛化和真实场景有效性；每项带来源位置和当前强度。
- [ ] 默认模式检测到“相关写成因果、无检验写显著、拟合/聚类/消融宣称机制、预测准确等同因果或真实场景有效”等风险时，只生成独立风险项，候选正文保持原结论语义。
- [ ] 证据安全修订模式只能消费来源账本已有方法、统计、数据和限定信息；材料只支持较弱结论时可以降级措辞，但不得新增论据或补写研究局限。
- [ ] 每个结论强度变化记录原文 span、改后 span、变化类型、来源条目、理由和是否需要用户确认；确定性 diff 可重建，模型自述不能代替差异证据。
- [ ] 数字、单位、日期、专名、模型/数据集、样本、变量、实验条件、图表编号、公式、引语和引用关系保持 protected；授权改结论不等于授权改这些项。
- [ ] 证据不足、来源冲突或无法判定时保持原文并返回稳定的 `needs_user_confirmation`/风险状态，不进入人工审稿队列，也不为了让文本“更科学”自动添加保守套话。
- [ ] 证据风险和实质性 claim 变化以稳定结构投影给 Issue 08；普通无风险文章不生成空洞的固定“事实核查总结”。
- [ ] 新增文档和净室记录明确：实现不复制无许可参考项目，目标是证据边界而非规避检测或冒充专家。
- [ ] 高风险体裁的来源硬门失败仍阻止交付，任何风格评分或系统裁判多数票都不能放行。

## Test plan

1. 为相关/因果、统计显著性、机制、预测、泛化和真实场景有效性建立成对夹具，分别验证默认提示与授权修订。
2. 用“结果证明”“显著提升”但无方法信息的原文验证默认保持正文并告警，授权模式也因材料不足返回 `needs_user_confirmation` 或稳定风险状态。
3. 用有明确相关证据、无因果设计的材料验证授权模式可将因果降级为相关，并生成准确 diff。
4. 构造含数字、公式、模型、数据集、图表编号、引语和引用的段落，验证修订只触及 claim span。
5. 构造模型试图添加样本局限、统计方法、未来工作和新引用的结果，验证来源硬门阻止。
6. 运行普通邮件、观点文和聊天回归，证明证据安全层不误触发或扩散到普通表面。

## Observability & rollback

- 记录模式启用率、claim 风险类型、保持/降级/用户确认数量、无来源阻断数和 protected span 冲突，不记录科研正文或未公开数据。
- 单独观察用户选择该模式后的撤回、失败与用户确认率，避免把高告警率误当成质量提升。
- 以文章 profile 能力开关灰度。回滚关闭证据安全修订，只保留默认保持结论和风险提示；历史差异记录继续可审计。
