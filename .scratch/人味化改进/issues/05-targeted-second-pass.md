# Issue 05：增加文章定向二次修订

Status: ready-for-agent

Type: task

Priority: P0

Parent: [BridGes 有人味表达改进方案](../README.md)

User stories: US-02、US-05、US-07

## What to build

在文章首稿完成保真检查和表达审稿后，只有存在明确、可修复问题时才追加一次定向模型修订。修订调用接收原文、来源账本、首稿和带位置的问题清单，只修指定问题；不重新注入全量规则，不扩张事实，不循环调用。修订后重新执行同一保真硬门和表达审稿，再决定交付、带警告交付或停止交付。

该行为改变了 ADR-0011 中“自然语言文章路径只做一次结构化生成”的已接受决策。实现代码前必须新增 ADR 或正式增量决策，说明文章最多两次、聊天仍一次、触发条件、预算、终态和回滚；不得以普通重试名义静默引入第二次调用。

## 已验证现状与根因摘要

- 自然语言文章路由当前只生成一次；质量检查不再调用模型。旧显式 SKILL 路径在特定软失败下可做一次定向修复，行为不一致。
- 旧体裁正则即使发现问题，也可能要求模型补入更多模板元素；Issue 04 将提供带位置和原因的原创表达审稿报告。
- 无条件双调用会增加成本和延迟，并可能把已经自然的稿件改坏；缺少循环上限还会造成不可预测的预算。
- 普通聊天的冻结合同要求沿唯一主模型调用注入轻量策略，不能把文章修订扩展到聊天。

## 非目标

- 不给普通聊天增加第二次写作调用。
- 不执行无限 critique/rewrite 循环。
- 不因单个软词表命中、标点或低置信节奏信号触发修订。
- 不把模型提供方重试、协议重试和风格修订混为同一个计数。
- 不在修订失败时交付违反事实锁的候选。

## Acceptance criteria

- [ ] 在实现前提交并接受 ADR，明确取代 ADR-0011 的单次文章生成条款；ADR 保留聊天单次调用、文章最多一次首稿加一次定向修订、最终文章跳过全局二次改写。
- [ ] 定义版本化触发裁决，至少区分：可修复保真问题、无来源新增 claim、任务契约遗漏、高置信表达问题、低置信软信号、模型/协议错误和无需修改。
- [ ] 只有可修复硬问题、任务契约遗漏或达到预注册阈值的高置信表达问题触发修订；低置信软信号和 `no_change_recommended` 不触发。
- [ ] 每个文章任务的写作模型调用上限为 2；调用计数在持久运行状态中原子记录，重试和恢复沿用计数，服务重启不能重新获得修订额度。
- [ ] 修订请求只包含原任务、必要原文/保护项、首稿和待修问题的 code/位置/证据/目标，不包含已通过项、全量黑名单或与当前问题无关的体裁规则。
- [ ] 修订提示要求最小修改并保留首稿中已通过部分；不得添加来源账本之外的事实、经历、例子或新论点。
- [ ] 修订后重新运行同版本来源硬门、任务契约检查和表达审稿：仍有关键保真失败时停止交付；只有非关键风格警告时按现有 WARN 语义交付并展示具体风险。
- [ ] 首稿通过时只调用一次模型；触发修订时恰好增加一次。任何路径都不会发生第三次写作调用。
- [ ] 运行结果记录是否触发、触发 code、首稿/修订稿检查摘要、问题解决数、额外 token、额外延迟和终态，不在普通日志保存正文。
- [ ] 为第二次调用设置独立预算和截止时间；预算不足、用户停止或全局前台截止时间不足时不启动，返回首稿的真实硬门/软审稿状态。
- [ ] 能力开关可独立关闭定向修订并恢复一次调用，关闭不会改变来源硬门或把未通过首稿标为成功。

## Test plan

1. 建立无问题、一个高置信风格问题、多个低置信警告、可修复事实遗漏、无来源新增事实和模型协议失败的状态机测试。
2. 用计数适配器验证所有终态写作调用数为 0、1 或 2，跨进程恢复和重复事件不会达到 3。
3. 捕获第二次请求，断言只含待修问题和必要上下文，不含全量规则 ID；protected spans 与来源哈希保持。
4. 构造修订成功、仍有软警告、再次破坏事实、超时、预算不足和用户停止场景，验证各自稳定终态。
5. 对首稿已自然样例验证不触发；对用户失败型文章验证第二次修订能移除指定 PPT 腔且不新增亲历。
6. 运行旧显式 SKILL 和新自然语言路径的兼容测试，确保二者共享统一调用上限和终态语义。
7. 验证普通聊天调用次数完全不变。

## Observability & rollback

- 指标包含修订触发率、按 code 触发分布、问题解决率、修订后硬门失败率、额外 token、p50/p95 额外延迟、预算拒绝和停止数。
- 对修订前后只保存内容哈希、检查摘要和必要审计 ID；正文仍按既有受控结果存储，不进入遥测。
- 通过独立能力开关和策略版本灰度。回滚关闭修订调用，恢复首稿一次生成；新 ADR 与历史审计不删除。
