# BridGes 聊天优先改进 PRD

Status: approved
Date: 2026-08-09

权威契约与迁移门：[`docs/adr/0026-frozen-product-contracts-and-migration-gates.md`](../../docs/adr/0026-frozen-product-contracts-and-migration-gates.md)。本 PRD 记录最终产品合同；若历史 ADR 或旧计划与本文件冲突，以 ADR-0026 和本文件为准。

## 1. 目标

把当前仍带有功能中心和手动工具选择痕迹的 BridGes，收敛为一个真正的聊天优先产品：

- 日常陪伴是一位持续了解用户、自然交流的知心朋友。
- 学习模式是一位依据用户画像、知识库证据和学习进展因材施教的老师。
- 用户用自然语言表达意图，系统自动选择正确能力。
- 所有私人材料统一进入账户级知识库，系统只在需要时检索。
- 系统在对话中低打扰地形成四维画像，并在后续回答中使用相关信息。
- 所有自然语言回答具有人味，但事实、引用、安全与机器状态不被风格化破坏。

## 2. 最终产品合同

### 2.1 对话模式

- 只存在日常陪伴和学习模式。
- 新聊天发送第一条消息前可以选择模式。
- 第一条消息与对话、模式原子创建；此后模式永久不可变。
- 重试、恢复、并发请求和直接 API 调用均不得绕过模式锁。
- 日常陪伴强调理解、陪伴与自然交流；学习模式启用教学计划、课时、测验和证据门。

### 2.2 自然语言能力路由

- 用户不选择 SKILL、MCP 或工具按钮。
- 明确的找论文、文章润色、图片生成或编辑、视频生成、生涯规划意图直接进入对应能力。
- 低置信或缺少必要输入时只追问一个澄清问题。
- 图片、视频等计费能力不得因随口提及而误触发。
- 路由结果随生成运行持久化；重试复用原结果，不重新分类或重复创建任务。

### 2.3 唯一知识库与检索

- 用户可上传的文件和图片只进入当前账户的知识库。
- 聊天附件、项目文件和局部知识库退出。
- 上传时自动执行受信任的解析、图片理解、元数据、分块和索引能力，原文件不可变。
- 普通闲聊、人味化、论文搜索和纯生成任务默认不检索知识库。
- 学习任务、用户明确询问私人材料等场景按需检索，优先使用知识库证据。
- 知识库不足、过时或冲突时，学习模式自动联网搜索，无需用户另行开启。
- 详细检索过程卡退出；实际使用资料时保留紧凑引用。

### 2.4 联网能力保证

产品保证的是可验证的联网检索能力，而不是第三方服务永不故障：

- 发布候选必须通过真实网页搜索和适用的论文搜索冒烟。
- 搜索有健康检查、超时、有限重试、脱敏查询和可恢复终态。
- 成功结果必须带可定位来源。
- 外网不可用或证据仍不足时，不推进学习计划，不用模型记忆冒充资料，并返回明确可重试状态。

### 2.5 四维自动画像

用户画像只包含：

1. 学业情况
2. 感兴趣的知识
3. 兴趣爱好
4. 阶段目标

写入与使用规则：

- 首次启用画像能力时仅展示一次非交互式隐私说明；它不是授权弹窗，不阻断聊天，也不提供授权开关或逐条写入通知。
- 每条用户消息先执行画像提取和去重，再生成回答。
- 无有效画像时正常继续；画像模块故障时聊天放行并创建持久重试。
- 每次提问可以成为内部观察，但知识兴趣只有在明确表达或跨轮次持续出现后才成为稳定记录。
- 敏感身份、健康、情绪、人格和心理推断禁止进入四维画像。
- 每轮都编译画像，但只注入与当前问题、模式和课时相关的最小切片。
- 页面只显示内容、首次稳定记录时间、修改和撤回。
- 来源、置信度、冲突、版本和撤回墓碑只供内部去重、纠错与审计。
- 撤回立即停止使用，并阻止同一旧证据再次自动写回。
- 单条画像不提供普通硬删除；只有账户删除生命周期才物理清除画像及其撤回墓碑。

### 2.6 学习计划

- 学习目标明确后，以最新画像、知识库和必要的联网证据创建持久化计划。
- 创建计划的同一回复展示简要计划并交付第一课时。
- 后续每个有效教学回复最多推进一个课时。
- 澄清、系统错误和重试不计课时。
- 在知识边界或约每 2–4 课时插入自适应测验。
- 重试不得重复推进；画像撤回、测验表现和用户反馈只影响后续课时，并留下计划调整记录。

### 2.7 有人味表达

同一个内置人味化能力分为两档：

- 轻量全局策略：随一次主模型生成注入所有面向用户的自然语言回答，不增加第二次模型调用。
- 完整改写流程：只在明确文章润色或改写意图中执行，包含任务契约、事实锁、体裁检查、修复和结构化结果。

错误、权限拒绝、安全拒答、引用、代码、公式、工具状态和精确数据不做二次风格改写。

参考项目只用于研究不受版权保护的通用方法。未声明许可证的内容不得复制；即便是 MIT 项目也优先净室重写，任何实际复用必须保留许可、署名和来源链。来源清洁记录必须补充本轮新增参考。

### 2.8 退出的产品能力

- 学习项目页面、项目文件域和项目对话归属
- 任务安排、QQ 邮件提醒和旧复习调度
- 插件中心、用户 SKILL 上传、MCP 安装管理和对话选择
- 会话内模式切换
- 聊天附件及手动工具菜单
- 画像许可、逐条通知、候选确认、新增、复杂来源与历史界面
- 独立本地检索过程卡

通用后台队列、内置 SKILL 注册表、内部论文搜索适配器和新的教学计划状态继续保留。

## 3. 数据迁移合同

| 旧数据 | 迁移结果 |
| --- | --- |
| 学习项目文件 | 按账户迁入知识库，按内容哈希去重 |
| 项目对话 | 保留全部消息和模式，解除项目归属 |
| 项目名称及关联 | 只进入迁移审计，历史引用保持只读可解析 |
| 未来提醒及待发邮件 | 停止并取消，不转换为教学计划 |
| 历史投递 | 保留供账户导出 |
| QQ SMTP 授权码 | 因功能退出而幂等清除 |
| 用户 SKILL/MCP | 立即停用、终止进程并清除会话选择；清单和审计封存 |
| 用户扩展包正文 | 先隔离为不可执行，回滚窗口结束且导出验证后清理 |
| 旧阶段目标 | 直接迁入新阶段目标 |
| 旧基本情况 | 只有明确学业信息迁入学业情况 |
| 旧兴趣偏好 | 仅高置信拆分为知识兴趣或兴趣爱好 |
| 旧知识状态 | 转为教学域内部学习记录 |
| 其余旧画像 | 只读封存并停止注入 |

迁移必须账户隔离、幂等、可重复运行、可生成报告，并在失败时保持旧数据和当前可用版本不变。

## 4. 界面合同

### 4.1 侧栏

- 保留搜索、收起侧栏、新聊天、知识库、用户画像、最近对话和账户菜单。
- 删除学习项目、任务安排和插件。
- “新聊天”不再使用突兀的白色大色块。
- 释放空间全部归最近对话列表。

### 4.2 新聊天

- 删除“长期科学学习与表达伙伴”和“有什么可以帮你的？”可见文案，但保留无障碍一级标题。
- 模式选择器位于主内容右上角。
- 删除来源状态条、“+”菜单和三张建议卡。
- 保留简洁输入区及原有名言区域。

### 4.3 用户画像

- 只保留四类标签及自动采集的记录列表。
- 不提供手动新增。
- 每条只显示内容、首次稳定记录时间、修改和撤回。
- 静态头像回归个人资料页面。

### 4.4 对话

- 进入对话后没有模式切换按钮、来源开关、“+”菜单、项目或插件选择。
- 消息区域独立滚动，输入框始终位于视口底部。
- 输入区周围颜色与对话背景连续。
- 自动能力结果仍以内嵌结果卡呈现。
- 检索过程卡退出，紧凑引用保留。

### 4.5 最近对话菜单

- 置顶、改名和删除完整可见、可点击。
- 菜单通过视口定位规避滚动容器裁剪，并支持上下、左右碰撞翻转。
- Esc 关闭并把焦点归还原按钮。

## 5. 迁移与发布顺序

1. 冻结新规范并用新 ADR 取代冲突决策。
2. 扩展新数据合同并迁移旧数据，旧读路径暂时兼容。
3. 交付模式锁、自然语言路由、唯一知识库、自动画像、人味化和教学闭环。
4. 替代能力可用后移除手动入口及旧页面。
5. 兼容窗口至少跨过一个可观测迁移版本并持续到旧调用清零；期间旧页面重定向新聊天，旧 API 返回稳定的 410。
6. 依赖清零、导出和回滚验证后，删除兼容代码并令旧路由返回 404。

## 6. 质量门

### 功能

- 每个能力都有明确意图、缺参、低置信、失败、取消和重试用例。
- 对话恢复后模式、路由、课时、引用和画像使用结果一致。

### 数据

- 所有迁移验证账户隔离、幂等、重复启动、部分失败和恢复。
- 历史引用、导出、备份恢复和删除生命周期不因域退出而损坏。

### 安全与隐私

- 禁止跨账户召回、查询泄露、密钥进入模型或日志。
- 画像敏感推断硬门和撤回墓碑不可由模型绕过。
- 隔离扩展绝不再进入可执行搜索路径。

### 模型与证据

- 普通回答只发生一次主模型调用。
- 人味化不得改变数字、单位、限定词、引用和事实强度。
- 学习计划及课时在证据不足时自动联网，失败时不伪造。

### 前端

- 1280×720、1440×900、1920×1080 和 200% 缩放通过。
- 键盘导航、焦点管理、屏幕阅读器语义和对比度通过。
- 旧视觉快照和 E2E 断言被新合同替换，不保留相反行为。

## 7. 非目标

- 不新增移动端、PWA 或原生客户端。
- 不允许用户选择模型、上传 SKILL 或配置 MCP。
- 不恢复学习项目、提醒或插件中心的替代页面。
- 不以规避 AI 检测、冒充真人或牺牲科学事实作为人味化目标。
- 不承诺第三方网络永不故障。

- 自然语言能力：06–10
- 检索与联网：12–13
- 画像与表达：15、17
