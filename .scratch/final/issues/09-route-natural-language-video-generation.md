# 09 — 让自然语言自动调用视频生成

Status: ready-for-agent
Type: task

## What to build

在聊天中识别“生成一段……视频”“把这个场景做成短视频”等自然语言请求，自动编译视频生成合同并提交现有视频能力。用户不再选择视频工具；任务排队、生成进度、完成资产、失败和重试都作为当前对话的一部分持久化。

本切片只交付已支持的文生视频范围。时长、画幅等可选参数采用产品固定默认值；用户给出明确且受支持的参数时覆盖默认值。请求超出能力、缺少核心场景或同时要求未支持的视频编辑时，先给出最小澄清或明确拒绝，不能伪装为已提交。

## Acceptance criteria

- [ ] **成功路径**：自然语言视频请求被自动识别，保存版本化路由与生成合同，只提交一个后台视频任务，并在同一消息流持续投影排队、处理中、完成或失败状态。
- [ ] **成功路径**：用户明确的主题、镜头内容、画幅和受支持时长进入合同；未指定参数使用可审计默认值，重试仍沿用同一合同。
- [ ] **失败路径**：空泛请求、编辑现有视频、非法参数、供应商拒绝、超时或资产保存失败时返回稳定中文说明和可操作恢复，不产生伪成功链接。
- [ ] **失败路径**：不支持的操作不得静默降级成图片或普通文字回答；需要澄清时在提交模型前完成。
- [ ] **幂等**：同一消息和尝试最多创建一个视频任务；页面刷新、后台重新领取和 SSE 重连不重复提交。失败后的显式重试产生关联的新尝试，而非覆盖原审计记录。
- [ ] **账户隔离**：任务、提示、模型结果、对象和下载链接绑定账户；跨账户查询统一表现为不存在或无权限，外部日志不包含密钥和私人上下文。
- [ ] **迁移**：历史显式视频载荷和任务投影保持可读、可恢复；新路由只作用于新消息，不批量重写历史视频记录。
- [ ] **模型调用次数**：每个新消息最多复用 Issue 06 的一次路由调用；命中后只提交一次已登记视频模型任务，不再调用普通文本模型。轮询次数不等于模型生成次数且不得导致重提任务。
- [ ] **事实安全**：视频必须标记为合成媒体，不得被回答描述为真实拍摄、实验记录或新闻证据；不得伪造人物授权、来源或科学结果。
- [ ] **前后端**：前端通过普通消息触发并显示可恢复任务卡；后端复用统一运行队列、对象存储和消息终态，不另建绕过聊天的页面或接口。
- [ ] **合同**：合同至少固定模型能力、提示词、画幅、时长、版本和账户对象域；参数越界与未知版本必须在外部提交前失败。
- [ ] **测试**：覆盖典型中文请求、口语同义词、普通视频讨论、缺少场景、非法参数、不支持编辑、外部超时、重复领取、断线恢复、旧合同兼容和跨账户访问，并加入论文/Humanizer/图片/生涯的共享路由互斥矩阵。

## Verification

1. 使用可计数的假视频供应商跑通一次成功任务，确认只提交一次并正确保存合成媒体标识。
2. 模拟提交后进程重启、轮询超时和迟到结果，确认状态收敛且无重复资产。
3. 验证普通“这个视频讲了什么”不会误触发生成。
4. 验证两个账户不能读取、重试或下载对方的视频任务与对象。
5. 运行视频、后台队列、聊天投影、前端及全量回归测试。

## Out of scope

- 视频编辑、数字人、口型同步和声音克隆。
- 增加新的供应商或改变固定模型矩阵。
- 自动发布到外部平台。
- 把生成视频当作可验证科学证据。

## Agent notes

- 继续遵守已有长任务恢复、迟到结果隔离和对象版本语义。
- 路由完成后不得让文本模型“模拟”视频生成结果。
- 任务卡可以展示公开进度，不展示供应商原始响应和内部推理。
- 只向 Issue 06 的注册表追加视频能力，禁止覆盖其他能力枚举、分类提示或顶层分支。
