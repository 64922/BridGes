# 12 — 按意图决定知识库检索并简化引用

Status: ready-for-agent
Type: task

## What to build

在能力路由之后增加可持久化的检索决策，让聊天不再每回合无条件扫描知识库。系统先依据用户当前请求、已锁定模式和必要的画像摘要判断是否需要全局知识库；需要时先从该账户的文件元数据中筛出候选文件名，再只读取候选文件的相关片段。新引用统一为简洁的全局知识库文件引用，保留文件名、稳定文件身份和足以定位证据的页码或片段位置。

论文搜索、Humanizer、图片生成和普通陪伴对话默认跳过知识库；学习解释、明确要求查询“我的资料/知识库”的请求以及需要依据知识库资料回答的请求触发检索。图片编辑只能明确指向知识库中的图片，并由能力路由做精确、授权的输入解析，而不是启动通用语义检索。学习模式优先使用知识库，但“优先”不等于每回合强制检索。历史三层引用只读兼容，不改写旧对话。

## Acceptance criteria

- [ ] 每个聊天回合在任何检索副作用前形成并持久化 `retrieve` 或 `skip` 决策、原因、规则版本和所依据的能力路由；生成恢复和幂等重试复用同一决定。
- [ ] 明确查询知识库、询问已上传材料或学习问题需要本地证据时触发检索；普通寒暄、情绪陪伴、纯创作及与资料无关的稳定问答默认跳过。
- [ ] 论文搜索、Humanizer 和图片生成路由默认跳过知识库，不产生空检索轮、伪 citation 或额外检索状态卡；图片编辑必须明确点名知识库图片，并只解析经授权的精确能力输入，不启动通用语义检索。
- [ ] 学习模式优先利用知识库：存在相关材料时使用并引用；没有相关材料时返回真实的未命中状态，再由后续联网证据策略决定是否搜索，而不是引用不相关文件。
- [ ] 检索分两阶段执行：先基于用户关键词、文件元数据和必要画像上下文产生有界候选文件名，再仅从候选文件读取相关片段；不得在每个回合全量读取全部文件。
- [ ] 画像只用于提高相关性，不得突破账户或撤回边界；已撤回画像、其他账户画像和与问题无关的敏感信息不能进入查询、日志或引用。
- [ ] 候选文件和片段都严格限制为当前账户的全局知识库；伪造文件 ID、同名文件碰撞、缓存键复用和并发检索均不能造成跨账户命中。
- [ ] 新 citation 只展示用户可理解的文件名和必要定位信息，同时携带稳定内部身份以区分同名文件；点击引用只能打开当前账户有权访问的对应文件位置。
- [ ] 历史 `project`、`attachment` 和旧层级 citation 继续可渲染，缺失历史对象时明确显示来源不可用；不得把旧引用重写为新的知识库证据。
- [ ] 无匹配、索引处理中、索引损坏、检索超时和引用对象已删除具有不同状态；任何失败都不能让模型声称“根据你的资料”或生成不存在的文件名。
- [ ] 相同回合重复执行不新增检索轮或 citation；规则版本变化只影响新回合，不静默改变已持久化回答的证据。
- [ ] 检索决定、候选文件筛选、片段读取、citation 投影和恢复全部使用确定性逻辑，语言模型调用次数为零；不得为了决定“是否检索”额外调用分类模型。
- [ ] 前端不展示独立的本地检索过程卡、来源层状态或手动重试控件；回答实际采用知识库证据时仅展示紧凑引用，跳过或失败时不闪现成功状态或虚构引用。
- [ ] 合同明确检索决定、原因枚举、候选文件摘要、命中状态和新旧 citation 投影；生成客户端、接口文档和运行时校验一致。
- [ ] 自动化测试覆盖各类触发与跳过意图、学习模式优先、无命中、同名文件、候选上限、索引失败、删除文件、历史引用、幂等恢复及账户隔离。
- [ ] 性能测试证明跳过路径不调用索引，触发路径只读取有界候选；指标能区分决策耗时、候选检索和片段读取，但不记录用户原文或敏感画像。

## Verification

- 运行能力路由、检索决策、知识库索引、聊天生成、citation 投影、合同和账户隔离测试。
- 使用决策表覆盖陪伴、学习、论文、Humanizer、图片、明确知识库查询和歧义请求，核对调用次数及持久化原因。
- 构造两个账户的同名文件、无关文件集合和一个已删除文件，执行端到端检索并验证候选、片段、链接授权和失败展示。
- 执行生成中断与恢复、并发重试和规则版本升级测试，确认单回合仅有一份检索快照。
- 运行前端引用组件、历史消息兼容、类型检查和桌面端端到端测试；重新生成并校验 API 合同。

## Out of scope

- 删除历史引用或历史来源枚举。

## Agent notes

- 顺序必须是“能力路由 → 检索决策 → 候选文件 → 相关片段 → 回答”；不要让检索器自行猜测工具意图。
- 决策快照和检索快照分别持久化，便于证明“决定跳过”与“尝试但失败”的差异。
- 引用简化是展示和新合同收敛，不是牺牲证据可追溯性。
