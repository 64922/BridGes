# 18 — 在学习对话中生成个性化计划与第一课

Status: ready-for-agent
Type: task

## What to build

当用户在学习模式提出学习目标时，在同一聊天回合完成目标解析、相关四维画像切片编译、全局知识库证据判定、必要的公开联网补充，以及“学习计划概览 + 第一课”生成。第一条正式教学回答就是第一课，不创建学习项目、课程工作台或任务安排页面。

检索遵循按需原则：先从目标和合法画像中提取本地关键词，先筛相关文件名和元数据，再读取少量相关片段；与教学无关、文章人味化等任务不检索知识库。学习材料不足、过时或无法覆盖目标时，自动调用已登记的公开网页或论文搜索，且只发送去身份化的最小查询。若必需证据仍然不足，则明确缺口并进入可重试的等待状态，不创建或推进正式课时，不用模型记忆伪装来源。

计划应给出目标、前置知识假设、课时序列、阶段检查点和完成标准；第一课应包含本课目标、讲解、例子、知识库/公开来源引用、小结和少量理解检查。学业情况决定解释起点，感兴趣的知识与兴趣爱好只用于选择例子，阶段目标用于调整路径；画像缺失时采用中性默认值，不直接盘问画像。

## Acceptance criteria

- [ ] **成功路径**：学习模式中包含明确目标的首条消息返回一个版本化计划和第一课，计划与课程均嵌在当前对话，第一课编号为 1 且能独立阅读。
- [ ] **成功路径**：相关四维画像能改变难度、例子或路径但不改变科学事实；无画像时仍可生成，正文不暴露“根据画像判断你……”等内部表述。
- [ ] **失败路径**：缺少可执行学习目标时只询问目标本身，不询问画像，不调用教学生成；知识库和联网均不足时明确证据缺口并进入可重试的等待材料状态，不创建计划版本或第一课，不推进课程索引。
- [ ] **失败路径**：知识库解析、搜索或模型失败时保存明确阶段状态，可安全重试；不得返回没有引用却声称基于材料的课程。
- [ ] **幂等**：同一首条消息只创建一个计划版本和第一课；页面重连、后台重复领取和生成重试不重复编号或重复写课程。
- [ ] **原子提交**：计划版本、第一课、课时编号、助手消息和生成成功终态必须一次对用户可见；若存储不支持单事务，则先写不可见 staged 状态并在全部成功后原子发布。任一提交阶段失败都不能留下“有计划无第一课”“有第一课无消息”或课程索引已推进的半状态，重试复用原 staged 记录。
- [ ] **账户隔离**：画像、知识库文件、检索片段、计划和课程全部按账户绑定；跨账户文件在检索和模型调用前拒绝，联网查询不含用户身份和私人原文。
- [ ] **迁移**：已有学习对话在下一次新学习请求时按新合同惰性建立计划，不回写历史回答、不依赖旧学习项目；旧教学消息仍可读取。
- [ ] **模型调用次数**：目标完整时，计划和第一课必须由一次结构化教学生成调用共同产出，不分别调用两次模型；本地检索和公开搜索不调用语言模型。Issue 15 的画像抽取和统一路由调用单独计量，不得在教学服务内重复执行。
- [ ] **事实安全**：正式教学结论优先引用全局知识库；材料不足时自动联网并展示来源，必需证据仍不足则不交付正式课时。不得编造论文、引用、公式、实验结果或把画像当知识证据。
- [ ] **前后端**：前端在聊天消息中展示计划摘要、第一课、引用和理解检查，不新增项目/任务页面；后端用统一消息运行、检索披露、停止和重试合同持久化。
- [ ] **合同**：计划、课时、证据充足性、来源、画像使用类别和理解检查均有版本化结构；计划与第一课共享同一目标快照和证据快照。
- [ ] **测试**：覆盖无画像/有画像、知识库充分/不足/过时、自动网页与论文搜索、完全无证据、缺目标、模型失败、重复投递、旧学习对话和跨账户检索。

## Verification

1. 准备一个知识库充分和一个知识库不足的学习目标，确认前者不联网、后者自动联网且查询已去身份化。
2. 对同一目标使用不同学业情况和兴趣画像，确认教学层次或例子变化，事实锁和引用不变。
3. 统计模型网关，确认计划与第一课只占一次教学生成调用。
4. 在计划写入、第一课写入、助手消息写入和终态提交之间逐点注入失败，刷新、断线并重试，确认半成品不可见且最终仍只有一个计划和第一课编号 1。
5. 运行教学、检索、画像切片、联网披露、前端和全量端到端测试。

## Out of scope

- 后续课时持久化、测验评分和自适应推进，由 Issue 19 交付。
- 学习项目、任务安排、邮件提醒和独立课程页面。
- 直接向用户询问学业、兴趣或爱好以补画像。
- 用模型记忆替代本地或公开证据。

## Agent notes

- “先检索文件名，再读取相关文件”应体现在可测试的检索阶段，不允许把整个知识库注入模型。
- 第一课中的理解检查只收集答案，不在本 Issue 建立长期评分和自适应状态。
- 教学正文应用 Issue 17 的全局表达策略，但不得追加第二次人味化模型调用。
