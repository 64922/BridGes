# 24 — 完成旧契约收缩、类型再生成与全量发布回归

Status: ready-for-agent
Type: task

## What to build

在所有替代用户旅程和数据迁移完成后执行最终 contract 阶段：先验证 `COMPATIBILITY-GATE.md` 已记录至少一个完整迁移版本且所有真实旧调用为零，再证明旧页面、旧 API、旧类型、旧数据库写路径、旧搜索与导出目录、旧测试夹具和旧后台入口已无调用者，然后删除兼容代码并形成可发布证据。门禁未通过时，本 Issue 不得开始破坏性收缩。

兼容窗口中的页面重定向和 410 API 在此 Issue 才能收缩为真正不存在的 404。只读迁移审计、历史引用兼容和依法必须保留的记录不属于旧运行契约，不得误删。

## Acceptance criteria

- [ ] **领取前置门**：`COMPATIBILITY-GATE.md` 状态为 `passed`，包含观察起止时间、兼容部署版本、逐路由真实流量零计数、探针成功结果、指标查询和证据校验值；缺少任一字段或出现非零调用时立即停止，不删除兼容层。
- [ ] 学习项目、任务安排、用户插件/MCP 等确实存在过的独立公开页面最终返回 404，导航、搜索结果和账户菜单无残留链接。
- [ ] 会话内模式切换、聊天附件及旧画像治理等嵌入式控件在最终界面和可访问树中不存在；不得为并不存在的独立页面伪造 404 验收。
- [ ] 上述领域的旧公开 API 在确认无调用者后从路由和 OpenAPI 中删除，不再返回兼容期 410；模式切换、附件和旧画像请求同样不存在可调用旁路。
- [ ] 旧客户端请求字段、事件投影、生成类型和 API 辅助函数被删除；不存在“前端不显示但仍可调用”的旁路。
- [ ] 数据库不再接受旧域的新写入；需要保留的废弃列或表有明确只读理由、删除门和迁移审计。
- [ ] 用户扩展隔离区已过回滚窗口且账户导出验证成功时，包正文按确定目标安全清理；清单、许可来源和运行审计按合同保留。
- [ ] 搜索目录、账户导出、账户删除、备份恢复和生命周期清理均使用新领域对象，不遗漏迁移后的知识库文件、画像墓碑、教学计划或生成资产。
- [ ] 单条画像始终只能修改或撤回；账户删除测试证明四维画像、内部观察、证据和撤回墓碑按保留合同物理清除，且不能从备份恢复旁路复活已删除账户。
- [ ] OpenAPI 重新生成，服务端 Schema、生成 TypeScript 类型、客户端调用和合同快照完全同步。
- [ ] 所有锁定相反旧行为的测试已被重写或删除，未通过 skip、xfail、弱化断言或保留不可达页面蒙混过关。
- [ ] 全量后端单元、集成、迁移、账户隔离、安全与生命周期测试通过。
- [ ] 前端类型检查、单元测试、生产构建和完整 E2E 通过。
- [ ] 1280×720、1440×900、1920×1080 与 200% 缩放的视觉和无障碍验收通过，快照只包含最终页面。
- [ ] 发布候选在明确启用的真实网络环境中通过网页搜索及论文搜索冒烟；失败报告能区分应用缺陷和第三方不可用。
- [ ] 普通聊天没有额外人味化模型调用；显式改写通过事实锁；学习计划在检索失败时不推进。
- [ ] 秘密扫描、日志脱敏和跨账户负向测试通过，SMTP 授权码及用户扩展可执行内容已按迁移合同处理。
- [ ] 最终发行报告列出执行版本、迁移版本、测试命令、结果摘要、已知限制、回滚点和人工验收项。

## Verification

- 在全新数据库、从上一版本升级的数据库、迁移中断后重试的数据库上分别运行完整测试。
- 运行后端全量 pytest，并单独保留合同、迁移、检索、画像、聊天、学习、安全、导出与恢复结果。
- 运行前端 typecheck、unit、production build 和 Playwright 全量矩阵。
- 运行 OpenAPI 再生成和同步检查、前端完整性检查、对比度检查与秘密扫描。
- 使用两个账户执行知识库、画像、对话、教学计划、搜索和删除负向隔离测试。
- 在受控真实网络中执行网页与论文检索冒烟，并记录访问时间、响应类别和引用可用性；测试日志不得保存私人查询正文。
- 访问清单中每个真实存在过的旧独立页面，验证最终 404 且没有内部错误、重定向循环或遗留导航；检查嵌入式退役控件不在 DOM 或可访问树中。
- 请求每个旧 API 路径，验证路由已删除且 OpenAPI、生成客户端和运行时均无残留合同。
