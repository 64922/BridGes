# 08 — 让自然语言自动调用图片生成与编辑

Status: ready-for-agent
Type: task

## What to build

让用户在聊天框中直接说“生成一张小猫的图”“把这张图的背景换成实验室”等话，系统即可区分图片生成与图片编辑，验证输入资产后提交现有图片能力。用户无需打开工具选择器，生成进度、失败恢复和最终图片都留在当前对话消息流中。

路由结果必须把操作类型、提示词、引用图片、尺寸或构图约束编译成稳定合同。生成任务没有引用图片；编辑任务必须绑定当前账户知识库中由用户明确指代且有权读取的一张图片，聊天消息不得上传或新建附件。意图或目标图片不明确时只请求最少的补充信息，不能把不完整编辑请求偷偷当成文生图，也不能降级为普通文字回答。

## Acceptance criteria

- [ ] **成功路径**：文生图自然语言被自动路由为图片生成，提交后立即出现可恢复的任务卡，完成后在同一消息中展示持久化图片资产及其状态。
- [ ] **成功路径**：明确指向当前账户知识库中一张合法图片的请求被路由为图片编辑，原图、编辑指令和输出资产关系可追溯；用户无需手工选择“生图”或“编辑图片”。
- [ ] **失败路径**：编辑请求缺图、多张图指代不清、媒体类型不支持、供应商拒绝或任务超时时，返回稳定中文状态和恢复动作，不创建伪成功资产，不退回普通回答。
- [ ] **失败路径**：路由置信度不足时只提出一个针对操作类型或目标图片的澄清问题；澄清前不得提交图片模型。
- [ ] **幂等**：同一消息和尝试只提交一个外部图片任务；重连与轮询不重复提交，显式重试关联原失败任务并产生新的尝试编号。
- [ ] **账户隔离**：输入图片、任务、输出对象和下载权限按账户校验；当前账户的全局知识库图片可在任意本账户对话中引用，跨账户、非知识库对象或历史聊天附件对象在外部提交前拒绝，日志不记录对象正文或密钥。
- [ ] **迁移**：历史显式图片载荷、任务卡和生成资产继续可读；新消息保存自然语言路由快照，旧消息不回填、不重新提交。
- [ ] **模型调用次数**：每个新消息最多复用 Issue 06 的一次路由调用；命中后只提交一次图片生成或编辑模型任务，不调用普通文本生成模型。状态轮询、对象保存和安全校验不计为模型调用且不得触发再次生成。
- [ ] **事实安全**：生成图片明确标记为合成内容；系统不得把生成画面宣称为真实证据，不得伪造来源、实验结果或用户上传内容，图片编辑不得静默替换原始资产。
- [ ] **前后端**：前端只发送普通自然语言消息，不提供聊天附件或手工能力载荷；后端从当前账户知识库解析被明确指代的图片，并继续使用统一消息运行、后台任务、对象存储、停止和恢复合同。
- [ ] **合同**：路由合同明确 generate/edit、提示词、输入对象标识、可选参数和版本；生成与编辑互斥，未知字段、越界参数或资产不一致按可理解错误拒绝。
- [ ] **测试**：覆盖文生图、知识库单图编辑、缺图、多图歧义、非图片知识库对象、普通“图片”讨论、提示注入、外部超时、重复投递、历史载荷兼容和跨账户访问，并加入论文/Humanizer/视频/生涯的共享路由互斥矩阵。

## Verification

1. 用固定假图片供应商验证生成与编辑各一次，断言外部提交次数均为一。
2. 在任务提交后刷新、断开 SSE 并重新进入对话，确认任务卡恢复且不重复提交。
3. 用两个账户交叉引用输入和输出对象，确认请求在供应商调用前失败。
4. 检查失败、取消、超时和重试的消息终态及对象清理策略。
5. 运行图片领域、聊天、前端和端到端回归测试。

## Out of scope

- 视频生成与视频编辑。
- 新增图片模型或改变已登记模型绑定。
- 图片作为科学证据的自动判读。
- 从其他账户、任意宿主路径或未绑定知识库读取图片。

## Agent notes

- 外部图片任务必须保持异步，不能占住聊天请求线程等待生成完成。
- 自然语言路由只负责选择能力和构造合同，供应商状态机仍由图片领域拥有。
- 原始图片与派生图片是两个版本化对象；任何清理都不能破坏原件。
- 只向 Issue 06 的注册表追加图片能力，禁止覆盖其他能力枚举、分类提示或顶层分支。
