# 17 — 为所有模型回复应用全局人性化表达策略

Status: ready-for-agent
Type: task

## What to build

把 BridGes 原创人性化表达规则拆成轻量全局策略和重型文章任务两层。所有普通模型回复在一次主生成中默认应用轻量策略：日常陪伴像可靠且有分寸的朋友，学习模式像因材施教的老师；语言自然、具体、少空话，依据和不确定性清楚。Issue 07 的文章人味化继续走完整任务合同、事实锁与结构化结果，不能在完成后再被第二个模型重写。

全局策略只作用于模型生成的自然语言正文。代码、公式、引用、链接、结构化工具结果、确定性错误提示、加载状态和协议字段必须保持原合同；工具结果外可以增加简洁说明，但不得改写证据。画像切片可调整解释深度、例子和称呼分寸，不能模仿用户或名人语气，也不能生成用户未提供的经历。

策略和评测资产必须净室原创。参考资料中的 scientific-humanization 与 cognitive-profile 未声明许可证，只能研究通用方法；Humanizer-zh 与 human-writing 虽含 MIT 许可，也默认零复用；nuwa-skill 的人物模仿、语录和第三方材料不可进入产品。`src/bridges/skills/humanizer/skill/CLEAN_ROOM.md` 与现有净室 ADR 必须列出本次研究对象、零复用边界、原创规则和新增测试资产。

## Acceptance criteria

- [ ] **成功路径**：普通日常、学习、搜索总结和能力结果说明均使用版本化全局表达策略，语气随对话模式和合法画像切片调整，但事实、引用和任务结果不变。
- [ ] **成功路径**：文章人味化意图只运行 Issue 07 的重型流程；最终文章不再经过第二次全局重写，普通包装说明仍可使用轻量策略。
- [ ] **失败路径**：策略版本缺失、编译失败或画像不可用时回退到内置安全基线，继续一次主生成并记录所用版本，不输出原始系统提示。
- [ ] **失败路径**：生成结果包含合同保护区时，策略不能修改代码、公式、JSON、引用、URL、错误码或工具原文；检测到越界时以原始受保护内容为准。
- [ ] **幂等**：同一运行保存一次策略版本、模式和画像切片快照；重试沿用同一快照，不能因策略热更新使同一次尝试前后漂移。
- [ ] **账户隔离**：个性化只来自当前账户的最小四维切片；策略编译器不得读取完整画像、其他账户示例或私人知识库正文。
- [ ] **迁移**：历史消息保持原文；新策略只用于新生成和显式重试的新尝试。已有 bridges-humanizer 结果继续按原版本读取，升级时同步更新来源清洁记录和能力版本。
- [ ] **模型调用次数**：普通聊天、教学、生涯建议和搜索总结把轻量策略注入各自既有的唯一生成调用；显式文章改写只执行 Issue 07 的一次专用生成，不追加包装模型；图片/视频结果卡、加载/停止/错误状态、引用和工具原文不得仅为风格新增文本模型调用。运行时不得新增自然度评分模型、二次改写或自动风格重试。
- [ ] **事实安全**：策略明确禁止规避 AI 检测、冒充真人/名人、伪造亲历、删除限定条件、升级因果、编造引用和以流畅度覆盖事实缺口。
- [ ] **前后端**：全局策略默认无感生效，不为每条普通回复展示 SKILL 开关或结果卡；文章任务仍展示既有结构化结果，前端可从运行元数据读取策略版本用于诊断但不显示内部提示。
- [ ] **合同**：策略输入包含模式、受众线索、允许使用的画像切片和受保护区；输出仍服从原能力合同。策略版本与净室来源记录进入能力注册和运行审计。
- [ ] **测试**：建立普通聊天、学习解释、代码回答、公式、带引用搜索、错误提示、工具卡和文章任务的黄金夹具；同时测试事实等价、语气质量、无双重改写、调用次数和跨账户画像隔离。

## Verification

1. 对固定夹具比较策略启用前后，人工盲评自然度，同时用确定性断言验证数字、限定词、引用、代码和公式完全保留。
2. 分别记录普通、教学、生涯、搜索总结、显式文章改写、图片、视频和错误状态的模型网关调用矩阵，确认轻量策略不制造任何额外生成或评分调用。
3. 在日常与学习模式使用同一问题，确认角色分寸不同但事实答案一致。
4. 模拟策略资源缺失和画像服务失败，确认安全基线及一次调用上限。
5. 审阅来源清洁记录并运行人味化、聊天、事实锁、前端与全量回归测试。

## Out of scope

- 规避 AI 检测或承诺通过任何检测器。
- 模仿用户、公众人物、名人或特定作者。
- 把外部 SKILL 安装进产品或复制其规则、示例、脚本。
- 为每条普通回答展示修改明细和事实锁结果卡。

## Agent notes

- 人味感来自清楚的任务位置、具体内容、自然中文和诚实边界，不来自错别字、粗口、口头禅或伪造个人经历。
- 外部参考的硬词表和标点禁令不可直接成为全局硬门；如做检测，只能作为体裁相关软警告并有反例测试。
- 来源清洁记录与策略版本必须同一变更更新，否则验收失败。
