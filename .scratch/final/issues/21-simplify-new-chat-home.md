# 21 — 精简新聊天首页并将模式选择移至右上角

Status: ready-for-agent
Type: task

## What to build

把登录落点和“新聊天”页面改成安静、直接的首轮输入界面。页面保留轮换名言、简洁输入框、听写、发送、必要的错误提示和来源核对说明；删除顶部“长期科学学习与表达伙伴”“有什么可以帮你的？”、三张快捷建议卡、来源状态条及“+”工具入口。日常陪伴/学习模式只在新聊天阶段可选，并固定放在主内容右上角；首轮发送成功后，所选模式随会话创建并不可在会话页修改。

首轮交互必须使用后端已经收敛的自然语言合同：用户直接输入论文搜索、人味化、图片生成、视频生成等意图，前端只提交自然语言内容和所选会话模式，不再预选功能、预建附件会话、选择学习项目或插件，也不再向用户暴露知识库和画像开关。

这是新聊天纵向切片，不能只隐藏现有元素：删除首页不再需要的建议卡预填状态、附件预建流程、项目/插件选择状态、各类手动工具对话框、会话级插件意图桥及首轮请求中的退役字段。若共享输入组件仍需兼容尚未迁移的会话页，应以明确的新聊天最小变体隔离旧分支，并确保本页面不会初始化或请求这些分支。

## Acceptance criteria

- [ ] 登录成功落点和点击侧栏“新聊天”进入的是同一个精简页面；可见区域不再出现“长期科学学习与表达伙伴”或“有什么可以帮你的？”。
- [ ] 页面仍有唯一、语义正确但视觉隐藏的一级标题“新聊天”，屏幕阅读器可识别，视觉设计中不重新出现被删除的大标题。
- [ ] 轮换名言保留在输入区上方，原有减少动态效果偏好仍生效；三张“论文搜索/文章人味化/生涯规划助手”建议卡完全不存在。
- [ ] 日常陪伴/学习模式选择器位于主内容右上角，默认选择日常陪伴；用户在发送首轮前可用鼠标或键盘切换。
- [ ] 首轮请求只提交当前文本、幂等键和所选模式等仍在新合同中的字段；不提交附件、学习项目、插件/MCP 选择、手动技能载荷、`use_knowledge_base` 或 `use_profile` 等退役字段。
- [ ] 页面中不存在“当前附件”“当前项目”“全局知识库”“使用画像”状态条，不存在“更多功能”按钮、隐藏文件输入、项目/插件选择器或人味化/生涯/图片/视频手动对话框。
- [ ] 普通自然语言首轮发送成功后只创建一个会话、只写入一条用户消息并导航到该会话；请求重放或快速双击仍由幂等合同保证不产生重复会话。
- [ ] 分别以日常陪伴和学习模式创建会话，服务端投影与最近对话模式标签准确；进入会话后不出现可修改模式的控件。
- [ ] 以自然语言输入“找几篇 Transformer 论文”“润色这段文章”“生成一张小猫图片”等意图时，前端不打开菜单或对话框，直接按普通首轮发送；协议替身返回相应能力投影时能顺利导航且无前端运行时错误。
- [ ] 发送成功态会清空输入并导航；发送失败态停留在新聊天页，保留输入文本和当前模式，显示中文可恢复错误，允许用户重试且不会显示假成功或留下空会话。
- [ ] 创建中展示明确状态并禁用重复发送；完成或失败后恢复正确的可操作状态。
- [ ] 在 1280×720、1440×900、1920×1080 三个桌面视口以及每个视口 200% 页面缩放下，模式选择器、名言、输入区和说明均不重叠、不被侧栏遮挡且没有水平滚动。
- [ ] 几何断言验证：模式选择器右边缘位于主内容右边缘内、顶部不越过视口；它与侧栏展开恢复按钮不相交；输入区水平居中且完整位于视口内；名言底边位于输入区顶边之上。
- [ ] 纯键盘可以依次到达两个模式按钮、消息输入、听写和发送；Enter/Space 能切换模式，输入框 Enter 发送、Shift+Enter 换行，所有焦点状态清晰，失败重试后焦点回到可继续编辑的位置。
- [ ] 删除或替换所有锁定可见大标题、建议卡预填、“+”菜单八入口、聊天附件、项目/插件选择和首页工具对话框的旧测试；不得以 skip 保留相反产品合同。
- [ ] 新端到端测试覆盖两种模式首轮、自然语言能力意图、创建中、防重复、成功导航、失败重试、三视口、200% 缩放、键盘路径和上述几何断言；视觉快照更新为精简首页。
- [ ] 类型检查、前端单元测试和相关端到端测试全部通过，首页不产生退役接口请求或未使用状态/导入。

## Verification

1. 在 Web 应用目录运行类型检查和单元测试。
2. 运行认证落点、新聊天首轮、模式、幂等、防重复发送、听写、无障碍、缩放和视觉回归用例。
3. 捕获首轮请求体，分别验证日常陪伴与学习模式，并断言所有退役字段不存在而非固定为某个布尔值。
4. 用协议替身覆盖普通聊天、自然语言能力意图、服务不可用和网络中断；确认成功与错误态均可恢复。
5. 在三个桌面视口及 200% 缩放下执行 bounding-box 和水平溢出断言，并生成新的首页视觉基线。
6. 监控网络请求，确认打开首页、切换模式和输入文字不会请求附件、学习项目、插件或 MCP 数据。

## Agent notes

- 可见标题删除后必须补视觉隐藏的一级标题，避免无障碍回归。
- 名言是保留项；建议卡、来源条和“+”是删除项，不要把它们折叠进另一个菜单。
- 模式选择只在首轮前可变。首页保持本地选择状态，首轮原子创建成功后由服务端投影成为会话事实。
- 不要通过向旧请求字段固定发送 `true` 来模拟自动知识库/画像；是否检索知识库和默认画像注入属于服务端合同。
- 若共享输入组件暂时仍服务会话页，本 issue 只允许保留会话页尚需的兼容分支；新聊天路径必须彻底不初始化、不渲染、不请求退役能力。
