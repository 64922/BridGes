# 03 — 退役学习任务安排与复习提醒

Status: ready-for-agent
Type: task

## What to build

从产品和运行时中完整退役“学习项目任务安排、复习计划、延期、调整、取消、完成以及提醒物化”这条纵向能力，让学习仅发生在聊天中的连续教学回合。移除桌面端入口和新建能力，停止后台生成或发送新的学习提醒，并通过一个有期限的兼容窗口让旧客户端得到明确、稳定的 410 响应，而不是 404、空成功或静默丢弃。

采用 expand-contract：先停止新任务创建和后台物化，盘点并安全终止遗留待执行提醒与待发邮件，保留历史投递的只读账户导出；随后幂等撤销并清除该退役能力专用的 QQ SMTP 授权码，不把凭据写入导出、日志或迁移报告。再发布不再包含该能力的新客户端合同；兼容窗口内，旧读写 API 均统一返回结构化 `410 Gone` 和替代路径，历史只通过现有账户导出流程提供，不保留公开只读页面或 API；观测确认无活跃调用后，才能在后续清理中物理删除遗留存储。旧任务和提醒绝不转换成新的教学计划。

## Acceptance criteria

- [ ] 桌面端不再显示学习任务、复习日程、提醒列表及其新建、延期、调整、取消、完成入口，聊天教学和测验入口仍正常工作。
- [ ] 后端不再接受新的学习复习计划或任务；兼容窗口内所有旧写接口返回 HTTP 410、稳定错误码、中文说明和“请在学习模式聊天中继续”的替代建议。
- [ ] 兼容窗口内旧任务/提醒列表、详情和历史读取 API 同样返回 410；历史投递只通过账户导出交付，产品中不存在只读幽灵页面或旁路 API。
- [ ] 每个 410 端点按稳定端点标识、服务版本和真实/探针流量分类计数，不记录账户、路径参数或请求正文，并向 `COMPATIBILITY-GATE.md` 输出观察数据。
- [ ] 旧接口不得返回假成功；客户端重试相同请求仍得到相同 410，不创建任务、不发送消息、不产生后台作业。
- [ ] 后台启动、周期扫描和队列恢复都不会再物化学习提醒；退役前已排队的提醒被幂等地取消或归档，进程重启后不会复活。
- [ ] 若部署中发现任何持久化遗留任务，先按账户导出状态并标记为退役，再停止执行；禁止无审计地直接删除。当前环境没有遗留项时也要记录零迁移结果。
- [ ] 退役处理严格按账户隔离；账户 A 不能读取、导出、取消或推断账户 B 的历史任务，猜测任务 ID 返回与普通不存在资源一致的结果。
- [ ] 与学习提醒专用的通知或邮件不会再发送；失败的取消操作进入可重试状态并告警，不能因超时而假定已取消。
- [ ] 已发送历史按账户继续只读导出；未来提醒、待发邮件和队列消息不迁入教学计划，也不会因恢复旧备份、重启或重试再次发送。
- [ ] 取消/归档确认后幂等清除学习提醒专用 QQ SMTP 授权码及可用派生凭据；明文和可逆值不进入日志、导出或报告，回滚只恢复无凭据的只读历史，不能恢复发送能力。
- [ ] 新客户端合同移除学习调度请求、响应和页面路由；兼容合同准确描述 410 错误体，生成的客户端、接口文档和运行时校验同步更新。
- [ ] 前端收到旧书签或深链时显示退役说明并返回聊天学习入口；不得展示永久加载、空白页或可操作的幽灵任务。
- [ ] 备份、恢复、账户导出与账户删除对只读历史采用一致策略；恢复旧备份不会重新启用调度器或触发补发提醒。
- [ ] 自动化测试覆盖创建、延期、调整、取消、完成、计划物化、待发邮件取消、SMTP 凭据清除、历史导出、进程重启、旧客户端兼容、重复请求、账户越权、深链和恢复旧备份。

## Verification

- 运行学习教学、复习调度、通知、后台任务、生命周期和账户隔离的单元及集成测试，确认只有调度能力退役。
- 使用冻结时钟和待执行旧任务快照执行升级测试，确认升级前后的任何时间推进都不会发送提醒。
- 对每个旧 API 方法执行合同测试，核对 410、错误码、替代路径以及重复请求无副作用。
- 运行前端路由、导航、深链、类型检查和桌面端端到端测试。
- 执行备份恢复冒烟并观察任务队列、邮件/通知适配器和审计日志均无意外调用；验证恢复后 SMTP 凭据仍不可用且旧历史可导出。

## Out of scope

- 删除通用工作流、运行队列、聊天生成任务或账户级通知基础设施。
- 删除学习模式中的课程计划、随堂测验和教学状态。
- 迁移学习项目文件；该工作属于 Issue 02。
- 物理删除尚需保留以兼容旧备份的历史表。

## Agent notes

- “任务安排”在本 Issue 中特指学习复习调度，不等同于所有后台任务。
- 410 兼容窗口至少跨一个可观测发布周期；用调用指标判断旧客户端是否仍在使用，不能凭猜测提前移除。
- 若现有实现仅使用内存存储，也要验证重启、队列和恢复路径，不能据此省略迁移审计。
