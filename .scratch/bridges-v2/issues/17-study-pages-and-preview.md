# 17 — 学习模式书页识别与预习

**What to build:** 用户在新聊天中选择学习模式，按顺序上传本节书页照片后，可得到可追溯的识别范围和暂不要求回答的预习问题。

**Blocked by:** 02 — 可恢复的对话运行；04 — 自然表达与专用人味化退出；05 — 聊天照片附件；09 — Qwen 凭据与主模型配置

**Status:** ready-for-human

**实施前必读：** [ADR-0030](../../../docs/adr/0030-v2-campus-assistant-and-approved-desktop-interaction.md)、[V2 设计索引](../../../docs/v2/README.md)及索引所列六份设计文档；先核对阻塞票已验收。

**编排合同：** 独立学习图从 `awaiting_pages → recognizing → preview → tutoring` 推进，此票交付前面三阶段及进入辅导的稳定状态。`study.recognize → study.map → study.preview` 分别检查页序／清晰度／同节归属、将知识点绑定页码与片段、生成覆盖重点的预习问题。图状态保存小节 ID、有序页 ID、识别片段、知识点覆盖、预习问题、当前阶段和等待原因；原始照片只存于会话附件库，检查点只存引用。关键处不清时停在待补拍等待，不推进或虚构知识点。

- [x] 新聊天右上角可选学习模式；首条带合格照片的消息成功创建会话时锁定模式，之后只显示只读标识，服务端拒绝模式变更和日常模块 ID。
- [x] 首轮纯文字或仅文件不能启动学习；发送失败保留模式、文字、照片和页序，已成功发送的多页照片归属本会话。
- [x] 历史侧栏标注会话模式；学习阶段条显示当前识别／预习／辅导等状态但不能点击跳阶段，已建立的会话只显示只读模式标签。
- [x] 每页识别文字、公式、图表及位置并合并知识范围；关键处模糊时指出页号和位置，等待补拍或标明为用户补录的文字。
- [x] 预习问题覆盖本节重点且明确暂不要求回答；阶段与页级证据在刷新后恢复，他人不能访问照片或检查点。
- [ ] 用多页、模糊公式和跨学科材料验证识别质量；模型或 OCR 失败不推进阶段或伪称已识别。
- [x] 同一小节在预习或辅导前可补页；重复书页有明确提示，页序变更和补录来源在重新打开会话后仍可辨认。
