# 03 — 长对话上下文

**What to build:** 用户在长对话中引用早先说过的内容时，助手能在实际模型预算内找回相关原文，并说明回答依据。

**Blocked by:** 02 — 可恢复的对话运行

**Status:** ready-for-agent

**实施前必读：** [ADR-0030](../../../docs/adr/0030-v2-campus-assistant-and-approved-desktop-interaction.md)、[V2 设计索引](../../../docs/v2/README.md)及索引所列六份设计文档；先核对阻塞票已验收。

**跨票接缝：** 编译器以原始消息为权威源，统一接收带来源的当前附件、最小画像、知识库片段和经核验的工具结果；本票先以普通聊天贯通近期及旧消息，`05`、`07`、`08` 和模块票分别接入其真实输入，不能另造互不兼容的上下文拼装链。

- [ ] 每轮按锁定模型的已验证窗口编译当前请求、近期消息、旧消息摘要及必要原文，保留输出与工具预算；原始消息完整保存。
- [ ] 动态预算明确预留系统规则、输出、工具及图片成本；编译记录模型 ID、预算版本、摘要版本和实际采用的原文消息 ID。
- [ ] 摘要记录其来源消息范围；用户引用早先实体或约定时，能补回相关原文并记录本轮使用的消息 ID。
- [ ] 预算不足时先裁掉低相关材料，不丢当前请求或已取得的关键证据；找不到旧原文时承认不确定并询问。
- [ ] 私人会话材料不会整体发送到公开检索服务，跨账户历史不可召回；模型切换后下一轮重新计算预算。
