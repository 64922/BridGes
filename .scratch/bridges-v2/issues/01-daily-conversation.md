# 01 — 日常普通对话

**What to build:** 用户新建日常陪伴会话后，可进行普通聊天、重开会话并查看完整消息；普通请求不会暗中启动专用模块。先交付可用的日常模式，学习模式在对应切片验收后开放。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**实施前必读：** [ADR-0030](../../../docs/adr/0030-v2-campus-assistant-and-approved-desktop-interaction.md)、[V2 设计索引](../../../docs/v2/README.md)及索引所列六份设计文档；先核对阻塞票已验收。

- [x] 首条消息成功提交时，服务端在同一事务中创建会话并固定日常模式；发送失败保留草稿，后续模式篡改或不合法模块值被拒绝。
- [x] 无模块的消息可生成、保存并在重开会话后继续普通对话；服务端不根据正文自动启动旧专用能力。
- [x] 新聊天发送前不产生会话 ID；输入框支持 Enter 发送、Shift+Enter 换行，发送失败保留文字，已登录账户之外不能进入会话页。
- [x] 历史会话及旧结果仍能按原样阅读和导出，新旧消息的模式与版本不会被迁移改写。
- [x] 数据变更具备备份、数量对账和失败恢复验证；新会话与消息按稳定账户 ID 隔离。
