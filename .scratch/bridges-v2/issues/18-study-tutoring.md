# 18 — 本节辅导

**What to build:** 用户带着预习问题学习时，可针对本节书页自由提问，并在需要时追加同节照片继续辅导。

**Blocked by:** 03 — 长对话上下文；07 — 知识库检索与通用 OCR；17 — 学习模式书页识别与预习

**Status:** ready-for-human

**实施前必读：** [ADR-0030](../../../docs/adr/0030-v2-campus-assistant-and-approved-desktop-interaction.md)、[V2 设计索引](../../../docs/v2/README.md)及索引所列六份设计文档；先核对阻塞票已验收。

**编排合同：** `study.tutor` 从当前问题编译最相关的本节页级证据，再按需补充同账户知识库、Tavily 或模型知识；页内事实与外部补充分别标记。追加书页重新进入识别与知识点合并，成功后返回辅导，保留既有问答与来源。超时、识别失败或不同小节归属未确认时停在原阶段，等待重试或澄清。辅导问答和引用进入学习检查点供后续复盘与总结使用。

- [x] 辅导优先引用本节书页页码或片段，解释通俗且可追溯；知识库、联网资料及模型知识作为补充时分别标明来源。
- [x] 用户可追加同节照片并更新知识范围；明显不同小节的照片先澄清归属，不混入原小节。
- [x] 书页未覆盖或关键内容不清时明确缺口并要求补页或补文字，不把补充材料冒充书页原文。
- [x] 辅导问答及阶段在重开后恢复，失败重试不重复绑定页或写问答；跨账户材料不可引用。
