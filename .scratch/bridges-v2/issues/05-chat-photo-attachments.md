# 05 — 聊天照片附件

**What to build:** 用户可在日常聊天中添加、预览和排序多张照片并就其内容提问；附件只属于该消息和会话。

**Blocked by:** 02 — 可恢复的对话运行

**Status:** ready-for-agent

**实施前必读：** [ADR-0030](../../../docs/adr/0030-v2-campus-assistant-and-approved-desktop-interaction.md)、[V2 设计索引](../../../docs/v2/README.md)及索引所列六份设计文档；先核对阻塞票已验收。

- [ ] 桌面端支持选择、拖入及粘贴图片；发送前可预览、移除、调整页序，键盘也能完成排序。
- [ ] 缩略图显示文件名、类型和页序；不支持类型、超限、读取失败或重复页在对应附件旁显示中文原因，不清空其他草稿。
- [ ] 上传草稿经类型、体积和账户校验；失败或发送失败保留文字、照片与顺序，成功后幂等绑定消息和会话。
- [ ] 图片确实进入本轮多模态回答；纯附件消息可发送并由助手询问用途，处理前不显示为已识别。
- [ ] 他人无法读取附件；聊天照片不进入全局知识库，也不弹出加入知识库的建议；删除、导出及过期草稿处理符合会话数据约束。
