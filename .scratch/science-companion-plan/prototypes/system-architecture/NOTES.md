# 原型结论

状态：用户已于 2026-07-24 接受默认组合

## 当前观察

- 私人原件和项目副本可以保持不同对象 ID 与不同授权域。
- 账户切换会重建作用域，用户 B 无法读取用户 A 的私人原件。
- 撤权会使旧运行不能提交，并推进项目密钥时期。
- 删除墓碑优先于离线编辑，旧操作进入隔离而不复活对象。
- Redis、Qwen 和沙箱故障可以按能力降级；PostgreSQL/授权不可用时必须失败闭锁。
- Conda `agent` 只出现在本地开发模式；四种生产模式共享业务状态与健康语义。

## 用户裁决

用户接受以下默认组合：

> 设备侧个人保险库 + Next.js + FastAPI 领域模块化单体 + PostgreSQL/RLS/FTS/pgvector + Temporal + Redis 非权威缓存 + S3 + 独立 Linux 沙箱；Conda `agent` 仅用于本地开发，生产使用手动分进程、统一 CLI、Docker、Podman 四种同合同路径。
