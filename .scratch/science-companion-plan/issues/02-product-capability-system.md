# 定义成熟产品的能力体系与边界

Type: prototype
Status: resolved
Blocked by: 01

## Question

围绕核心用户、科学成长循环和“全局伙伴 + 项目工作台”，成熟产品应包含哪些一级能力、二级功能、跨模块闭环、用户任务和明确非目标？如何组织功能才能同时覆盖长期陪伴、科学学习、科学表达、可信校验与多模态创作，而不形成拼盘？

## Answer

完整结论见 [成熟产品能力体系与边界](../decisions/02-product-capability-system.md)。

用户确认采用组合结构：以“全局科学伙伴 + 科学项目空间”为用户产品主结构，以“科学成长循环”为跨模块业务闭环，以“四条主链能力地图”为内部规划模型。产品具有九类一级能力，并增加多用户认证门、逐用户画像与学习路径隔离、参考 `teach` 的长期教学闭环；本地开发使用 Conda `agent`，生产独立支持手动分进程、统一 CLI、Docker 和 Podman。
