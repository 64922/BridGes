# 细化证据化画像、长期记忆与授权治理

Type: research
Status: resolved
Blocked by: 01

## Question

证据化画像、候选画像、知识掌握度、学习记录、会话记忆、项目记忆和用户明确保存的事实应如何区分？需要哪些数据结构、晋升与衰减规则、任务切片策略、用户控制、版本回滚、删除语义、敏感信息限制、多用户逐账户隔离和纵向评测，才能形成可信的长期陪伴闭环？

## Answer

完整研究见 [证据化画像、长期记忆与授权治理研究](../research/04-profile-memory-governance.md)。

结论：系统采用相互独立但可追溯的学习证据链、画像断言链和记忆使用链。原始画像观察与学习记录是版本化证据，证据化画像、知识状态和学习路径是可撤销、可重算的派生判断；会话记忆、项目记忆、用户置顶事实、偏好和短期情境信号具有不同作用域，不能混入一个通用 `memory`。任何个性化都必须先编译为绑定单次运行的最小授权记忆切片；Qwen 只能提出候选、评估开放表现和执行受约束表达，不能自行晋升画像、扩大授权、恢复删除或查询全量记忆。删除沿出处图级联到派生物、索引、向量、缓存、队列、同步副本和备份计划，权限或隔离异常时必须停止个性化或闭锁。
