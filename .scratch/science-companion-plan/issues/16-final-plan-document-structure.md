# 确定最终规划书的章节编排、图表与附录结构

Type: prototype
Status: resolved
Blocked by: 01, 02, 03, 04, 05, 06, 07, 08, 09, 10, 11, 12, 13, 14, 15

## Question

全部核心产品、可信体系、画像学习、表达、多模态、编排、前端、评测、架构、协作、领域包和开发路线决策均已形成后，最终《科教智能体项目规划书》应如何编排，才能既全面覆盖比赛硬约束，又能直接指导产品、研发、专家治理、测试评测和部署运维？请形成可评审的目录原型、章节权重原则、跨章节去重与引用规则、需求—决策—章节覆盖矩阵、必备架构与流程图清单，以及数据字典、接口合同、评测矩阵、风险、来源和部署手册等附录结构；不得包含作品演示、比赛答辩或宣传内容。

## Answer

采用组合式文档结构：A“决策与系统蓝图”的五部二十二章作为正文权威骨架；B“科学成长旅程”的六条黄金路径进入第 5 章，并作为各章的路径位置导航；C“评分证据与验收”的需求—章节—证据矩阵进入第 2 章，完整追踪分别进入附录 B、H、M。

正文按“方向与约束—产品与体验—可信智能与治理—系统工程与生产—评测与演进”递进，规划 25 张必备关系图和 13 项附录。每个规范概念只有一个权威章节；其他章节通过稳定 ID 和摘要交叉引用。完整目录、权重、去重规则、覆盖矩阵、图表、表格、附录和文档质量门见[最终规划书章节编排决策](../decisions/16-final-plan-document-structure.md)，经用户确认的三种结构对比见[最终规划书结构 UI 原型](../prototypes/final-plan-document-structure/README.md)。
