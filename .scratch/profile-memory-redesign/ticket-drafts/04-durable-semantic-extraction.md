# 04 — 让自然自述形成可恢复的长期记忆

**What to build:** 用户自然说出姓名、习惯、兴趣或时间约束后，后台在回答正常完成后整理，页面如实显示结果，后续使用已提交事实；重启不漏记或重复记。

**Blocked by:** [03 — 开放记忆管理与唯一写入](03-open-memory-manual-roundtrip.md)。

**Status:** needs-triage

**发布状态：** 待审核草稿，尚未发布或实施。

**对应合同：** D02、D03、D08、D11；T01、T02、T03、T15、T17。参见[定稿](../PRD.md)、[共同执行约束](../README.md)。

## 用户演示

「我在学线性代数，每晚只能抽出半小时」正常获得回复，后台保存两项完整信息；重启后仍能查看，重复完成事件不新增副本。

## 依赖与实施范围

03 提供开放提案的唯一提交目标和基础管理。

- 替换固定句式/四维入口否决和明确自述仅走规则分支；有限的新消息及相关旧记忆交给语义提取，支持一条消息多项事实。
- 使用实际生产运行组合，不能测试提取器正确而运行时仍选旧分支；复用运行模型快照、网关和持久队列。
- 回复正常终态与任务登记一致；模型调用不占写事务，失败或停止轮不登记普通提取。
- 服务定位单消息证据引用并核验主体、否定、时间、条件及语义支持；事实正文不再要求逐字原文子串。
- 任务状态区分无可记事实、已提交、暂缓和失败；实现有界窗口、进度、有限重试、取消、背压和诊断。

## 验收标准

- [ ] T01–T03 从实际入口完成后台保存，不能用新增逐例正则代替语义能力。
- [ ] 普通琐事、行为推测、助手建议、敏感自述和短期情绪不自动长期化。
- [ ] 提交前重查来源、用户权威、账户控制和目标版本；模型只提出候选。
- [ ] 回复不等待普通整理，本轮自述仍从当前对话使用，跨会话只使用已提交内容。
- [ ] 重复事件、任务租约/重试和重启不重复写入；失败不消费未完成窗口。
- [ ] 模型超时、合同错误、提交错误与无信息分别反馈，未保存不宣称已记住。
- [ ] 新任务与状态有账户删除、导出、恢复、脱敏日志和适用 UI 状态验证。

## 验证与交付

正常/失败/停止轮、重复消费、超时及 worker 重启集成测试；用真实模型对照 01 的单消息语料。交付提案合同、证据结果、可恢复进度和状态读投影；05 在同一链路扩展多来源。

## 明确不做

不让模型故障放行写入，不拼接原文兜底成事实，不声明尚未支持的材料授权。
