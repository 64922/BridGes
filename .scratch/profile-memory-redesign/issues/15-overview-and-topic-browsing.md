# 15 — 提供有依据的整体概览与开放主题浏览

**What to build:** 用户能查看系统对自己的整体了解，定位依据并修正错误，按实际主题查找条目；修改后不继续展示过时概览。

**Blocked by:** [13 — 事项和近期上下文](13-ongoing-items-continuity.md)。

**Status:** ready-for-agent

**发布状态：** 2026-10-15 用户已确认拆分与依赖，正式发布；尚未实施。

**对应合同：** D09、D11；T18、T20。参见[定稿](../PRD.md)、[共同执行约束](../README.md)。

## 用户演示

进入「关于我的记忆」查看整体概览、进行中事项和具体条目。点击「每晚半小时」可定位依据并修改；旧概览立即失效，更新完成后显示新内容。

## 依赖与实施范围

13 提供条目、事项和近期连续性。概览本体无需等待 14；学习内容只在真实对接完成后出现，最终验收再验证组合。

- 从有效事实和事项引用生成简短概览，每项陈述保存依赖条目及版本，不产生新事实。
- 同页组织概览、事项和条目，默认主题作为开放筛选，新主题和无主题条目均可找到；不出现空档案必填槽位。
- 点击概览定位条目依据和编辑入口，保留保存/取消、删除确认和错误恢复。
- 条目、来源、事项、使用控制发生变化时立即失效相关陈述；后台生成以依赖版本提交，避免旧结果覆盖。

## 验收标准

- [ ] 每项概览陈述有可访问事实依据，不出现无证据人格、情绪或能力评价。
- [ ] 未知主题不丢条目，多主题不复制事实，分类调整不改变身份和授权。
- [ ] 编辑/删除后旧概览不再作为当前事实显示，迟到生成不能恢复旧内容。
- [ ] 无记忆、整理中、部分可用、失败和重试状态诚实，加载失败不显示伪造概览。
- [ ] 长条目和多主题在三个既有桌面视口可用，键盘及辅助技术状态完整。
- [ ] 概览不成为提取证据或默认全量上下文，账户和用途边界与原子记忆一致。
- [ ] 新派生状态的迁移、清理、账户删除、重启和重建均有验证。

## 验证与交付

页面编辑、删除、失效与重建竞态的 E2E；核验每项来源、空态及可访问性，运行前端检查与构建。交付最终页面、概览依赖、主题组织与状态合同。

## 明确不做

不新增人格分身、3D 头像或全新视觉体系，不要求用户填满分类。
