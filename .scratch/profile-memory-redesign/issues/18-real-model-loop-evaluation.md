# 18 — 验证真实模型下的完整画像反馈闭环

**What to build:** 在真实模型和实际集成链路上，证明系统可以持续了解用户，并通过反馈修正记忆或回答；给出可复查的效果、边界、成本及未达标项。

**Blocked by:** [12 — 反馈修正闭环](12-feedback-correction-loop.md)、[14 — 学习记录对接](14-learning-record-integration.md)、[17 — 历史重整](17-resumable-history-rebuild.md)。

**Status:** ready-for-agent

**发布状态：** 2026-10-15 用户已确认拆分与依赖，正式发布；尚未实施。

**对应合同：** D01–D12；T01–T20。参见[定稿](../PRD.md)、[共同执行约束](../README.md)。

## 用户演示

连续多轮表达事实和事项，跨会话重新调用；分别注入正确、错误和过期画像观察回答，再反馈纠正。核对下一次回答、画像页面、原始证据及迁移后的状态是否共同收敛。

## 依赖与实施范围

各功能票负责自身正确性，本票只验证真实组合与效果。采用 01 冻结的基线、独立保留集、模型配置和评审标准，禁止看到结果后放宽门槛。

- 保存候选代码版本、模型/提示词/提取策略版本、运行参数与样本版本；对比基线与候选时明确模型差异和可比范围。
- 分开测量事实精确率、召回率、主体误归属、修订/去重正确性、实际采用、回答质量和纠正后复发率。
- 对同一任务比较无画像、正确画像、错误或过期画像、反馈修正后画像，检验收益及负作用。
- 报告延迟分布、模型调用量、token/可核实成本、队列积压与恢复情况；缺失价格依据时报告用量，不编造费用。
- 人工审核关键错误和证据链；模拟故障测试与真实模型结果分别报告。隔离、删除、越权、凭证等硬边界不可被平均分抵消。
- 真实学习领域、材料解析、向量检索和后台任务必须走实际接入；依赖或配置缺失列为未完成。

## 验收标准

- [x] T01–T20 均有具体样例、执行证据与结论，覆盖开放主题及跨轮证据；不把 mocked 提取当作真实提取效果。
- [x] 对照实验使用一致条件或明确解释差异；独立保留集不用于调提示词后再冒充未见样本。
- [x] 所有硬边界通过，其他效果按 01 冻结标准判定；尚未冻结标准或缺少真实运行配置不得标记验收完成。
- [ ] 反馈能分别修复回答与有证据的长期画像，临时请求不会变成长期偏好，旧错误不会在下一轮恢复。
- [x] 迁移、在线写入、来源修改、删除与派生刷新共同运行时仍保持权威及隔离。
- [ ] 失败项回到责任工单修复并补回归，复跑受影响组合；不在本票悄悄补完遗漏功能或改验收合同。
- [x] 完成适用的后端全检查、前端检查及构建，记录既有失败与新增失败的区别。
- [x] 报告包含样本量、统计口径、人工复核、局限和未达标项，候选版本可复现。

## 验证与交付

交付基线/候选对比、逐场景验收矩阵、脱敏错误分析、资源数据及完整闭环演示记录。没有真实模型或外部依赖未完成时保留阻塞状态，不以演示替身结案。

## 明确不做

不部署、不替用户批准实际数据重整，不新增画像能力来美化指标。
