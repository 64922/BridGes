ADRs: [ADR-0001](../../../docs/adr/0001-chat-first-product-surface.md), [ADR-0016](../../../docs/adr/0016-incremental-vertical-replacement.md), [ADR-0023](../../../docs/adr/0023-desktop-only-deployment-and-use.md)

## What to build

以 [ChatGPT](https://chatgpt.com/) 电脑端当前页面作为信息架构、可折叠侧栏、聊天区、输入区、消息操作和账户菜单的布局与交互模板，先形成带日期的行为对照基线，再建立 Claude-inspired 的温暖、克制、高可读性美术语言。所有品牌图形、Logo、模块图标、令牌和组件外观必须为 BridGes 原创，并落到可运行的登录、注册、聊天内容页、列表页、详情页和设置页桌面模板中，供后续功能 Issue 直接复用。

## Acceptance criteria

- [x] 形成带采集日期的中文参考矩阵，逐项记录 `https://chatgpt.com/` 电脑端的页面骨架、侧栏、输入区、消息流、建议入口、搜索和账户菜单行为；对无法访问或地区差异有明确说明。
- [x] 参考矩阵明确区分“借鉴的布局/交互”与“禁止复制的商标、Logo、品牌图形、插画、专有文案和像素级视觉细节”。
- [x] 建立 Claude-inspired 的颜色、字体、层级、留白、圆角、阴影、边框、动效、焦点、成功/警告/错误状态令牌，并通过对比度检查。
- [x] 设计表达“连接用户与知识之桥”的原创 BridGes Logo，交付横向完整版、独立图标版、单色版、浅色背景版、深色背景版及常用桌面尺寸。
- [x] 设计统一原创图标集，至少覆盖 Logo/新聊天、搜索、收起/展开、本地知识库、学习项目、任务安排、插件、用户画像、最近、账户、上传文件/图片、论文搜索、文章人味化、生涯规划、听写、发送、复制、重试、反馈、朗读和状态提示。
- [x] 可运行桌面模板覆盖登录、注册、聊天内容、列表、详情和设置页面；使用相同导航、表单、卡片、菜单、对话框和反馈组件，不出现“将在这里呈现”等占位页面。
- [x] 每类页面模板都有真实的 loading、empty、error、permission/unauthenticated 和正常内容状态，使用清楚一致的中文文案；状态不能只靠颜色表达。
- [x] 仅用键盘即可遍历模板中的导航、表单、菜单、对话框和主要操作，焦点顺序、可见焦点、Esc 关闭与焦点归还正确。
- [x] 在约定的电脑端视口进行视觉回归；长中文、代码、公式、表格、文件名和错误信息不遮挡主要操作。

## Verification

```powershell
npm --prefix apps/web run typecheck
npm --prefix apps/web run build
npm --prefix apps/web run test:e2e -- --project=chromium
```

人工验收：在电脑端逐页对照参考矩阵、Logo 资产清单、图标清单、深浅主题与键盘路径；确认视觉具有 BridGes 原创性，而非 ChatGPT 或 Claude 的品牌复制品。

## Non-goals

- 不复制 ChatGPT、OpenAI、Claude 或 Anthropic 的商标、Logo、品牌插画和像素级组件。
- 不在本 Issue 完成所有业务后端；模板状态由后续纵向 Issue 接入真实数据。
- 不设计、实现或验收移动端、响应式移动布局、移动抽屉和触摸手势。

## Comments

参考网页会变化，因此行为基线必须记录日期并进入仓库。后续页面 Issue 必须复用本 Issue 的令牌和组件，同时各自交付完整业务状态，不能把模板当作最终空壳。

**修订（2026-08-02，按产品负责人复核意见）**

依据 1.txt 标准与 ChatGPT 桌面布局对模板做了第二轮修订：
- 聊天页顶部新增「日常陪伴 / 学习模式」切换（按对话持久化到本机，ADR-0022 的输入区位置调整为页面顶部，以负责人要求为准）。
- 移除全部页面模板右上角的「正常/加载中/空/错误/未登录/成功/恢复」状态按钮排；状态改由系统行为自动转换（打开对话→加载→正常、失败→重试→恢复、保存→成功），开发验收改用 URL 参数 `?state=` 落在指定状态。
- 空白新对话重排：5 条学习名人名言轮播于输入区上方，输入区居中，下方给「论文搜索 / 文章人味化 / 生涯规划助手」功能推荐；输入区左侧「+」弹窗承载「上传文件/图片、论文搜索、文章人味化、生涯规划助手」，听写按钮移到发送按钮左边。
- 侧边栏补齐 1.txt 模块：本地知识库、学习项目、任务安排、插件、用户画像，均链接到列表模板对应分区并高亮当前模块。
- 账户菜单改为「切换账号 / 密钥设置 / 个人资料 / 退出登录」；设置模板改为 `?section=` 分区（个人资料 / 密钥设置 / 外观 / 账户与安全 / 危险区），新增密钥设置分区（Qwen API 密钥本机持久化、掩码显示、未配置提示功能不可用）。
- 顺带修正逻辑漏洞：登录接受用户名或 QQ 邮箱（此前只接受 QQ 邮箱，违反 ADR-0003）；侧栏账户名与个人资料修改同步；危险区清除同时移除本机密钥。

已完成（2026-08-02）：实现与双轴代码审查（Standards + Spec）修复完毕，等待人工视觉验收。

**工作内容总结**
- 建立带日期的 ChatGPT 电脑端中文行为矩阵；匿名一手页面和 OpenAI 官方更新记录可访问，登录态账户菜单仍明确标注需人工复核；文档区分可借鉴的信息架构/交互与禁止复制的品牌资产和像素细节。
- 建立温暖、克制、高可读的深浅主题令牌及原创 Logo、完整图标集、SVG 变体和 16–512 px 电脑端 PNG；`scripts/check_contrast.py` 的 37/37 对组合通过 WCAG 阈值。
- 交付开发态登录、注册、聊天、列表、详情、设置六类电脑端模板和共享导航、表单、卡片、菜单、对话框、反馈组件；模板在生产模式统一重定向到 `/`，不形成生产 Stub。
- 页面覆盖正常、加载、空、错误、未登录/权限、成功、恢复状态；文件选择、语音听写/朗读、复制、列表操作、主题和资料持久化、模板数据清除、内容完整性检查均为真实浏览器或本地行为，不冒充后端成功。
- 键盘覆盖 Enter/Shift+Enter/Esc、导航、账户与条目菜单、注册表单、对话框焦点陷阱和焦点归还；视觉回归覆盖六类页面 × 1280×720、1440×900、1920×1080，且只保留电脑端 Desktop Chrome 测试。

**代码审查 bug 修复总结**
- Standards：模板改为仅开发态可访问；移除领域能力普通主导航，恢复“新聊天”唯一默认入口；删除超范围 `apple-touch-icon.png` 和遗留移动端 E2E。
- Spec：补齐成功/恢复状态和错误恢复路径；补齐 Esc 停止生成、键盘菜单/表单/Logo 路径与六页三视口快照；移除注册条款范围蔓延。
- 交互真实性：修复对话框输入时焦点跳回、深色 Logo 不可见、主题刷新丢失、剪贴板失败误报成功；将演示附件、听写、朗读、反馈、资料保存、密码流程、删除和索引操作改为真实或明确的本地开发模板行为。
- 回归稳定性：限制本地 E2E 为 4 workers，避免 Windows 上 Next 开发编译的连接重置竞态。
