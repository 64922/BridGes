# 30 — 交付听写与单条回答朗读
Status: ready-for-human
Blocked by: 10, 11, 13
Covered requirements: CHAT-05, MODEL-01, MODEL-03, IMP-03, SCORE-02, SCORE-03, DESKTOP-01
ADRs: [0006](../../../docs/adr/0006-one-model-snapshot-per-capability.md), [0009](../../../docs/adr/0009-fixed-model-and-provider-matrix.md), [0015](../../../docs/adr/0015-minimum-cloud-disclosure.md), [0023](../../../docs/adr/0023-desktop-only-deployment-and-use.md)

## What to build

在真实聊天链路中交付“录完再转写”的 Qwen 听写与单条助手回答按需朗读。听写固定使用 qwen3-asr-flash-2025-09-08：用户开始录音、停止后提交完整音频、收到可编辑文本，再自行决定是否发送，绝不自动发送。朗读固定使用 qwen3-tts-flash-2025-11-27：每条助手回答都提供播放、暂停、继续和停止操作，并清楚呈现生成、可播、失败和重试状态。两项能力共用当前账户百炼密钥和独立真实探测；不可用时明确停用，不得切换模型或以浏览器模拟结果冒充成功。

## Acceptance criteria

- [x] 聊天输入区提供键盘可达的开始录音、停止、取消和重新录制操作，并清楚显示录音时长、麦克风权限拒绝和设备不可用状态。
- [x] 停止录音后才向固定 ASR 快照提交完整音频；转写结果进入输入框且可自由编辑，不自动产生用户消息。
- [x] 用户取消录音或转写时不会遗留待发送文本、跨账户临时音频或后台孤儿任务。
- [x] 每条已完成的助手文本回答可独立生成朗读，并支持播放、暂停、继续、停止和同一条回答的受控重试。
- [x] 页面同时只管理一个清晰的活动播放会话；切换回答、离开对话或切换账户时，旧播放状态安全停止且不串号。
- [x] ASR 与 TTS 分别执行真实能力探测，固定模型标识进入运行记录；失败只重试同一快照，能力不可用时禁用入口并说明原因。
- [x] 百炼密钥、完整画像和无关聊天历史不进入音频请求；临时音频和生成音频遵循当前账户最小留存及清理规则。
- [x] 刷新页面后不会伪造仍在录音或播放的状态，已保存消息及其可重新请求的朗读入口保持一致。

## Verification

- [x] 为录音状态机、完整音频提交、转写回填、编辑后发送和取消清理建立自动化测试。
- [x] 为朗读生成、播放、暂停、继续、停止、切换回答和失败重试建立浏览器端到端测试。
- [x] 使用配置了真实账户密钥的能力探测验证两个固定快照，记录模型标识和明确失败语义。
- [x] 覆盖麦克风拒绝、空音频、超限音频、网络中断、密钥失效、刷新和跨账户切换。
- [x] 在受支持桌面浏览器中仅使用键盘完成一次听写编辑发送和一次回答朗读控制。

## Non-goals

- 不提供实时转写、全双工语音聊天、持续监听、唤醒词或电话式语音模式。
- 不提供用户选择 ASR、TTS、音色或其他模型的入口。
- 不开发手机录音、触屏手势、PWA 后台音频或原生音频应用。
