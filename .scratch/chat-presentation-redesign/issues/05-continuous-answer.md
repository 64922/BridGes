# 05 — 让普通回答形成连续可阅读正文

**What to build:** 用户在真实流式回答和历史回答中连续阅读段落、标题、列表及已有富内容，用户消息保留气泡，助手正文不被外层卡片包裹。

**Blocked by:** 02 — 整理消息呈现职责，保留全部结果投影

**Status:** ready-for-human

> 已于 2026-10-17 经用户确认发布。仅在本票所有阻塞项完成验收后开始；无阻塞票可立即领取。设计与原型已批准，无需重新决定视觉方向。

## 当前事实与动机

当前历史组装主要将内容作为保留换行的文本段落，需确认现有富文本能力与依赖，避免只为原型做静态排版。

## 工作范围

- 为普通对话建立真实内容到连续正文的渲染路径，并与历史读取共用。
- 保留文本原文及复制、朗读所需语义；支持设计需要的标题、列表、代码、表格及现有公式能力。
- 在协议与视图边界处理不可信内容。新增成熟渲染依赖前先核查现有依赖、类型定义及许可，不手写通用 Markdown 解析器。

## 验收标准

- [x] 同一回答在流式结束、刷新和重新打开后内容一致，不重复段落，不丢换行或标点。
- [x] 助手正文无统一大卡片；通过标题、段落和留白组织阅读，用户消息保留轻量气泡。
- [x] 流式片段尚未闭合的标记不会导致页面崩溃或把后续整段吞入错误容器。
- [x] 代码、表格与长链接在自身范围内滚动或换行，不撑破主阅读列。
- [x] 用户文本按文本处理；助手内容中的脚本、危险 URL 和原始 HTML 不成为可执行内容。
- [x] 复制与朗读取得完整可读回答，不混入工具标签或隐藏的流程日志。
- [x] 不擅自把用户上滚位置拉回底部，流式更新不抢焦点、不逐 token 播报。
- [x] 普通对话可独立演示；尚未迁移的模块投影仍可读，不在本票一刀切删除。

## 验证方式

使用真实保存的多段回答回放流式与历史两条路径，覆盖长文本、未闭合标记、代码与表格、恶意内容、滚动位置和复制。新增缺陷先复现再修复。

每票完成受影响行为的测试与项目要求的检查；涉及前端必须完成生产构建。复用已有可用依赖，不例行重装。外部依赖不可用、既有失败和本票新增失败分别记录，未验证项不得标为通过。最终整合票不能替代本票自身的验证。

## 范围外

不重写模型输出策略、引用生成协议或各业务模块，不把模拟示例当真实回答。

## 实施交接（2026-10-17）

### 实际变更

- 新增 `MarkdownBody`，以 `react-markdown@10`、`remark-gfm`、`remark-breaks`、`rehype-sanitize` 统一渲染流式与历史助手正文；依赖均为 MIT。
- 历史与流式消息组装不再预生成 `<p>` 和光标节点：`buildThreadMessages` 只保留 `plainText`，`composeConversationMessages` 移除 `streamCursorClassName` 参数；`AssistantBody` 在无专用 `body` 时统一走 `MarkdownBody`。
- 用户消息继续使用 `PlainTextBody`，保留轻量气泡；助手正文无统一大卡片。
- 支持标题、段落、单换行、有序/无序/任务列表、引用、围栏代码、GFM 表格、链接、粗体/斜体/删除线与分隔线；代码和表格自身滚动，长链接与长代码换行，列表符号显式恢复。
- 安全边界：原始 HTML 不进入可执行 DOM，并经 `rehype-sanitize` 清理；`javascript:` 等危险协议不保留；正文远程图片不自动加载，降级为链接或替代文本。
- 复制继续使用 `message.plainText` 原文，保证与持久化/SSE 内容逐字一致；朗读入口按 ADR-0030 保持退役，不新增按钮，仅保留可被后续朗读消费的纯文本语义。
- 新增 `MarkdownBody` 单测、消息呈现边界单测和真实 API/SQLite/SSE 浏览器验收；更新历史/流式组装单测。

### 格式、清理边界与容器归属

- 已支持：标题、段落、单换行、列表、引用、围栏代码、GFM 表格、链接、强调、删除线、分隔线。
- 公式：现有链路没有 LaTeX 排版器，本票按 Markdown/纯文本原文保留公式内容（如 `$...$`、`E = mc^2`），未引入 KaTeX；需要数学排版时另行评估。
- 图片：正文 Markdown 图片不作为 `<img>` 自动请求，远程图片降级为链接，无 URL 时保留替代文本；媒体生成结果、检索引用、思考、职业过程等仍由既有专用投影容器承载，本票未删除。
- 纯文本：`plainText` 是复制和后续朗读的唯一语义来源；不改聊天协议、不改数据库 schema、不迁移数据。

### 遗留限制

- 未做 KaTeX 数学排版；公式按 Markdown 文本保留。
- 未闭合围栏在闭合前仍按 CommonMark 视为代码块；闭合后后续段落正确退出代码容器，页面不崩溃。这是解析器标准行为，不是吞段缺陷。
- 远程 Markdown 图片不自动加载，只显示链接或替代文本，属于安全边界。
- 朗读按钮仍为退役状态，本票只验证复制与纯文本语义。
