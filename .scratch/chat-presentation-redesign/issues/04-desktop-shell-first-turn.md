# 04 — 交付新对话布局与真实首轮发送

**What to build:** 用户进入新的简洁桌面对话页，在输入区选择模式、发送第一条消息，并自然进入同一风格的正式会话。

**Blocked by:** 01 — 整理对话运行职责，保持发送与恢复行为；03 — 整理输入区职责，保持发送、附件与听写能力

**Status:** ready-for-human

> 已于 2026-10-17 经用户确认发布。仅在本票所有阻塞项完成验收后开始；无阻塞票可立即领取。设计与原型已批准，无需重新决定视觉方向。

## 当前事实与动机

采用已验收原型的侧栏、顶部栏、静态欢迎区与输入列；正式入口必须接入现有认证、最近会话和首轮创建。

## 工作范围

- 调整正式主对话的侧栏、顶部、欢迎区与输入区，正文和输入保持限宽对齐；使用现有 BridGes 品牌。
- 将模式选择放入输入区，静态欢迎替代轮换名言；轻量建议只调用已支持的实际入口。
- 对话开始后输入区沉底，消息区独立滚动；保留搜索、知识库、画像、账户及历史菜单的真实导航。

## 验收标准

- [x] 未发送时可选择日常陪伴／学习模式，首轮服务端锁定后只能显示固定模式，刷新与重新打开一致。
- [x] 首轮成功创建后最近会话出现且标题正确；失败时用户仍看到草稿、具体反馈和可用的恢复入口。
- [x] 无轮换名言、营销横幅、功能卡片网格或原型体验菜单；不复制示例账户和静态历史列表。
- [x] 侧栏折叠、展开、历史搜索和既有重命名／置顶／删除等入口仍可操作。
- [x] 知识库、画像、登录及设置等共享外壳页面不因局部样式修改失去导航或布局。
- [x] 输入区保留附件、模块、已有听写等真实能力，未实现能力不能作为可用按钮展示。
- [x] 1280×720、1440×900、1920×1080 下输入区可见、阅读列限宽，无页面级横向溢出。
- [x] 加载、空态、认证过期、历史加载失败和重试可区分；键盘顺序及焦点反馈可用。

## 验证方式

使用正式认证、首轮创建、持久化与会话路由验证两种模式，刷新后核对模式和最近历史；截图比较首页与首轮后的布局，不只测模板页。

每票完成受影响行为的测试与项目要求的检查；涉及前端必须完成生产构建。复用已有可用依赖，不例行重装。外部依赖不可用、既有失败和本票新增失败分别记录，未验证项不得标为通过。最终整合票不能替代本票自身的验证。

## 范围外

不重做知识库或画像业务页面，不增加移动端产品范围，不改变日常能力启动授权。

## 执行约束

遵循已批准的 ADR-0044、设计原则 0005、本功能 PRD 及仓库准则。在 Conda 的 agent 环境开发。优先复用现有接口与领域能力；只有用例证明现有合同不足时才改协议，并在同票完成服务端、生成类型、消费端和测试。无必要不改 schema，不搬迁数据。

本票必须交付可演示或可验证的完整行为，而不是只有接口、组件或截图。内部路径直接替换，不引入兼容 shim、双写或长期双实现。只修改本票需要的范围；不要在执行中顺便重写业务。

## 完成后的交接

交付三种桌面尺寸截图、首轮成功／失败证据和样式影响范围。

交接记录包含实际变更、验证命令和结果、必要截图／服务证据、遗留限制与回退方式；只有行为验收通过才解除后续票的阻塞。

## 交付记录

### 实际变更

- 新增 `ChatHeader`：新对话显示「新对话」，已有会话显示真实标题；右上角只读展示服务端锁定的模式，不再在输入区上方重复模式标签。
- 重写 `NewChatHome`：静态欢迎（品牌标记、标题、说明）替代轮换名言；三条轻量建议只预填真实入口（论文模块、学习模式、贴吧模块）；首轮失败显示具体错误与「草稿与附件已保留」恢复提示，草稿、附件、模式均保留。
- 模式选择移入输入区工具栏：仅新对话传入 `onModeChange` 时显示；首轮创建中禁用；已有会话不提供切换。`ModeToggle` 紧凑形态只收紧水平内边距，点按目标保持 44px。
- 阅读列与输入列统一使用 `--chat-column-width`（48rem）；空白态垂直居中、短视口可滚动，对话页输入区沉底、消息区独立滚动。
- 移除旧轮换名言、首页右上角模式行及对应孤儿样式；`RotatingQuote` 仅保留在模板页。顶部栏与新聊天专属样式拆分到 `ChatHeader.module.css`、`NewChatHome.module.css`，`chat.module.css` 保持 408 行（低于 500 行上限）。
- 模式标签由 `ModeToggle` 导出单一 `CHAT_MODE_LABELS`；新聊天建议预填与已有草稿用换行分隔；首轮创建中显示禁用的「正在发送」，不再展示无实现的停止按钮。
- E2E：新增 `issue04-desktop-shell-first-turn.spec.ts`（6 项：3 个替身边界用例、三视口布局、长对话滚动、零 mock 真实链路两种模式 + 刷新 + 重新打开 + 删除）；更新 issue12 的首次建会话助手（改用原子首轮 + PATCH 标题）与画像/首页断言、issue13 的静态欢迎/模式可用/附件入口断言，并同步各 spec 的新首页标题；更新 issue38 视觉快照。
- issue12 的画像断言与首轮助手属于 base 漂移的测试维护：旧断言引用已退役的画像分区，旧 POST 建会话已返回 `first_turn_required`；不改业务。
- 未修改 API、协议或数据库 schema。
