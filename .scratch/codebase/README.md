## 执行顺序

优先执行 01 → 02 → 03；画像链为 04 → 05 → 06。两条链没有业务依赖，可独立推进；并行实施时需避免同时修改公共装配代码。

初始可领取任务：01、04。`ready-for-agent` 表示任务描述已具备执行条件，不表示依赖已完成；必须同时检查 `Blocked by`。

每张票据必须独立保持相关测试通过。每次从现有行为进入一条真实调用路径，不单独交付空抽象或仅有测试、没有行为闭环的横向任务。
