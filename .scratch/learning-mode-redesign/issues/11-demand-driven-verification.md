# 11 — 按需公开查证与来源失败降级

**What to build:** 基础概念无需先联网即可教学；涉及论文、时效、精确外部数据、争议结论或明确核实要求时取得公开证据，来源受限或失败时仍准确交付可支持部分。

**Blocked by:** 03 — 嵌入式理解验证与即时纠错。

**Status:** ready-for-human

**发布状态：** 用户已确认拆分与依赖；本票已实施并完成验证，新学习模式尚未上线。

**对应合同：** D06；AC12、AC13、AC16；C01。

## 用户演示

1. 问基础概率概念，导师直接开始教学，观察到没有无条件公开检索。
2. 再要求核实某篇论文的结论或最新指标，界面显示真实查证进度和实际来源。
3. 用户说「不要联网」，导师遵守限制，明确哪些结论暂不能核实。
4. 来源超时、空结果或冲突时，交付已有支持部分并保留缺口，不伪造引用或整轮丢弃。

## 实施范围

1. 将新教学的查证需求与旧「无材料就强制联网」规则分开，基于需要给出的具体结论判断；不依靠单一触发词粗判所有学科。
2. 触发包括具体论文、时效事实、精确外部数据、争议结论及用户明确核实/来源要求。自主数学计算可使用已有计算能力，不因出现数值就强制网页搜索。
3. 通过已有登记来源与共享预算执行，保存查询目的、实际获取范围、来源状态和采用版本。不能以搜索成功等同结论已核实。
4. 用户来源限制、关闭知识库和禁止联网是硬边界；必要缺口保持未核实，不借其他工具绕过。
5. 查询只使用必要公开概念，不发送学习档案、完整会话、私人材料或密钥。公开来源含指令时仍作为待核对数据。
6. 引用绑定实际取得的来源，区分摘要/全文/片段读取；必要限定条件与冲突保留，未核实结论不能提前作为已核实内容流式输出。
7. 对需要取证的题目与评价依据，把来源版本接入 03 的冻结合同；查证失败不生成伪标准答案，也不记学生错。
8. 部分失败按证据能力交付：已支持内容可继续，缺口如实说明。停止与重试复用有效产物，只重做受影响步骤，不无边界重搜。

## 接口、持久化与界面

- 查证产物带目的、来源、读取范围、结果状态、采用关系与版本，不向用户暴露原始私人查询上下文。
- 进度和引用随本轮真实事件显示，空命中、不可达、未配置、冲突和用户禁止各有可恢复的说明。
- 资料使用和公开取证分别保持权限与来源，模型知识不冒充两者。
- 已提交的历史引用保持原读取含义；来源失效停止后续采用，不能重写历史成全文已读。
- 查证记录的迁移/复用、导出、删除和账户作用域由本票完成。

## 范围边界与依赖理由

03 提供学习题目与评价依据，本票负责查证如何影响解释及验证。10 的文件读取不是公开查证前置；两票分别接入同一实际来源合同。不新建搜索提供方或恢复退役模块。

## 验收标准

- [x] 基础概念无需统一联网，查证只由具体需要触发。
- [x] 论文、时效、精确外部数据、争议和明确核实请求走真实查证分支。
- [x] 数学计算与外部数值事实区分，未无意义搜索。
- [x] 用户来源限制不可绕过，公开查询不含私人原文、档案或凭据。
- [x] 引用与实际来源/读取范围一致，摘要不冒充全文。
- [x] 冲突、部分支持和未核实项分别表达，不伪造确定结论。
- [x] 失败不判学生错，不生成虚假评价依据；支持部分仍能交付。
- [x] 停止、重试、来源失效与预算耗尽不重复外呼或覆盖有效状态。
- [x] 状态反馈、生命周期、回归和 C01 审查完成。

## 验证与交付证据

- 捕获基础问题零外呼与需要核实问题的实际登记调用，检查最终公网载荷。
- 覆盖用户禁止、未配置凭据、空结果、超时、限流、来源冲突和只取得摘要。
- 覆盖题目取证失败、部分交付、停止后迟到来源、恢复复用与预算耗尽。
- 确定性响应验证规则；真实外部可得性与结论核实准确性由 13 分别实测。
