# 08 — 跨会话续学、岔题与目标切换

**What to build:** 用户能在新对话接着已有目标学习；临时问题不改目标，明确改学时保存并切换。多个会话同时继续同一目标也不会相互覆盖进展或串题。

**Blocked by:** 04 — 直接讲解、跳过验证与自然小结；07 — 系统性目标与简短学习路线。

**Status:** needs-info

**发布状态：** 票据草稿，等待拆分确认；尚未实施。

**对应合同：** D08、D11、D15；AC06、AC07、AC10；C01。

## 用户演示

1. 昨天暂停线性代数，今天新建学习对话并说「继续上次的线性代数」。
2. 导师恢复正确目标与位置，使用必要前文，不要求重建路线。
3. 学概率时临时问一个 Python 问题，回答后当前目标仍是概率。
4. 明确说「接下来改学 Python」，原目标保存并暂停，新目标成为当前目标。
5. 两个窗口推进同一目标，冲突可见且进展不被静默覆盖。

## 实施范围

1. 以账户内目标引用恢复，识别目标名称、用户明确选择和既有会话关系；多个候选确有歧义时只澄清一个必要问题。
2. 恢复读取已保存的目标、路线、进展、待答处置和必要学习前文。旧会话原消息保持原归属，不搬移或改写消息。
3. 同一对话保持一个当前目标，局部问题与临时岔题允许插入；判别明确切换与顺便提问，不能按最近关键词自动改目标。
4. 切换保存原目标进展与待答处置，暂停原目标并关联新目标；相关状态在一个正确事务边界提交，失败不留半次切换。
5. 待答问题、作答、控制和诊断各自携带原目标/进展版本。切换后的新回答不能填旧题，旧结果不能更新新目标。
6. 同目标跨会话采用版本守卫处理并发；冲突重新读取或要求必要选择，不悄悄覆盖。消息交付与目标进度提交冲突分开显示。
7. 全局目标暂停和各会话当前关联的关系明确。另一会话继续时按最新版本恢复，不以过期状态隐式撤销刚发生的暂停/切换。
8. 删除、取消、不可访问或版本已变化的目标不能从旧缓存恢复；不把未完成控制重试套在后来的目标上。

## 接口、持久化与界面

- 提供本人目标选择与续学投影，隐藏他人目标及无权来源；列表加载、无目标和歧义均有反馈。
- 顶部当前目标、按需展开的路线及暂停/恢复状态由权威关联派生，不依赖客户端自行切名字。
- 沿用学习/日常模式锁定，目标切换不允许把当前对话改成日常模式。
- 恢复提示说明真实位置及待确认项，不宣称跳过内容已掌握；必要前文按上下文预算选择。
- 目标关联和切换事件完成迁移、导出、删除与恢复；保留旧目标和路线版本。

## 范围边界与依赖理由

04 提供暂停、跳过和等待解除，07 提供长期目标及路线。本票不并行推进多路线，不自动替用户恢复某个含糊目标，不增加提醒；有效档案调整由 09 完成。

## 验收标准

- [ ] 新对话可继续正确的本人目标，不重建、不搬移原消息。
- [ ] 多目标歧义有一次必要澄清，未采用无依据默认候选。
- [ ] 临时提问不改变目标，明确切换才保存并暂停原目标。
- [ ] 切换原子提交，待答问题和旧控制不能串到新目标。
- [ ] 两会话并发提交产生正确守卫与反馈，不静默覆盖进展。
- [ ] 暂停与另一会话恢复按最新版本处理，旧缓存不复活已删除目标。
- [ ] 恢复使用必要且有权前文，跳过内容保持未验证。
- [ ] 模式锁定、账户隔离、详情展示和失败/重试一致。
- [ ] 生命周期、合同同步和 C01 审查完成。

## 验证与交付证据

- 完整执行「学习—暂停—新会话续学—临时岔题—明确切换—返回原目标」。
- 在两个会话的目标提交前后设置屏障，覆盖暂停与恢复竞态、同时前进及旧版本重试。
- 覆盖目标删除、候选歧义、跨账户访问、前文预算不足和切换事务失败。
- 交付目标/待答/消息三个版本关系的实际记录和可见界面反馈。
