# 07 — 楼中楼分页保留稳定身份和纠正上下文

**What to build:** 楼中楼首批预览之外的反驳、纠正与补充可以被读取，并与正确父楼层一起呈现在总结依据中。

**Blocked by:** 06 — 普通回复逐页读取并保存可恢复证据

**Status:** ready-for-agent

## 实施边界与关键决策

核实楼中楼独立分页及上游身份，按父楼层维护进度。把普通回复、嵌套回复、父子关联和上下文用途清晰建模，沿用逐页证据保存。

## 验收条件

- [ ] 真实样本至少读取超过首批预览的一条嵌套发言，核对帖子、父楼层、自己的稳定身份和实际时间。
- [ ] 父帖/父楼层不匹配响应被拒绝；被回复对象缺失时保持未知，禁止按展示邻接关系猜作者关系。
- [ ] 每个父楼层独立游标，重复页、删除父楼层、部分失败和取消不会混串或无限翻页。
- [ ] 一条纠正旧说法的嵌套回复连同必要上下文进入总结，引用能定位已读原文，不推导未知作者立场。
- [ ] 身份缺失时如实降级并标记重复组，不造真实ID；预览、已读部分、确认读完的状态可区分。
- [ ] 界面能核对嵌套发言与父上下文；历史无身份材料仍按旧证据读取。

## 验证方式

真实楼中楼协议样本 + 多父楼层/错误归属/重复页回归 + 纠正说法端到端样例。

## 不在本票范围

不以文本哈希作为上游发言身份，不要求每个长帖全量读取才能交付。
