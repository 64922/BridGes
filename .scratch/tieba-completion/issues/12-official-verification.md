**Blocked by:** 04 — 打通单话题单帖的真实采集与引用总结

**Status:** ready-for-human

## 实施边界与关键决策

沿用已有来源意图与官方读取链路，对新浏览器证据及预算分类做端到端补齐。官网请求、跳转、原文读取与模型引用遵守同一任务边界。

## 验收条件

- [x] 同一话题“搜集住宿费讨论”不自动访问官网；“核实住宿费规定”才追加允许的官方来源。
- [x] 官方确认必须来自实际读取且适用的官方原文，核对发布日期/生效范围；标题和搜索摘要不足以确认。
- [x] 官网失败、过期或规定冲突时保留贴吧结果并明确未核实，不让局部失败抹掉已取得讨论。
- [x] 官方跳转不越允许来源域，正文中的链接或指令不扩大来源；每次请求和重试进入共享预算。
- [x] 正文与引用详情分别显示网友说法和官方依据；真实公开官方页面与受控过期/失败场景均有记录。

## 验证方式

来源意图成对旅程 + 官方读取失败夹具 + 至少一个真实适用官方来源核对。

## 不在本票范围

不扩展全网核验，不默认将规定类词语判为官方核验请求。
