# 03 — 正确解析带口语前缀的校园通勤请求

**What to build:** 用户输入“我现在想从42栋步行到南区25栋”时，系统准确使用 42 栋和南区 25 栋查询步行路线；地点含糊时沿用现有澄清流程，不把意图前缀发送给地点服务。

**Blocked by:** None — 可立即开始；真实界面的配置后路线链路由 07 等待 02 一并验收。

**Status:** ready-for-human

## 问题与证据

真实解析函数已复现起点为“现在想从42栋”，终点和步行方式正确。截图中的地点查询也包含错误前缀。缺少高德凭据是当次首先暴露的失败，但配置完成后仍可能因错误地点短语无法定位。

## 任务内容

1. 用原始句子建立确定性失败测试，断言起点、终点、出行方式以及实际送入地点查询端口的词。不能只断言解析函数不抛异常。
2. 检查出行方式剥离、句首意图处理、起终点识别的顺序，最小修改使“我现在想从”等口语前缀在位置明确时被识别，而不是对全句任意删字。
3. 覆盖“从42栋步行到南区25栋”“我想从42栋到南区25栋，步行”“42栋到南区25栋”等等价表达；保留南北区、数字、建筑名和用户原始地点信息。
4. 回归只有终点、缺少方式、多个地点候选、上一轮澄清恢复和不同出行方式。缺失信息应询问，不得从错误前缀或未经确认的上下文生成坐标。
5. 通过模块服务验证解析结果确实传入起终点查询与路线请求。学校范围限定可以继续使用现有规则，但不应把“现在想从”等意图词拼进地点。
6. 有效凭据下使用原句查询真实路线，保留来源、时间、路线及多候选选择过程；若具体楼栋无法唯一定位，证明澄清流程正确，不以伪造坐标强行完成。

## 验收标准

- [x] 缺失信息、多候选及澄清恢复仍可用，账户和会话上下文不混用。

### 3. 等价句与负例

等价句（参数化 7 条，断言起终点、方式与方式原话）：`从42栋步行到南区25栋`、
`42栋到南区25栋，步行`、`我想从42栋到南区25栋，步行`、`我现在想从42栋步行到南区25栋`、
`我现在想走路从42栋到南区25栋`、`帮我看看从42栋骑车到南区25栋`、
`我打算今天从42栋骑电动车到南区25栋`。

负例与边界：

- 地名首字与意图词同形不得被吃：`先骕楼到北门怎么走` → 起点 `先骕楼`；`明天广场步行到南区` → `明天广场`；
- 指代不得变成地点（带／不带礼貌前缀）：`我现在的位置到北门怎么走`、`请问我现在的位置到北门怎么走`
  → 仍是「无法定位」澄清；
- 前缀不得当起点：`我现在想去图书馆` → 只问起点；`请问从南区到北区怎么走`、`我们要从南区到北区`、
  `现在从南区到北区` → 起终点 `南区`／`北区`、只问方式；
- 问句尾巴不当前缀：`要多久到图书馆` → 终点 `图书馆`、只问起点；
- 校区词与数字不被误删：`我从南区25栋步行到北区3号楼` → `南区25栋`／`北区3号楼`。

行为对账（探针 `.tmp/issue03/probe.py`，51 句）：修复前后 17 句输出变化、逐条为修正；
其余 34 句逐字节相同，含 `从南区骑车到图书馆要多久`、`走路还是骑车去图书馆`、
`从我这里到北门怎么走`、`这里到北门怎么走`、`从图书馆到我现在的位置`、`要多久到图书馆`、
`要多久能到图书馆`、`先骕楼到北门怎么走`、`明天广场步行到南区`、`我在42栋…`、
`从3号教学楼到25栋宿舍`、`去北区3号楼`。

### 4. 方式剥离、句首意图、起终点识别的顺序

`route.parse` 顺序不变：先 `detect_mode` 剥离方式词（原话保留在 `mode_phrase`），再对
剩余文本做句首意图处理，最后识别起终点。本票只改句首意图处理：按词类（请求语／主语／
时间填充／意愿动词）逐词剥离，**剥到地点写法的句首词（从／到／去／往／前往／走到／骑到）
或位置指代为止**；两者都不是就整体放弃、一字不改。因此不是对全句任意删字，也不会吃掉
地名首字。

### 5. 两轴评审与修正（`5136157`）
