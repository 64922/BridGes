# Issue 01：正确识别 DuckDuckGo 挑战页并阻止错误空结果

Status: ready-for-agent

Type: task

Priority: P0

User stories: US-01、US-05

## What to build

交付一条可演示的学习模式联网纵向切片：当 DuckDuckGo 返回正常结果页时，用户的学习请求能获得可绑定的公开来源并正常教学；当提供方返回 HTTP 202 或伪装成 HTTP 200 的反机器人挑战页时，系统必须把它显示为可恢复的提供方受阻，不得误报为“没有搜索结果”，不得在同一轮内密集重试，也不得伪造引用或推进学习进度。

请求应使用固定、非用户特定的浏览器兼容请求特征；搜索响应应被区分为正常结果、真实空结果、挑战页和无效页。搜索卡、教学卡、回复正文、健康检查和持久化投影必须对同一结果给出一致语义。

## 已验证复现与根因摘要

- 实际运行仓库自带 DuckDuckGo 冒烟后，公开查询 `OpenAI` 返回空列表并使测试失败。
- 对同一请求的只读检查得到 HTTP 202、零个结果链接，正文明确要求机器人完成人类挑战。
- `DuckDuckGoClient` 的默认请求特征为 `python-httpx`；当改用固定的浏览器兼容特征时，相同公开查询可返回正常结果。
- 当前响应校验接受 202，解析器又把“是 HTML 但没有结果节点”直接收敛为空列表；`WebSearchService` 随后将它持久化为 `web_search_no_results`。
- 精确学习请求的确定性全链路替身复现为：4 次请求、搜索状态 `empty`、0 条来源、教学不可靠、回复被加上“本轮未联网核实”。
- 当前健康检查也会把挑战页误报为就绪，因此运行前无法发现该故障。

## 非目标

- 不在本任务中引入或选定结构化备用搜索提供方；该能力由 Issue 02 交付。
- 不在本任务中判定搜索页是否语义覆盖学习目标；该能力由 Issue 03 交付。
- 不删除或隐藏真实联网失败时的“本轮未联网核实”安全提示。
- 不发送完整对话、画像、知识库正文或账户标识给搜索提供方。
- 不通过随机请求特征、无界重试或隐藏挑战来规避提供方限制。

## Acceptance criteria

- [ ] 给定“我想学习Transformer架构的相关知识”且 DuckDuckGo 返回正常结果页时，完整聊天流程产生成功或部分成功的联网投影、至少一条已抓取来源和可绑定引用，不显示“本轮未联网核实”。
- [ ] HTTP 202 挑战页与伪装为 HTTP 200 的挑战页都被投影为稳定错误 `web_search_provider_challenge`，不得投影为真实空结果。
- [ ] 只有经明确识别的正常无结果页才可返回 `web_search_no_results`；其他未知 HTML 必须进入可观测的解析或提供方错误。
- [ ] 发生挑战时，同一次生成运行最多向 DuckDuckGo 发出一次搜索请求，随后进入有冷却时间的提供方受阻状态；用户稍后可显式重试，但系统不在同轮自动攻击性重试。
- [ ] 搜索健康检查复用相同页面分类规则；挑战页、无效页、DNS 失败、超时和限流都不得报告为就绪。
- [ ] 挑战且没有其他证据时，搜索卡和教学卡明确说明提供方受阻及恢复动作，回复仍保留未核实安全提示，不产生任何公开来源引用，不推进教学计划或课时。
- [ ] 回复正文中的未核实提示被规范化为一次，不出现“本轮未联网核实：本轮未联网核实”式重复。
- [ ] 所有 DuckDuckGo 请求使用固定、版本化、非用户特定的请求特征，且继续只接收本地脱敏后的最小公开查询。
- [ ] 日志、指标、审计和错误文本不保存查询正文、挑战页正文、结果正文、账户标识或任何凭据。
- [ ] 公网搜索阶段仍受 8 秒共享墙钟约束，完整前台运行仍在 120 秒硬上限内收敛到终态。

## Test plan

- 使用确定性 HTTP 替身覆盖正常结果页、真实空页、202 挑战页、200 挑战页、无效 HTML 和限流响应，断言响应分类、健康状态和同轮请求次数。
- 在完整聊天编排测试中提交“我想学习Transformer架构的相关知识”，分别断言正常搜索与挑战失败时的消息投影、教学卡、引用、正文和进度。
- 增加前端契约或端到端测试，验证提供方受阻文案、冷却后重试动作、单一未核实提示和无虚假引用。
- 重跑现有查询脱敏、危险 URL、响应上限、账户隔离、教学降级和时延预算测试。
- 保留显式真实 DuckDuckGo 冒烟，将它纳入发布前或定时联网验证；普通单元测试不依赖真实公网。

## Observability & rollback

- 按次记录脱敏的 HTTP 状态类别、页面分类、解析结果数、同轮请求数、冷却状态、阶段耗时和终态错误码，不记录查询或响应正文。
- 为 `web_search_provider_challenge` 提供可聚合的本地计数和健康状态，以便区分真实无结果与提供方受阻。
- 如新请求特征或冷却策略出现回归，可回滚该请求策略并把 DuckDuckGo 显式置为暂不可用；不得回滚“挑战页不等于空结果”这一安全不变量。
- 回滚时保留已持久化的历史投影和审计记录，不重写旧消息。
