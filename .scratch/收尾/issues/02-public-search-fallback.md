# Issue 02：为学习联网交付可观测的结构化备用来源

Status: resolved

Type: task

Priority: P0

User stories: US-01、US-05

## What to build

在 DuckDuckGo 主用搜索之后交付一条可配置、可审计的结构化备用提供方纵向切片。当 DuckDuckGo 正常可用时，仍只使用它；当它返回挑战、限流、连接错误、超时、无效响应，或在有界改写后仍无真实结果时，系统在同一公网阶段的剩余预算内调用一个已登记的结构化备用提供方。用户必须在搜索卡、来源与引用中看到实际使用的提供方，不得默默换源。

用户已批准“DuckDuckGo 主用 + 可配置结构化备用提供方”的方向。实现必须同步修订 ADR-0009、ADR-0025 与 ADR-0026，明确提供方顺序、共享阶段预算、失败语义、凭据边界、来源披露与回滚方式。备用提供方必须来自显式允许的注册表，不接受用户任意填写的网络端点。启用备用源时必须为其保留非零、版本化的预算窗口，避免主源挂起耗尽整个公网阶段后备用源永远无法执行。

## 已验证复现与根因摘要

- Issue 01 已锁定当前 DuckDuckGo HTML 路径会返回反机器人挑战，且现有实现将它误报为空结果。
- 固定浏览器兼容请求特征能在真实单次探针中恢复结果，但重复探针仍观察到间歇空响应，因此它只是必要修复，不足以支撑生产可用性承诺。
- 当前产品将无密钥 DuckDuckGo 固定为唯一普通网页搜索提供方，没有结构化备用来源；一旦 HTML 路径受阻，学习模式只能安全降级。
- 当前公网阶段已有 8 秒共享墙钟，任何备用都必须消费同一截止时间，不能为每个提供方重新获得一份完整预算。

## 非目标

- 不把备用提供方替换成新的唯一主用来源；DuckDuckGo 仍是默认首选。
- 不在用户界面提供任意网址、任意 API 或用户自定义爬虫的安装入口。
- 不为了“搜到东西”而放宽私密查询切片、来源 URL 安全、页面抓取或引用绑定规则。
- 不在本任务中建立教学证据的语义覆盖裁决；该能力由 Issue 03 交付。
- 不使用模型记忆伪造搜索结果，不在所有提供方失败时隐藏未核实状态。

## Acceptance criteria

- [x] ADR-0009、ADR-0025 和 ADR-0026 与代码同步更新，明确 DuckDuckGo 主用、已登记结构化提供方备用、共享截止时间、凭据与隐私边界、显式来源披露以及全部失败时的安全降级。
- [x] 至少一个返回结构化标题、URL、摘要和提供方版本的生产备用适配器可由部署配置显式启用；未登记的提供方标识或任意网络端点被拒绝。
- [x] DuckDuckGo 成功时不调用备用提供方，搜索卡、结果、引用和审计只显示 DuckDuckGo。
- [x] DuckDuckGo 发生挑战、限流、连接错误、超时或无效响应时，备用提供方在剩余公网阶段预算内有界执行；成功后同一条聊天消息以成功或部分成功终结，并展示备用提供方的真实名称和可打开来源。
- [x] 启用备用源时采用 ADR 固化的 failover/延迟对冲预算策略，为备用调用和来源安全校验保留非零窗口；受控时钟下即使主源挂起至其分配窗口结束，备用源仍能在共享 8 秒阶段内完成，不能出现“配置了备用但主源总能耗尽全部预算”的伪降级。
- [x] DuckDuckGo 经一次真实空结果与最多一次有界改写后仍无结果时，可进入备用提供方；这一路径不得与挑战页错误语义混同。
- [x] 投影持久化已尝试提供方、最终采用提供方、各次脱敏结果码和提供方版本，历史消息可不依赖当前配置正确重建来源披露。
- [x] 主用与备用全部失败时，用户得到最后一个有意义、可稍后重试的结构化失败状态，教学不伪造来源、不取消未核实提示、不推进课时。
- [x] 主用与备用只接收同一份本地脱敏最小查询；不传输账户 ID、画像、会话原文、知识库正文、提供方凭据或其他私密上下文。
- [x] 备用凭据只从现有全局运行配置或凭据库注入，不进入消息、搜索投影、审计、日志、导出或前端返回。
- [x] 主用、备用、来源页抓取和必要改写共享同一个公网阶段截止时间；公网阶段不超过 8 秒，完整前台运行不超过 120 秒，且每个未开始的后续调用在截止时间到期后被取消。
- [x] 缓存与健康状态按账户、提供方、提供方版本和脱敏查询隔离，不得跨账户或跨提供方误用结果。
- [x] 每个已登记提供方都有复用业务解析合同的语义健康检查：缺凭据、挑战、限流、结构错误和不可安全引用的响应均不得报告为可用；整体健康状态准确反映当前是否至少有一个可用公开来源。

## Test plan

- 使用确定性主用与备用替身覆盖：主用成功、主用挑战后备用成功、主用超时后备用成功、主用真实空结果改写后备用成功、双方失败、剩余预算不足未启动备用。
- 用完整聊天集成测试验证搜索投影、提供方披露、教学卡、可打开来源、模型上下文、引用绑定和终态的一致性。
- 增加配置合同测试，验证未登记提供方、缺失凭据、无效端点和生产环境不安全配置均以中文明确拒绝，不静默回退。
- 使用可控时钟和慢替身验证共享 8 秒阶段预算、未启动调用的取消、运行终态以及无后台泄漏任务。
- 使用主源挂起与备用源快速成功的受控时钟用例，验证预算预留/延迟对冲策略确实给备用源留下完成窗口，并且选择结果的规则确定、可审计。
- 重跑脱敏、危险 URL、页面抓取、来源冲突、缓存持久化、账户隔离、备份恢复与历史消息渲染回归。
- 对已登记备用提供方保留显式联网冒烟，在发布前验证结构化响应、真实 URL、错误分类和凭据不泄漏。

## Observability & rollback

- 记录脱敏的提供方尝试序列、选中提供方、结果计数、错误码、缓存命中、剩余预算、熔断状态和阶段耗时；不记录查询、结果正文或凭据。
- 本地运行摘要应能区分“主用成功”、“备用成功”、“全部失败”和“未在预算内启动备用”，但不建立外部遥测。
- 备用提供方通过部署配置和能力注册开关可独立停用。回滚时恢复为“DuckDuckGo 主用 + 显式可重试失败”，不得回滚 Issue 01 的挑战分类不变量，不得默默切到未登记来源。
- 新增投影字段保持向后兼容；回滚版本仍可读取历史消息，不修改或删除已持久化来源。

## Answer

- 已在 `codex/issue-02-public-search-fallback` 分支的独立 worktree 中完成实现：DuckDuckGo 主用、显式注册的 Brave Search 结构化备用、共享 8 秒阶段截止时间与 2 秒默认保留窗口、最多一次真实空结果改写、结构化失败与提供方健康摘要均已接入。
- 搜索投影、聊天上下文、教学来源、前端搜索卡和审计均展示实际提供方与版本；缓存键包含账户、脱敏查询、提供方、版本和 freshness 窗口，SQLite 已从 v43 迁移到 v44。
- 确定性测试已覆盖配置拒绝、结构化解析、健康分类、主用成功、挑战/无效响应/真实空结果切换、预算不足、双失败、取消、缓存隔离和聊天/教学投影。
- 已通过：89 个相关测试（1 个跳过）、备用搜索测试 19 个、前端 typecheck、lint、OpenAPI 同步和 Python 编译检查。真实 Brave 外部冒烟未执行，因为当前环境未提供部署凭据；发布前仍需按 Test plan 显式验证。
