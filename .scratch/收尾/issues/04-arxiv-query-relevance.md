# Issue 04：让中文论文请求生成最小且相关的 arXiv 查询

Status: ready-for-agent  
Type: task  
Priority: P0  
User stories: US-02, US-05

## What to build

交付一条可独立验收的论文搜索纵向路径：用户用自然中文提出“给我找几篇Transformer方向相关的论文”时，系统应稳定识别为论文搜索，先在本地删除“给我、找、几篇、方向相关的论文”等指令词和低信息量修饰语，再把仅包含公开主题与显式约束的最小查询发送给受限 arXiv worker。返回结果必须通过确定性的 Transformer 主题相关性检查，只有合格论文及其紧凑引用可以进入模型上下文和聊天展示。

同一条路径必须继续执行最小公开披露：私人文档描述、账户信息、邮箱、凭据、令牌、代码块、网址和其他身份材料不得进入外发查询、持久化查询摘要、日志、指标或错误详情。净化后没有有效公开主题时应先澄清，不得发起“公开论文主题”之类的宽泛兜底搜索；没有相关结果时应明确返回可重试的空结果状态，不得让模型凭记忆伪造论文或引用。

## 已验证复现与根因摘要

- 确定性本地探针确认，精确用户输入能够命中 `paper_search`，但当前规范化结果仍包含“给我”和“方向相关”等中文指令/关系词。
- 当前 arXiv 请求编译会把规范化查询中的每个词都变成必须同时命中的条件。这样会把中文礼貌词和泛化修饰语错误升级为检索条件，即使 `Transformer` 是清晰主题，也可能得到空结果或低相关结果。
- 现有隐私净化覆盖部分显式敏感格式，但缺少“自然中文指令词 + Transformer 主题 + 私人材料”组合输入的端到端外发载荷断言，也缺少结果进入模型前的确定性相关性门。
- 复现不依赖真实网络；在 worker 边界捕获查询即可稳定观察错误的最小化结果。

## 非目标

- 不建设通用搜索引擎、论文推荐画像、向量排序平台或新的用户可管理 MCP。
- 不翻译或重写论文正文，不生成论文摘要之外的新科学结论。
- 不改变网页搜索 8 秒、arXiv 10 秒和前台 run 120 秒的预算合同；来源感知截止时间由独立 issue 05 负责。
- 不以删除所有中文词作为修复方式；合法中文主题、作者、标题、年份和 arXiv 标识符必须继续受支持。
- 不为提高命中率而放宽私人材料外发边界，也不在空结果时回退到模型记忆。

## Acceptance criteria

- [ ] 对精确输入“给我找几篇Transformer方向相关的论文”，持久化路由为论文搜索，外发查询保留 `Transformer` 高信息量主题，且不包含“给我”“找”“几篇”“方向相关”“论文”等指令词或泛化修饰语。
- [ ] 中文指令词清理采用短语/上下文感知规则；“量子纠错方向的论文”等输入仍保留真实学科主题，不因机械删除“方向”附近文本而丢失语义。
- [ ] 对包含“私人文档：内部代号蓝鲸、alice@example.com、token=secret-123、个人网址”等材料的 Transformer 请求，worker 捕获的查询、查询摘要、日志、指标和模型载荷均不出现这些私人内容，只保留最小公开主题与显式论文约束。
- [ ] 净化后没有主题、作者、标题、年份或 arXiv 标识符时，系统返回一次必要澄清并且 arXiv worker 调用次数为零。
- [ ] 固定结果集中同时存在 Transformer 相关与无关论文时，只有标题或摘要满足确定性主题相关性规则的论文可以进入投影、模型上下文和紧凑引用；无关结果不得仅因 arXiv 返回顺序靠前而通过。
- [ ] arXiv 返回成功但所有论文均不相关或结果为空时，聊天以可重试的空结果/证据不足状态收敛，不调用模型生成无来源答案，不推进学习课时。
- [ ] 成功路径展示真实论文标题、作者、摘要链接/PDF 链接和稳定引用标识；模型答案必须引用允许清单中的论文。
- [ ] 路由快照和公开查询摘要保存的是净化后的最小查询；重试复用同一版本快照，不重新引入原始私人正文，也不重复发起已经成功的查询。
- [ ] 本地确定性基准中，论文意图识别、净化与查询编译的单次 p95 不超过 50 毫秒，不新增网络调用或模型调用。
- [ ] 用户在外发前取消时不得启动 arXiv 请求；外发后若编排器进入取消终态，本切片不得把取消误报为空结果或相关性失败。跨层停止传播与有界回收由 Issue 05 验收。
- [ ] 两个并发账户分别提交 Transformer 与量子纠错请求时，各自的外发查询、结果白名单、持久化投影和模型上下文严格隔离，不串入另一请求的主题或私人材料。
- [ ] 新行为不改变 web-only、arXiv-only、both 和总 run 的现有预算数值，且所有错误仍使用中文、稳定、可重试的产品合同。

## Test plan

- 为自然语言路由和查询编译增加表驱动单元测试，覆盖精确输入、中文礼貌/指令词、合法中文主题、英文主题、作者/标题/年份/arXiv 标识符、空主题和结果数量边界。
- 增加隐私最小化参数化测试与属性测试，组合邮箱、凭据、令牌、私人文档句子、网址、代码块和身份描述；在 worker、持久化、日志、指标及模型载荷五个边界分别断言不泄漏。
- 在聊天集成测试中使用捕获型 arXiv worker 替身，验证精确输入的外发查询、路由快照、成功引用、无关结果过滤、空结果 fail-closed、取消和重试。
- 增加两个账户/两个主题的并发测试，使用不同固定论文结果验证查询、投影与模型上下文不会串线。
- 增加真实 API 的确定性浏览器纵向测试：自然中文输入后展示 Transformer 论文和紧凑引用；私人材料不出现在任何可见查询摘要或诊断产物中。
- 运行论文路由、arXiv 服务、聊天生成、隐私扫描和收尾组合套件；测试必须使用仓库虚拟环境，避免解释器路径混用造成无关握手假红。

## Observability & rollback

- 仅记录路由版本、净化结果码、公开主题词数量、被移除的数据类别、候选数、相关结果数和终态；不得记录原始消息、净化前后查询正文、论文摘要或任何秘密。
- 为“净化后为空”“全部候选不相关”“arXiv 空结果”和“引用门拒绝”保留可区分的内部结果码，用户侧继续使用稳定中文恢复提示。
- 查询编译器和相关性规则必须版本化；新消息使用新版本，已持久化的旧路由快照保持可读取和可审计，不做破坏性数据改写。
- 若上线后相关结果率异常，可回滚新版本路由编译器并停止新快照写入；隐私最小化门和 fail-closed 相关性门不得随回滚关闭。无法安全回滚时应临时返回可重试不可用状态，而不是恢复宽泛外发或模型兜底。

## Blocked by

None - can start immediately.
