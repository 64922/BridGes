# Issue 03：让学习可靠性与实际证据覆盖保持一致

Status: ready-for-agent

Type: task

Priority: P0

User stories: US-01、US-05

## What to build

交付一条可演示的学习证据一致性纵向切片：公网搜索“成功返回网页”不再自动等于“证据足以教学”。只有已实际抓取、可安全引用、与当前学习目标相关并达到覆盖门槛的来源，才能进入教学证据门、模型上下文和回复引用。搜索成功但结果无关、仅有摘要、页面无法抓取、来源冲突或覆盖不足时，用户应看到“已搜索但未覆盖本轮目标”的准确状态，而不是虚假的可靠教学。

本切片必须使搜索投影、教学证据门、教学卡、模型输入、回复引用和学习进度共享同一份经裁决来源集。它应同时适用于 DuckDuckGo 与后续已登记的结构化提供方，但不依赖 Issue 02 才能完成。

## 已验证复现与根因摘要

- 当前教学来源收集只检查搜索投影是否成功或部分成功、单条结果是否标记为已抓取，没有核对它是否覆盖当前学习目标。
- 只要存在一条这样的外部来源，教学证据门就可以被判定为足够；这会在 Issue 01 恢复搜索后把“空结果”风险变成“无关结果被认为可靠证据”风险。
- 现有成功测试大多使用固定相关结果，因此没有覆盖“搜索技术成功但语义无关”的反例。
- 学习模式的安全合同要求证据仍不足时明确说明缺口，不得把模型记忆或无关网页伪装成来源。

## 非目标

- 不建设通用互联网排名引擎、全站爬虫或全局推荐系统。
- 不在本任务中引入新的搜索提供方或凭据；结构化备用由 Issue 02 交付。
- 不把“来源站点知名”直接当成“覆盖用户目标”，不把搜索结果数量当成充足性。
- 不改变学习模式的课程交互、画像提取或全局知识库产品范围。
- 不在证据不足时隐藏缺口，也不允许模型自行声称来源充足。

## Acceptance criteria

- [ ] 给定“我想学习Transformer架构的相关知识”，已抓取且明确覆盖 AI Transformer、架构和自注意力核心概念的来源可通过证据门，进入模型上下文并产生可绑定引用；教学卡显示证据充足，回复不带未核实提示。
- [ ] 对同一学习目标，仅讨论电力变压器、与 AI Transformer 无关的网页被排除在教学来源集之外，即使这些页面已成功抓取且搜索投影本身为成功。
- [ ] 仅搜索摘要、页面抓取失败、来源冲突、相关但无法覆盖本轮核心目标的结果，均不得让 `can_answer_reliably` 变为真。
- [ ] 搜索技术成功但证据覆盖不足时，搜索卡保留可查看结果，教学卡则明确显示“已搜索但未覆盖本轮目标”及可恢复动作，两者状态不被错误合并。
- [ ] 只有通过覆盖裁决的来源才能进入教学卡来源、模型上下文和回复引用；每个回复引用都可反向绑定到同一条已接受来源。
- [ ] 当没有来源通过覆盖裁决时，回复保留未核实或证据不足提示，不伪造引用，不将本轮写为有效课时，不更新已覆盖主题。
- [ ] 当来源通过裁决且回复引用校验通过时，同一轮最多推进一次学习进度；重试、恢复和幂等回放不重复推进。
- [ ] 覆盖裁决的输入只包含当前脱敏学习目标与本轮已安全抓取的有界来源内容，不自动混入完整会话、画像、账户标识、知识库无关正文或凭据。
- [ ] 覆盖裁决在公网搜索截止时间之后不启动新的外部调用；公网阶段仍在 8 秒内收敛，完整前台运行仍在 120 秒内到达明确终态。
- [ ] 历史消息保持原有证据投影和渲染，新规则只影响新运行；不追溯改写过往教学结论。

## Test plan

- 为覆盖裁决建立确定性测试矩阵：相关已抓取来源、无关已抓取来源、仅摘要、抓取失败、部分覆盖、多来源冲突、无任何来源。
- 用 AI Transformer 学习目标与电力变压器干扰页构建必须失败的反例，并用覆盖架构和自注意力的真实样式来源构建必须成功的正例。
- 在完整聊天集成测试中验证搜索投影、教学证据门、模型输入、回复引用、未核实前缀和学习进度使用同一份已接受来源集。
- 增加前端契约或端到端测试，区分“搜索未成功”、“搜索成功但覆盖不足”和“证据充足”三种用户可见状态。
- 重跑教学强制联网、本地证据充足、搜索失败降级、引用校验、来源冲突、学习进度幂等和账户隔离回归。
- 使用可控时钟验证裁决不开启新的无界外部调用，且失败、取消和预算耗尽都收敛到一个明确终态。

## Observability & rollback

- 记录脱敏的候选来源数、已抓取数、已接受数、拒绝原因码、冲突数、裁决耗时和最终证据状态；不记录学习目标正文、页面正文、用户消息或画像。
- 为“搜索成功但无来源通过覆盖”提供独立可聚合的本地结果码，避免它与提供方失败或真实空结果混在一起。
- 如新裁决策略出现回归，可通过版本化规则回滚；紧急安全回滚必须把公网来源视为证据不足，不得恢复“任意已抓取页都是充足证据”的宽松行为。
- 回滚不改写历史消息、历史引用、已发布课时或审计记录。
