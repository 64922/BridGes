## 五、共享全局 Key 运营风险披露（AC10）

所有本地账户共用同一把全局百炼运行凭据，由此接受以下运营风险：

- **配额与限流共享**：一个账户的高负载会消耗共享配额并可能触发供应商
  限流，影响其他账户的模型调用；
- **费用共享**：全部账户的模型调用（含图片/视频异步任务）计入同一供应商
  账单，无法按账户拆分供应商侧计费；
- **审计边界**：应用审计仍按发起账户记录（account_id 归属、运行锁、
  云端披露记录不变），但**不代表**供应商侧独立计费或独立限流；
- **轮换即全局**：Key 轮换影响全部账户，轮换后必须重启相关服务；
- **启动硬门**：缺失全局 Key 时规范入口（`BridGes start`/`api`/`worker`）
  直接失败关闭，这是"打开即完整可用"的明确选择，不应被后续实现静默改回
  降级启动；
- **Key 有效性边界**：启动只校验可读取，非空不等于权限与额度可用；运行期
  供应商错误如实呈现，不伪装成功。

## 六、真实百炼冒烟（显式启用，不计入 CI）

自动化使用确定性适配器；真实供应商冒烟必须显式启用且**可能计费**：

```bash
# 文本/语音/向量（轻量）；图片/视频（较重，会调用异步任务）
BRIDGES_SMOKE_QWEN_KEY=sk-... python scripts/smoke_ingestion_embedding.py
BRIDGES_SMOKE_QWEN_KEY=sk-... python scripts/smoke_image_generation.py
BRIDGES_SMOKE_QWEN_KEY=sk-... python scripts/smoke_video_generation.py
```

约束：Key 只经环境变量或项目外 `*_FILE` 文件引用提供，绝不写入仓库、
`.env`、日志或输出；脚本自带无泄漏校验。验收记录只保存模型、能力、状态与
追踪 ID，不保存全局 Key、完整私人提示或供应商原始敏感响应。账户级密钥
探测冒烟（smoke_key_probes）已随账户密钥整体退役删除。
