# 职业规划 Agent 目标与公开岗位取证修复

Status: ready-for-human

## 问题与复现

用户请求：`我想做agent开发相关工作，可以以给我规划一下吗；算法；大三`。
失败结果有 11 个候选链接、0 个样本，查询只有泛化的算法工程师，输出主要为诊断记录。

确定性回归：`python -m pytest -q tests/career_plan/test_agent_retrieval_regressions.py`。
最初 4 项测试全部失败；修复后包含完整持久节点、HTTP 解析与质量门的 8 项测试通过。

## 根因与修复

- 岗位词表缺少 Agent/智能体方向；算法澄清回答丢掉原始细分目标。增加识别，澄清后保留原始 Agent 方向，使用该方向的同义岗位和职责证据筛选。
- 查询偏向招聘列表，列表与首页占用有限详情读取配额。公开招聘限定详情路径，详情排序优先，已知列表仅作入口链接保留，不消耗详情配额。
- 企业查询命中的官网校招详情被预期来源类别排除。保留所有已识别招聘来源的候选，按实际来源分类和展示，不把另一类的有效详情当作非招聘页。
- 年级原话作为校招查询词，与岗位常用招聘口径不符。在校低年级查询实习，保留原年级；届别仍按明确年份查询，校招不再绑定单一门户。
- 非 JSON-LD 页面把全站导航当岗位要求、截断前 15 条，错误采用新闻日期/学历。以职位 h1 确定范围，截去相关职位；岗位职责开始后才提取要求，读取明确工作地点或岗位元信息行。
- 读取截止时间在搜索前已开始计时。改为按实际读取耗时消耗读取预算，仍受全轮预算控制。
- 输出先展示统计与有依据的准备动作，查询记录后置；无样本时提供恢复动作，继续禁止无依据的技能/薪资结论与个人能力判断。
