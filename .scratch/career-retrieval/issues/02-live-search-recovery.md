# 职业规划真实搜索仍为零样本：正文复用与有界补搜

Status: ready-for-human

## 用户再次复现

2026-10-07，用户重启后仍得到 0 样本。输入：
`我想做agent开发相关工作，给我规划一下；算法；大三`。

上轮只验证了指定详情页与确定性替身，没有验证真实 Tavily 召回后的完整链路，验收不充分。
本轮通过项目凭据接口只读取得已保存的安装级 Tavily 配置；密钥不打印、不落盘、不发送给其他服务。没有读取或修改用户会话和画像，真实验收状态只写独立临时数据库。

## 已确认根因

1. 初始查询多数返回访问验证页、列表、动态页面与已下线职位；即使实际可用样本为零，三次查询结束后也没有补搜。
2. 公网搜索客户端已经通过 Tavily Extract 获取部分公开正文，职业规划适配器丢弃这项证据，随后直接 HTTP 再次撞访问验证页。
3. 招聘汇总 FAQ 的岗位标签不能当作单个职位的名称和要求；真实验收中发现并补了拒绝测试。
4. 常见 `100-200元/天` 字段漏读；提取服务把编号要求合成一段后，尾部要求被 200 字截断。

## 修复

- 同时满足 verified/cross_verified、抓取时间和实际正文时，才复用来源内容；structured/摘要不能形成样本。
- 只从正文中的单个岗位名、独立职责/要求段和工作地点提取证据；保留部分可读状态，未知字段不补造。校招汇总、职位百科、讨论页等不占详情读取配额。
- 原查询未形成样本时，按同一 Agent 方向最多补搜两条招聘词；取得有效样本即结束。非招聘来源、过期和岗位/城市不匹配继续剔除。
- 补搜只占用共享账本的一轮调整额度；额度已使用时拒绝补搜，每次外部调用仍走账本，候选核对最多 20 个。
- 实际执行的补搜计划随采集产物持久化，最终正文与调用记录一致；配方/能力版本已更新，旧收据不复用旧采集逻辑。
- 识别明确日薪原文，并恢复编号条款边界；没有原文的薪资和要求保持缺失。
